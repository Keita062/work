## MTG遍歴（西村氏との定例）

**作業内容は毎回このMTGで決まる。着手前に必ず直近の回を確認する。**

### ① 2026-06-01 — GIS・地理情報の可能性

雑談主体の回だが、以降に効いている論点が2つ。

- GISコミュニティフォーラムで**渡辺美智子先生**の講演を聴き、個別に相談。「地理情報を可視化に使うだけでなく**主成分に入れるとモデルの説明力が向上する**」「1km×1kmメッシュ統計のヒートマップは既に一般化しているので、その先を考えてほしい」との投げかけ
- **主成分の軸を回転させると説明の仕方が変わり、EBPM・政策提言がしやすくなる**
- 国土交通省 **PLATEAU**（3D都市モデルのオープンデータ）を勧められた
- → GISデータを使いたい、という方向づけ

### ② 2026-06-23 — 要件定義書の型づくりと最終アウトプットの決定

鈴木がインターン先の要件定義書23件を参照して**分析要件定義書のテンプレを作成**。Googleドキュメントで共同編集し、アジェンダは1つ上の階層に集約する運用を開始。

決まったこと：

- **目的と背景・課題は分ける**。西村が書いた「経済発展の裏側でWBが向上していない」は背景であって目的ではない
- 「**なぜ和歌山なのか**」の理由づけが必要。今は「和歌山コンペだから」しかない。データの特徴を見て後から記述する
- **提言対象（政府 or 個人）は未決定のままでよい**。分析後に決める、または両方
- 分析対象（ターゲット）は早めに決める。データが無いという事態を避けるため
- **ER図を書いてテーブル→中間集計→アウトプットのパイプラインを図式化する**（鈴木の実務目線）
- サンプルサイズ不足への対応：**クラスタリングで和歌山に類似した県を統合してデータを増やす**（西村案）
- **最終アウトプットは「ベイジアンネットワーク（因果構造ネットワーク）」に決定**。PERMA-V 5要素を独立に並べて提言すると聞き手に刺さらないため、要素間の依存関係をデータから自動探索し、優先度をつけて「これをすればWBが何%上がる」を示す
- **感度分析は不要**と判断（ROI算出のストーリーに吸収されるため）
- **ROI（費用対効果）の算出をやる**方針で合意。「学生レベルで止めたくない、やるなら本気で」。経営学部の教授（PL・損益計算書が専門）に相談する案
- データのやり取りは**GitHub**で行う

### ⑤ 2026-08-05 — **「仕事に着目する」路線の断念とデジタル庁ダッシュボードへの転換（最重要）**

### 2026-08-10: 「方法」の手段を詰める作業ドキュメントを作成

08-07 MTGで**空欄のまま持ち帰った「方法（進め方3・4の手段）」を埋める**ための作業ドキュメントを新規作成 → [docs/方法提案_0810MTG.md](../../031_wakayama-wellbeing-competition/01_docs/方法提案_0810MTG.md)。

**構成は 目的 → 設計 → ステップ → 各ステップをどう測るか。** [`作業会話.md`](../../031_wakayama-wellbeing-competition/01_docs/作業会話.md)（AI壁打ちで詰めた分析設計）を並べ直したもの。**各ステップに「検討して採らなかった案＋その理由」と「決まっていないこと」を持たせてあり、壁打ちして埋めてからMTGに出す**運用にしている。

**各ステップの手段（要点）**：

| ステップ | 何を測るか |
|---|---|
| **1** どの分野を攻めるか | 目的変数＝**主＝Q4生活満足度／従＝Q1幸福度**（両方回す）。**線形（Elastic Net＋ブートストラップ選択頻度）→ 階層（Mixed Effects）→ 非線形（XGBoost）の3本を回し、GroupKFold＋時間外挿で勝った方を主役に**。出力は β・選択頻度・SHAP順位・年度安定性・**設問数**の統合表 |
| **2** どこが凹んでいるか | **分野ごとの回帰の残差**（主観カテゴリ = a + b×客観カテゴリ + 人口 + 高齢化率）。24分野すべてで回す。**副産物のR²で「受賞・条例の有無が過半」の分野を機械的に落とせる** |
| **3** 上げられるのか | ★**「残差の大きさ」ではなく「主観の可動域」で測る。** 分散分解＋`(主観_t − 主観_{t-1})² = α + λ×(1/n)` で**回答者数由来の誤差を差し引いたα**を出し、固定効果パネル `Δ主観 = γΔ客観 + 年ダミー` と組み合わせて **(a)動く＆γ小→ソフト（存在証明つき）／(b)動く＆γ有意→ステップ4／(c)動かない→撤退** を判定 |
| **4** 何のKPIを上げるか | 分野の**客観個別KPI**を回帰（10本以上ある分野はLasso）。**KPIの符号が住民の主観と一致しているか確認**し、飽和を見て、+1偏差値に必要な量を逆算。**潜在変数は4分類**（(i)時間不変の未観測要因＝**固定効果で消す**／(ii)時間可変の共通要因＝年ダミー／(iii)構成概念＝CFA・SEM／(iv)取得可能＝**GIS等で観測変数として足す**） |
| **5** どんな施策か | **「残差が高い自治体」ではなく「残差が改善した自治体」**（客観が動いていないのに主観残差が改善＝環境を変えずに実感を上げた事例）を抽出し、Web資料＋LLMで定性調査。施策時期が特定できればイベントスタディ／DiD |
| **通し** | `政策優先度 ＝ 重要度(ステップ1のβ) × 課題の大きさ(ステップ2の残差) × 改善可能性(ステップ3の判定) × 政策介入可能性(ステップ4・5)`。**ROIの分子には β×γ×ΔKPI を使う** |
