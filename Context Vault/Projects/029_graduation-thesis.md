- ステータス：着手前（教授への合意形成待ち）

## 背景・経緯
- 【2026-09-28】初期案は研究室用チャットボット（Gemini API／Node.js・TypeScript／Cloudflare／研究用DB／SQL抽出＋Python分析）でユーザー入力・AI回答・ログインID・時刻を保存する方式を検討
- 【2026-09-28 方針変更】研究室の人は既に使っているCoding Agent（VS Code／Unity開発）で開発相談をするため、研究用Botには自然なデータが集まらないと判断。VS CodeとUnityの通常の開発作業の中でCoding Agentの利用イベントをHook等から観測する方向に転換
- 【2026-09-28】被験者の回収負担をなくすため、初回同意・ID設定後はイベント発生時に自動取得→ローカルに一時保存→ネット接続時に研究用APIへ自動同期する構成（VS Code／Coding Agent → Hook → Collector → ローカルバッファ → 研究用API／DB）とする方針
- 【2026-09-28】研究室内でClaude Code／Codexの有料契約者が少なく無料でも利用者が少ないため、「研究室共通のAI開発環境を整備し、みんなに使ってもらいながらデータを収集する」という副次目的を設定
- 【2026-09-28】教授への合意形成文書（DOCX）「研究室共通AIコーディング環境の試行と利用行動研究に関する相談」を作成。準備→少人数試行（希望者2〜3名）→本実施（4〜8週間を仮置き）→分析の流れ、取得データ初期案、参加者保護・同意/撤回/仮名化、費用・製品選定の論点、教授に判断を仰ぎたい事項を記載
- 【2026-09-28 重要な訂正】Gemini CLIの個人無料枠を研究室で使い回す前提は成立しない。Googleの公式案内により2026年6月18日以降、個人向けGemini Code Assist等によるGemini CLI利用は停止されている（参考：https://developers.google.com/gemini-code-assist/docs/deprecations 、 https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/ ）。共有アカウント・個人枠の使い回しは前提にしない
- 【2026-10-19】ChatGPTとの会話の引き継ぎ用コンテキスト（`00_context/Claude引き継ぎ用_研究室AI環境と利用行動研究_20261019.txt`）と教授向け提案書原本（`00_context/研究室AIコーディング環境と利用行動研究の実施相談.docx`）をダウンロードフォルダから取り込み

- 観測対象はチャットボットではなく、VS Code／Unityでの日常のCoding Agent利用イベント
- 初期試行ではプロンプト・回答本文・コード・ファイル名・絶対パス・認証情報は収集・送信しない。取得候補は研究用ID／時刻／セッション識別子／イベント種別／ツール名／所要時間／成否などに限定

- 共有アカウントや個人無料枠の使い回しを前提にした製品選定はしない（Gemini CLI個人無料枠は不可）
- 研究参加は任意。不参加・途中撤回による不利益を生じさせない。環境利用と研究へのログ提供は分けて説明する
