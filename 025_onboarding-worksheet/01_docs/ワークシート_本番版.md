## 成長経験

### 人生で一番成長した経験

```
大学1年から4年間、自分が通っていた塾で講師を務め、「全体400人中トップ12人の優秀講師」を目標に取り組んだ経験。
新人最優秀賞（新人100人中1位）、二年連続優秀講師選抜（全体400人中9位）、科目優秀講師（380人中1位）を獲得し、担当生徒の偏差値30以上アップを実現しました。
```

### 活動/経験の中で一番苦労したこと・難しかったこと

```
最初の授業で生徒に何も教えられていないという強い無力感を感じ、同僚や先輩との学力・言語化能力の差を痛感しました。
加えて教室長からのフィードバックも厳しく、常にプレッシャーを感じながら働いていたことが一番の苦労でした。
```

### その時どう乗り越えたか

```
授業前に先輩講師へ「今日の授業を見てほしい」と自分から依頼し、授業後にフィードバックをもらって課題を明確化し、次の授業で改善することを繰り返しました。
さらに個人の改善に留めず、教室をどうするべきかを先輩講師や教室長と対話し、生徒の成績が上がりやすい環境そのものを改善しました。
```

### その経験からの学び

```
フィードバックを自分から取りに行き、課題を明確にして改善を繰り返すという、自己成長の進め方を身につけました。
また、個人の成果に閉じず、チームとして課題を捉えて解決することで、より大きな成果につながることを学びました。
```

## 強み／弱み

### 強み

```
・コミュニケーション力／構造化力／推進力
・相手に合わせて伝え方を変え、ゴールから逆算して分解し、立てた目標を最後までやり切れる
```

### 弱み

```
・発散してしまうところ／スピード感がないところ
・検討範囲を広げすぎて絞り込みに時間がかかり、優先順位が低いと判断したものは熱量が下がる
```

> ※ 強み・弱みは、上記の成長経験エピソードと関連していなくてもOK（スライド7 記載例より）
