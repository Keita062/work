今日のセッションの終了処理を行う。

1. このプロジェクトの `Context Vault/Projects/NNN_案件名.md` を読み、今回の変更内容を踏まえて以下を更新する
   - 「現在の進捗」に今日の作業を追記する
   - 「次のアクション」を具体的に書き直す
   - 「注意点」「未確認事項」を追記する

2. 上記の中に、他の案件でも再利用できそうな知見があれば、該当する `ナレッジベース/` 配下のファイルに
   転記することを提案する。ユーザーの確認を取ってから転記する（新規作成時は `ナレッジベース/README.md`
   の索引にも1行追記する）。

3. この案件が完了したかどうかをユーザーに確認する。完了であれば以下を `git mv` で移動する
   （履歴を保持すること）。

   ```bash
   git mv NNN_案件名 completed_projects/NNN_案件名
   git mv "Context Vault/Projects/NNN_案件名.md" "Context Vault/Archive/NNN_案件名.md"
   ```

   移動後、`README.md` §2 の案件ID一覧の状態を更新する。

4. 変更内容を要約した意味のあるコミットメッセージで git commit する
   （実行前にユーザーに確認する）。
