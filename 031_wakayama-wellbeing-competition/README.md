# 和歌山コンペ

和歌山県のウェルビーイング（主観的幸福度）向上をテーマにしたデータ分析コンペ用フォルダです。「仕事の質」が個人・地域社会の幸福度に与える影響をリサーチクエスチョンとし、PERMA-Vの枠組みで分析を進める方針です。詳細は [`docs/和歌山コンペ_分析要件定義書_整形版.md`](docs/和歌山コンペ_分析要件定義書_整形版.md) を参照してください。

## フォルダ構成

- `docs/` — 分析要件定義書（オリジナル版・整形版）
- `data/` — 内閣府・厚労省・総務省等の公的データ（Well-being、健康・栄養、就業構造、社会生活時間 等）とER図
  - `data/digital_wellbeing_shikuchoson_2022_2026.xlsx` — デジタル庁 地域幸福度（Well-Being）指標 全国調査の全国版（全47都道府県×全市区町村×2022〜2026年度版）。シートは「説明」「主観データ」（年代・性別区分あり）と「客観データ」。収集日は2026-09-21
