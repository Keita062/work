# 和歌山コンペ

和歌山県のウェルビーイング（主観的幸福度）向上をテーマにしたデータ分析コンペ。デジタル庁 地域幸福度（Well-Being）指標ダッシュボードのデータを使い、主観24カテゴリーの何が幸福度に寄与しているか／客観の水準に対して主観が下振れているカテゴリーは何かを分析する。西村瞭一氏との2人チームで進行中。

- 案件ID：031
- ステータス：進行中（提出済み・2026-12-12の発表会待ち）
- 案件の詳細・経緯・MTG遍歴・次のアクションは [Context Vault/Projects/031_wakayama-wellbeing-competition.md](../Context%20Vault/Projects/031_wakayama-wellbeing-competition.md) を参照
- 共同作業の正本は別リポジトリ [`Keita062/wakayama_competition`](https://github.com/Keita062/wakayama_competition)（西村氏との共有リポジトリ）側にある。本フォルダは鈴木個人の作業領域

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `00_context/` | 受領した原本。編集しない（デジタル庁ガイドブック等） |
| `01_docs/` | 分析要件定義書・設計書・レビュー依頼資料など自分が作った成果物 |
| `02_memo/` | 調査メモ・WBS/ガントチャート |

| `04_data/` | 内閣府・厚労省・総務省等の公的データ（Well-being、健康・栄養、就業構造、社会生活時間 等）とER図 |
