# 【共有】分析の前提と、知りたいこと

> **宛先**：西村 瞭一 さん
> **作成**：鈴木　2026-08-07
> **この文書の役割**：デジタル庁 地域幸福度指標を使った分析について、**①何のためにやるのか ②データの前提 ③何を知りたいのか ④そのために使う指標**を一枚に整理したもの。認識合わせと、方針の合意をとるための資料です。
> **読み方**：§0 → §1 → §2 → §3 の順。§4 に決めたいことをまとめています。

## 0. 目的

### 0.1 この分析の目的

> **和歌山の主観的ウェルビーイング（住民が実際に感じている幸福度・生活満足度）を向上させるために、
> どの分野に、どんな手を打つべきかを、データから導き出す。**

24分野すべてに均等に予算と人員を割くことはできません。**限られたリソースをどこに集中させれば住民の幸福度が最も上がるのか**を、感覚ではなくデータで決める。これがこの分析の存在理由です。

### 0.2 なぜ「主観的」ウェルビーイングを目的に置くのか

施設を増やすこと・制度を作ること自体が目的ではなく、**住民が幸せを感じることが目的**だからです。

これは我々の解釈ではなく、**デジタル庁自身が指標の設計思想としてそう置いています**（ガイドブック p.11 のロジックモデル）。

| | ロジックモデル上の位置 | 測る指標 |
|---|---|---|
| **手段** | インプット／アクティビティ／アウトプット | **客観指標**（オープンデータ） |
| **目的** | アウトカム／インパクト | **主観指標**（アンケート） |

つまり**客観指標は「手段がどれだけ整っているか」の測定、主観指標は「その結果として住民が幸せになったか」の測定**です。目的側を目的変数に置くのが素直な設計になります。

### 0.3 最終的に出したいもの

コンペの応募要件は**「データから得られるエビデンスに基づく施策提案かつ、応募者が発案したオリジナルなもの」**です。これを満たすため、以下3点セットで出すことをゴールにします。

| # | アウトプット | どこから出るか |
|---|---|---|
| ① | **最優先で手を打つべき分野は◯◯である** | 知りたいこと1〜3 |
| ② | **その分野で具体的にこの施策を打つべきである** | 知りたいこと4（ソフト施策）または 知りたいこと5（ハード施策）。**どちらになるかは知りたいこと2-Bの判定で決まる** |
| ③ | **その施策で幸福度が◯ポイント上がると見込まれる** | 知りたいこと3の優先度スコア（＝ROIの分子） |

**①だけでは「分野を指さしただけ」で終わり、②だけでは「他所の真似」に見えます。③があって初めて費用対効果の議論ができます。** 3点そろって初めて、決裁者が動かせる提案になります。

### 0.4 一言でいうと

**「和歌山の主観的ウェルビーイングを上げるには、どの分野に手を打つべきか」を段階的に絞り込む**、という設計です。

```
[1]   主観総合スコアに効いている分野を特定する        （24分野 → 重要分野）
[2]   和歌山で「客観のわりに主観が低い」分野を特定する （24分野 → 下振れ分野）
[2-B] その下振れの正体を判定する                      （→ 施策の型が決まる）
[3]   1と2を掛け合わせて最優先分野を1つに絞る          （→ ターゲット確定）
[4]   (a)判定なら「お手本都市」を探して施策を持ち帰る  （→ ソフト施策）
[5]   (b)判定ならどのKPIをどれだけ動かすかを出す       （→ ハード施策）
```

**[2-B] が今回の追加分で、設計の分岐点です。** 詳しくは §2 の該当項と、その末尾の「なぜ 2-B と 5 を追加したか」を参照してください。

## 1. 前提 — データの構造

### 1.1 出どころが違う2種類のデータがある

ガイドブック2章 p.12・p.13 で明示されています。

| | 正式名称 | 出どころ | 測っているもの |
|---|---|---|---|
| **主観指標** | ウェルビーイングの因子 | **アンケート調査**（令和7年度 86,420件） | 市民のウェルビーイング（幸福感） |
| **客観指標** | 暮らしやすさの因子 | **オープンデータ**（公的統計） | 暮らしやすさ（Liveability） |

デジタル庁のロジックモデル（p.11）では、**客観指標＝「手段」側の測定、主観指標＝「目的」側の測定**と位置づけられています。つまり**客観が原因側、主観が結果側**という向きは、デジタル庁自身の設計思想です。

### 1.2 本書で使う4つの言葉

「主観指標」「客観指標」だけだと階層の違うものを同じ言葉で呼ぶことになり混乱するので、以下に統一します。

| 用語 | 中身 | 個数 | 尺度 |
|---|---|---|---|
| **主観総合スコア** | 「あなたは幸せですか」を直接聞いた4問 | 4 | 0〜10点 |
| **主観カテゴリスコア** | 24分野それぞれの「地域の◯◯をどう感じるか」 | 24 | **偏差値** |
| **客観カテゴリスコア** | 24分野それぞれの実態 | 24 | **偏差値** |
| **客観個別KPI** | 完全失業率など。客観カテゴリスコアの材料 | 208 | 元単位 |

ガイドブック p.15 に **「主観指標・客観指標ともに、データを偏差値化しています」** と明記されています。主観と客観を同じレーダーチャートに重ねられるのはこのためです。

### 1.3 ★重要：客観側に「総合スコア」は存在しない

ダッシュボードで確認したところ、**客観側の総合値はありませんでした。** 幸福度・生活満足度Q1〜Q4は主観アンケートのみで構成されています（p.14）。

これは表示上の都合ではなく、**分析の組み方を決めてしまう制約**です。

> **「暮らしやすさ全体 → 幸福感全体」を直結で分析することはできない。必ず24分野を経由する。**

```
客観カテゴリスコア(24)  →  主観カテゴリスコア(24)  →  主観総合スコア
       ↑                          ↑                        ↑
  オープンデータ             アンケート46問            アンケート4問
       └────── 知りたいこと2 ─────┘└──── 知りたいこと1 ────┘
```

つまり**知りたいこと1と2に分けているのは好みの問題ではなく、データ構造上そうするしかない**ということです。

### 1.4 データの形

最終的に手元にできるのは**1枚の表**です。

| 自治体 | 幸福度Q1 | 生活満足度Q4 | 主観_医療福祉 | … | 主観_事業創造 | 客観_医療福祉 | … | 客観_事業創造 |
|---|---|---|---|---|---|---|---|---|
| 札幌市 | 6.5 | 6.7 | 52.1 | … | 48.9 | 55.0 | … | 47.2 |
| … | | | | | | | | |
| **和歌山** | ? | ? | ? | … | ? | ? | … | ? |

**列は 4 + 24 + 24 = 52本。** 行数は分析単位によって変わります（次項）。

### 1.5 分析単位はまだ決めていません

**ここは相談したい点です**（§4 D1）。

| 案 | 行数 | 「和歌山」の指す先 | メリット | デメリット |
|---|---|---|---|---|
| **A. 市区町村版** | 530 | **和歌山市** | サンプル数が多く統計的に安定。お手本都市探しが成立する | 提言先が「和歌山市」になる。県全体の話ができない |
| **B. 都道府県版** | 47 | **和歌山県** | 提言先が県になる | n=47に説明変数24本は載らない。お手本探しも母数不足 |
| **C. 併用** | 530で推定／両方で診断 | 市と県の両方 | 情報量が最大 | 工数1.5倍 |

**現時点の傾き：A または C。** B単独は統計的にかなり厳しいです。

### 1.6 調査設計の実態（p.17〜p.20）

主観データは全年度とも**インターネット調査**（モニターへメール依頼→WEB回答）、対象は全国の18〜89歳男女。**母集団構成比による回収は考慮していません**（自治体規模に応じた目標値を設定）。

| 年度 | 有効回答数 | 回答数100以上の団体数 | 設問数 | 幸福度 全国平均 |
|---|---|---|---|---|
| 令和4年度 | 33,610 | **71** | 160（フルスペック版） | 5.96 |
| 令和5年度 | 84,965 | 391 | 50 | 6.47 |
| 令和6年度 | 101,498 | 668 | 51＋属性3 | 6.49 |
| **令和7年度** | **86,420** | **530** | **58（必須50＋オプショナル8）＋属性8** | **6.44** |

- **年度パネル（経年比較）をやる場合の制約**：令和4年度は71団体しかなく設問数も違うので土台になりません。**実質 R5〜R7 の共通自治体に限られます**
- **令和7年度は属性データが追加されているが、ダッシュボードには未反映**（p.17に明記）。デジタル庁に照会すれば取れる可能性があります

## 2. 知りたいこと

### 知りたいこと1：どの分野を改善すれば、住民全体の幸福度が一番効率よく上がるか

**なぜ知りたいか**
医療・買い物・雇用・子育てなど24分野すべてを均等に改善する予算も人員もありません。**「総合的な幸せに最も強く結びついている分野（てこの原理が働く分野）」に絞り込む**必要があります。

**使う指標**

| | 指標 | 個数 |
|---|---|---|
| 目的変数 | **主観総合スコア**（幸福度Q1／生活満足度Q4） | 1〜2 |
| 説明変数 | **主観カテゴリスコア** | 24 |

**どう分析するか**

1. 24分野の主観カテゴリスコアは**相互に強い相関**を持ちます（満足度が高い自治体は多くの分野で高く出る）。通常の重回帰では**多重共線性**で係数の破綻や符号の逆転が起きます
2. そこで、多重共線性を自動で抑制できる**正則化回帰（Elastic Net）**と、指標間の重複した影響を分解して純粋な貢献度を割り出す**ドミナンス分析（相対的重要度分析）**を使います
3. 多重共線性の影響を排除したうえで、各分野が幸福度を引き上げる**「真の影響力の強さ」を1位から24位まで順位づけ**します

### 知りたいこと2：和歌山で「客観の水準に対して主観が下振れしている分野」はどこか

**なぜ知りたいか**
全国の標準ライン（この客観水準ならこの主観になるはず）から、和歌山がどれだけ外れているかを24分野それぞれで測ります。**この段階では「なぜ下振れているか」は判断しません**（それは知りたいこと2-B）。

**使う指標**

| | 指標 | 個数 |
|---|---|---|
| 目的変数 | **主観カテゴリスコア**（分野ごとに個別） | 24分野それぞれ |
| 説明変数 | **客観カテゴリスコア**（同じ分野） ＋ 人口規模・高齢化率 | 1＋統制変数 |

**どう分析するか**

1. 全国のデータから「**客観的な環境がこれくらいのレベルなら、主観の実感はこのくらいになるはずだ**」という標準ライン（予測直線）を回帰で計算します
2. その標準ラインに和歌山の客観データを当てはめ、「**和歌山で本来期待される主観値**」を割り出します
3. 「実際の主観値」から「期待される主観値」を引き、**マイナスの残差が大きい分野**を「下振れしている分野」として抽出します

**「似ている市を探して比べる」ではなく回帰の残差にした理由**：全自治体を母数として使えて、「似ている」の定義（どの指標で、どんな重みで測るか）に結果が左右されなくなるためです。人口規模の統制も回帰の中で処理できます。

> **用語を変えました。** 当初この項目は「**環境はあるのに実感が追いついていない分野**」というタイトルにしていましたが、これは**解釈をひとつに決め打ちした表現**でした。中立に「下振れ」と呼び、その理由は次の 2-B で判定します。

---

### 知りたいこと2-B：その下振れは「伸び代」なのか、「その環境水準での実力値」なのか ★追加

**なぜ知りたいか**

知りたいこと2で出た負の残差を、そのまま「**伸び代がある**」と読むのは**論証されていない仮定**です。同じデータから、少なくとも3つの解釈が同じくらい成り立ちます。

| 解釈 | 中身 | 打ち手 |
|---|---|---|
| **(a) 届いていない** | 環境はあるが、認知・利用されていない | 周知・利用促進・使いやすさ（**ソフト**） |
| **(b) その環境水準での実力値** | この客観水準では、住民はこの程度しか感じない。回帰線まわりの自然な散らばりの範囲 | **環境そのものをさらに上げる**（**ハード**） |
| **(c) ノイズ／測定のズレ** | 回答者が約100人で誤差が大きい。または客観KPIと主観設問が別物を測っている | 打ち手なし。**この分野は降りる** |

**当初の設計は(a)を暗黙の前提にしていました。** しかし(b)なら周知施策では動かず、(c)なら何をしても動きません。**どれかを判定しないまま施策の型を選ぶことはできません。**

**使う指標**：知りたいこと2の残差（できれば R5〜R7 の3時点）、全自治体の残差分布。

**どう分析するか** — 4つのチェックで(a)(b)(c)を切り分けます

| # | 検証 | 方法 | 判定 |
|---|---|---|---|
| **V1** | **残差の経年安定性** | R5・R6・R7の3時点で同じ回帰を回し、和歌山の残差の符号と大きさが一貫するか | 3年とも同符号・同程度 → (a)か(b)。**符号が振れる → (c)** |
| **V2** | **残差の分布上の位置** | 全自治体の残差の標準偏差 σ を計算し、和歌山の残差が何σ分外れているかを見る | **\|残差\| < 1σ → ただの散らばり＝(b)**。2σ以上外れる → (a)の可能性 |
| **V3** | **残差と客観水準の関係** | 残差を客観カテゴリスコアに回帰（またはLOESSで可視化） | **系統的な負の傾き → (b)**。環境が良い自治体ほど期待も高く主観が下振れる（適応）。周知では動かない |
| **V4** | **残差の分野間相関** | 和歌山の24分野の残差が全部負に寄っていないか | **全分野で負 → (c)**。その自治体の回答者が全般的に辛口なだけ |

**V2 が最も安く、最も効きます。** 「残差が −3偏差値」と言っても、**全自治体の残差の標準偏差が5なら、それはただの散らばりであって伸び代ではありません。** この確認が当初の設計に完全に欠けていました。単年データだけで数十分で回るので、最初にこれをやります。

**V4 は補正としても使います。** 各分野の残差から「その自治体の全分野平均残差」を引くと、自治体単位の回答傾向（辛口／甘口）が抜けて、**分野固有の下振れだけ**が残ります。優先度スコアにはこの補正後の残差を使います。

**V1 だけは年度パネルが必要**です（R5〜R7の共通自治体）。取れない場合は V2・V3・V4 の3つで判定します。判定自体は成立しますが、(c)の切り分け精度は落ちます。

### 知りたいこと3：影響の大きさ × 和歌山の凹み で、最優先分野はどこか

**なぜ知りたいか**
単に「主観が低い分野」を選んでも、それが総合幸福度に関係なければ意味がありません。逆に「幸福度に効く分野」でも、和歌山で既に住民が十分満足しているなら改善の余地がありません。**「影響が大きく」かつ「和歌山で下振れしている」分野**こそが最優先ターゲットです。

**使う指標**

| | 指標 | 出どころ |
|---|---|---|
| 影響度 | 回帰係数 **β** | 知りたいこと1 |
| 凹み | **負の残差（2-BのV4で補正済み）** | 知りたいこと2・2-B |

**どう分析するか**

```
優先度スコア  =  影響度  ×  凹みの大きさ
```

**★1点、実装上の注意があります。**
ドミナンス分析の出力は「R²への寄与率（%）」、残差は「偏差値ポイント」なので、**このまま掛け算しても意味のある量になりません**（順位づけには使えますが、大きさの解釈ができない）。

そこで知りたいこと1から**2種類の出力**を取ります。

| 出力 | 用途 |
|---|---|
| **寄与率（%）** | 24分野を1〜24位に順位づけする＝知りたいこと1の答えそのもの |
| **回帰係数 β** | 優先度スコアの掛け算に使う |

`β × |残差|` と定義すると、次のように**解釈できる1つの数字**になります。

> **その分野の主観が全国標準ラインまで回復したとき、総合幸福度が何ポイント上がるか**

単位が揃うので24分野を横並びで比較でき、そのまま**ROIの分子**として使えます。残差を100%埋めるのは非現実的なので、実務では**「残差の30%／50%を埋めた場合」のシナリオ**を併記します。

### 知りたいこと4：最優先分野の「お手本都市」はどこで、何をしているか（2-Bで(a)判定の場合）

**なぜ知りたいか**
最優先分野が決まっても、**具体的にどんな施策（PR・イベント・デジタル化・手続き改善）をやれば主観が上がるのかはデータだけでは分かりません。** 同じような環境下で住民の実感を上げることに成功している都市のやり方を学ぶのが最も確実です。

**使う指標**

| | 指標 |
|---|---|
| マッチング用 | **客観カテゴリスコア**（最優先分野）＋ 人口規模 |
| 選定用 | **残差**（知りたいこと2の出力） |

**どう分析するか**

```
1. 最優先分野の客観カテゴリスコアが 和歌山 ± 3偏差値 の自治体を抽出
2. さらに人口規模が近いものに絞る
3. 残ったグループの中から、残差が大きい順に上位3〜5件
   ＝「客観条件は和歌山と同等なのに、住民の実感が突出して高い自治体」
4. その都市の行政計画・広報施策・Webサービス・住民向け事業を定性調査
```

**この手続きについて正直に書いておきます。**
知りたいこと2の回帰で人口規模は既に統制されているので、残差ランキング上位を取るだけでも「同じ客観条件で主観が高い自治体」にはなります。**統計的にはマッチングは重複した手続きです。**

それでも重ねるのは、**決裁者への説得力のため**です。

> 「和歌山と同じくらいの人口規模で、雇用環境の客観水準もほぼ同じ◯◯市では、住民の実感が和歌山より大きく高い。何が違うのか」

という形にしたほうが圧倒的に伝わります。**統計的な必要ではなくコミュニケーション上の必要**という位置づけです。

**注意**：ガイドブック p.16 に「自治体同士の過度な比較は避け、自身のまちの特徴を読み取ることを主目的としてください」とあります。本分析は**優劣のランキングではなく、施策を学ぶための事例選定**であることを提出資料でも明示します。

**空振りしたときの意味**：お手本都市を調べて「特別なことは何もしていない」だった場合、それは失敗ではなく**(b)の傍証**です。知りたいこと5へ切り替えます。

### 知りたいこと5：環境を上げるとしたら、どのKPIをどれだけ動かせばよいか ★追加（2-Bで(b)判定の場合）

**なぜ知りたいか**

2-Bで**(b)「その環境水準での実力値」**と判定された場合、打ち手は周知ではなく**環境そのものを上げること**になります。しかし「客観_雇用所得を上げる」は施策になりません。**動かせるのは個別KPI**（正規雇用者比率・創業比率など）です。

さらに、**「環境を上げれば主観が上がる」こと自体が自明ではありません。** 以下3点が未検証のままです。

1. 個別KPIのうち、どれが実際に主観と結びついているか
2. **デジタル庁が設定したKPIの符号（高いほど良い／悪い）が、住民の主観と一致しているか**
3. 関係が飽和していないか（すでに頭打ちなら、上げても主観は動かない）

**2 が特に重要です。** 例えば医療・福祉では「人口あたり国保医療費」が**高いほど偏差値が下がる**設定になっています。しかし医療費が高い＝医療にアクセスできている、とも読めます。**符号設定が住民の主観と逆なら、そのKPIを「改善」する施策は主観を下げます。**

**使う指標**

| | 指標 | 個数 |
|---|---|---|
| 目的変数 | 最優先分野の**主観カテゴリスコア** | 1 |
| 説明変数 | 同じ分野の**客観個別KPI** | 1〜24（分野による） |

**どう分析するか**

1. 最優先分野の個別KPIを説明変数にして回帰します。**KPIが10本以上ある分野（デジタル生活24本・自然災害23本など）はLassoで絞ります**
2. **各KPIの符号を確認します。** デジタル庁の設定と住民の主観が一致しているか。**一致しないKPIを『改善』する施策は主観を下げる**ので、提言前に必ず潰します
3. **非線形性を確認します。** 関係が飽和していて、和歌山が既に頭打ちの領域にいるなら、環境を上げても主観は動きません → その分野は降りて次点へ
4. **必要量を逆算します。** 主観カテゴリスコアを+1偏差値上げるには、そのKPIをどこまで動かす必要があるか

**効果の伝播**：

```
KPI（例：正規雇用者比率）を 1標準偏差 改善
  → 主観カテゴリスコアが γ 上がる          （知りたいこと5）
    → 総合幸福度が β × γ 上がる            （知りたいこと1）
```

**現実性フィルタとして機能します**：「総合幸福度を+0.1上げるには、正規雇用者比率を全国3位相当まで上げる必要がある」と出たら、その施策は提案しません。

[2] 下振れ分野の抽出 ─┘                            │

### なぜ 2-B と 5 を追加したか

当初の設計は「客観が高いのに主観が低い ＝ 周知不足 ＝ ソフト施策で安く伸ばせる」という筋書きでした。しかしこれは**同じデータの別解釈を排除していません**。

> 環境があるのに主観が追いついていないのではなく、**「その環境水準では、主観はその程度にしかならない」**という解釈が同じくらい成り立つ。
> であれば、主観を上げるには**環境そのものを動かす**しかない。

**この読みが正しい場合、当初の設計では施策がひとつも出せません。** お手本都市を探しても「特別なことは何もしていない」で終わってしまいます。そこで、

- **2-B** で3つの解釈を切り分ける検証を入れ、
- **5** で「環境を上げる」側の打ち手（どのKPIを、どれだけ）を用意しました

**どちらに転んでも施策が出せる構造**になった点が、この追加の意味です。

### 08-05に西村さんが提案してくれた案との対応

**この設計は西村案を置き換えるものではなく、仮定を減らして実装可能にしたものです。**

| 西村案（08-05） | 本設計での扱い |
|---|---|
| 目的変数＝主観的ウェルビーイング | **そのまま採用**（知りたいこと1の目的変数） |
| 客観が高いのに主観が低い指標に伸び代がある | **仮説としては採用。ただし検証対象に格上げした**（知りたいこと2-B）。→ 下記 3. |
| 優先度スコア＝相関係数 × 差 | **考え方を採用。「差」を「回帰の残差」に、「相関係数」を「β」に置換**（知りたいこと3）。→ 人口規模を統制でき、単位が揃って解釈可能になる |
| 客観プロファイルが似ている市を抽出して比較 | **知りたいこと4として採用**。ただし「似ている」の定義（±3偏差値・人口規模）を明示し、選定は残差で行う |
| 差の要因をWeb資料＋LLMで解析して政策提言に | **そのまま採用**（知りたいこと4の手順4） |

**変えたのは3点です。**

1. **「差」→「残差」**：単純な差だと人口規模や地域特性の影響が混ざるため、回帰で条件を揃えてから比較する
2. **「相関係数」→「β」**：残差と掛け算したときに単位が揃い、「幸福度が何ポイント上がるか」という解釈可能な量になる
3. **「伸び代がある」を前提から検証対象へ**：西村案の中核仮説をそのまま前提にすると、外れていた場合に**施策がひとつも出せません**。知りたいこと2-Bで検証し、外れていた場合は知りたいこと5（環境そのものを動かす）へ回す道を用意しました。**仮説を否定するためではなく、外れたときにも進めるようにするための追加です。**

### 3.3 客観カテゴリスコアはどう作られているか

**雇用・所得**を例にします。

```
ステップ1  和歌山の「完全失業率」を全自治体の中で偏差値化      → 例 43.2
           ※ 失業率は高いほど悪いので符号反転
ステップ2  同じ処理を残り8本にも適用
           正規雇用者比率 → 48.1 ／ 課税対象所得 → 41.5 ／ 創業比率 → 45.0 …
ステップ3  9本を集約して1つの数字にする                       → 客観_雇用所得 = 44.8
```

**偏差値の定義**（p.16）：

```
偏差値 = ±(当該自治体の数値 − 平均値) / 標準偏差 × 10 + 50
        （数値が高いほど悪い状態を表すKPIはマイナスを使用）
```

**50が全国平均、10が1標準偏差。** 44.8なら「平均より約0.5標準偏差ぶん劣位」。

**基準集団**（p.16）— ここは分析に影響します。

| | 基準集団 |
|---|---|
| 客観指標 | **東京23区および人口10万人以上の自治体**。人口10万人未満は上記の平均・標準偏差を適用 |
| 主観指標 | **人口10万人以上かつ回答数100以上の自治体**。それ未満は上記の平均・標準偏差を適用 |

→ **人口10万人未満の自治体の偏差値は「同規模の中での相対位置」ではなく、大都市を基準にした外挿値**です。530自治体には10万人未満が多数含まれるため、人口規模を統制変数に入れたうえで、10万人以上のサブサンプルでも結論が変わらないか確認します。

### 3.4 指標の「質」は分野によって違う ★結果の読み方に影響

#### 主観側：設問数が1問〜5問でばらつく

24分野のうち、**9分野は設問1問だけ**から主観カテゴリスコアが作られています。

> 移動・交通／遊び・娯楽／都市景観／自然景観／環境共生／自然災害／自己効力感／教育機会の豊かさ／事業創造

**含意**：1問由来のスコアは測定誤差が大きくなります。**知りたいこと1で影響度が低く出ても、「効いていない」のか「測れていない」のか区別できません。** 結果表には必ず設問数を併記します。

#### 客観側：KPIの性格が分野によって全く違う

「客観指標」と一括りにできません。**知りたいこと2でR²が低く出る分野は、事前にある程度予測できます。**

|---|---|---|
| 買物・飲食 | 商業施設徒歩圏カバー率・飲食店数 | **高い**（主観設問と対応が明快） |

デジタル庁は各KPIに「高いほど良い／高いほど悪い」の向きを設定しています（悪い場合は偏差値を符号反転）。**しかしその向きが住民の体感と一致している保証はありません。**

| KPI | デジタル庁の設定 | 疑問 |
|---|---|---|
| 人口あたり国民健康保険者医療費 | 高いほど**悪い** | 医療費が高い＝医療にアクセスできている、とも読める |
| 通勤通学に自家用車等を用いない割合 | 高いほど**良い**（公共交通が発達） | 車社会の地方では「車を使えない不便」かもしれない |
| 人口あたり小型車走行キロ | — | 走行距離が長い＝移動が不便、とも、移動が自由、とも読める |

**符号が住民の主観と逆なら、そのKPIを「改善」する施策は主観を下げます。** 知りたいこと5の手順2で全KPIの符号を確認し、提言前に必ず潰します。

#### 客観KPIの調査年は2010〜2025で混在

「自然の恵み」16本は全て2010年、「保育所への距離」「空家率」は2018年。

| 2 | 知りたいこと1（影響度の順位づけ） | 半日 | 攻める分野が絞れる |
| 3 | 知りたいこと2（残差とR²） | 半日 | 下振れ分野が出る |
| **4** | **知りたいこと2-B（V2 → V4 → V3 → V1）** | **半日〜1日** | **(a)(b)(c)の判定。施策の型が決まる** |
| 5 | 知りたいこと3（優先度スコア） | 2時間 | ターゲット分野が確定 |
| 6a | (a)判定なら 知りたいこと4（お手本都市＋定性調査） | 2〜3日 | ソフト施策のアイデアが出る |
| 6b | (b)判定なら 知りたいこと5（KPIの用量反応） | 1〜2日 | ハード施策と必要量が出る |

**山は2つ、手順1と手順4です。**

- **手順1**：ここで「②が低くて①が高い分野」がゼロなら、その時点で路線を組み替える判断ができます
- **手順4はV2から始めます。** 単年データだけで数十分で回り、「そもそも和歌山の残差は他の自治体の散らばりと比べて特別なのか」という最も基本的な問いに答えます。**ここで「1σ以内」と出たら、その分野は(b)であり、お手本都市探しに進んではいけません**
- 6a と 6b は排他ではありません。分野ごとに判定が違えば両方走ります
