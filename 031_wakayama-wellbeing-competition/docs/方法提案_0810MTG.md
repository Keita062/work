## 1. 目的

### 1-1. 何のための分析か

> **和歌山の主観的ウェルビーイング（住民が実際に感じている幸福度・生活満足度）を上げるために、どの分野に、どんな手を打つべきかをデータから決める。**

24分野すべてに均等に予算と人員は割けない。**どこに集中させれば住民の幸福度が最も上がるのかを、感覚ではなくデータで決める。** これがこの分析の存在理由。

### 1-2. 最終的にこう言えるようにする

**分析が終わったとき、次の1文が言える状態になっているのがゴール。**

> 和歌山で最優先に手を打つべき分野は **「雇用・所得」** である。
>
> 理由は3つ。
> ① 生活満足度への効き目が24分野で最大（**係数 0.31**）
> ② 和歌山はこの分野で、客観の水準に対して主観が **16ポイント低い**
> ③ その低さは **改善できる**（他の自治体で、環境を変えずに主観が上がった実績がある）
>
> 打つべき手は **「正規雇用者比率を全国平均まで引き上げる」**。
> これにより **生活満足度が +0.15ポイント** 上がると見込まれる。

※ 分野名と数字は例。**この形の文が出せれば目的を達成したことになる。**

### 1-3. この文の中の数字は、どのステップで埋まるか

**5つのステップは、上の文の空欄を1つずつ埋めるためにある。**

| 上の文のどこ | 埋めるステップ | 出る数字 |
|---|---|---|
| ①「効き目が24分野で最大（係数0.31）」 | **ステップ1** | 分野ごとの係数 β |
| ②「客観に対して主観が16ポイント低い」 | **ステップ2** | 主観と客観の差 |
| ③「その低さは改善できる」 | **ステップ3** ← **空欄だった箇所** | 改善可能かの判定 |
| 「正規雇用者比率を全国平均まで」 | **ステップ4** ← **空欄だった箇所** | KPIの係数 γ と必要量 |
| 「打つべき手は」 | **ステップ5** | 施策の中身 |
| 「+0.15ポイント」 | **ステップ1 × ステップ4** | β × γ |

**①だけだと「分野を指さしただけ」、施策だけだと「他所の真似」に見える。効果量まで出して初めて費用対効果の話ができる。**

【ステップ1】                                     【ステップ2】

                             ▼

              その分野の主観は上げられるのか
                             │
        ┌────────────────────┼────────────────────┐

**分岐はステップ3の1か所だけ。** ここで(a)(b)(c)のどれかが決まらないと、**ステップ4に行くのかステップ5に行くのかが選べない。** だからここが空欄のままでは先に進めなかった。

### 2-2. ステップ一覧

| | 答える問い | 使うデータ | 計算すること | 出る数字 | 次への渡し方 |
|---|---|---|---|---|---|

### 2-3. 最後に優先度を出す

```
政策優先度 ＝ 重要度 × 課題の大きさ × 改善可能性 × 政策介入可能性
                ↑          ↑            ↑             ↑
            ステップ1   ステップ2     ステップ3     ステップ4・5
```

**「重要だから投資する」ではなく、「重要で、いま問題があり、改善でき、行政が介入できる」領域を選ぶ。** 4因子はステップと1対1で対応している。

## 3. ステップごとの手段

---

### ステップ1：24分野のうち、どれが生活満足度に効いているか

> **08-07 MTGで共有したドキュメントの記載**
>
> 進め方1：「主観的ウェルビングの総合スコアに対して、主観的の各カテゴリには何が一番寄与しているのか。」
> 手段：「正則化回帰もしくは主成分回帰」／目的変数「Q1の主観的ウェルビングの中の幸福度もしくは満足度」／説明変数「主観的ウェルビーイングの各カテゴリ」
>
> **残論点：「もしくは」が2か所ある。** ① 正則化回帰か主成分回帰か ② 幸福度か満足度か

#### 目的変数をどちらにするか

**結論：生活満足度（Q4）を主にする。幸福度（Q1）でも同じ分析を回して、結果を並べる。**

| | 設問文 |
|---|---|
| **Q1 幸福度** | 現在、あなたはどの程度幸せですか |
| **Q4 生活満足度** | 住んでいる地域の暮らしに満足している |

**Q4を主にする理由：24分野との対応が取れているから。**

24分野はすべて「**地域の**医療は充実しているか」「**地域の**雇用は」というように、**地域について尋ねた設問**でできている。

- **Q4も「住んでいる地域の暮らし」を尋ねている** → 尋ねている対象が一致する
- **Q1は「あなたが幸せか」を尋ねている** → 個人の健康・家族・収入など、地域と無関係な要因が大きく入る

我々が出すのは県が打てる手なので、**地域の要因で説明できる割合が高い側を主に置く。**

**Q1も回す理由**：テーマ名が「幸福度」なので必要なことに加え、**Q1とQ4で効く分野が違えば、その差が「地域の施策で動く範囲」と「動かない範囲」の切れ目を示す。**

#### 何を使うか

| | 内容 | 個数 | 尺度 |
|---|---|---|---|
| 目的変数 | 生活満足度（Q4）／幸福度（Q1） | 1（＋1） | 0〜10点 |
| 説明変数 | 主観カテゴリスコア（24分野） | 24 | 偏差値 |
| 統制変数 | 年度。年代・性別が取れれば追加 | — | — |

#### どう測るか

**結論：3種類の回帰を回し、予測精度を比べて、いちばん当たったもので分野の効き目を読む。**

**【A】その前に、24分野の相関構造を確認する**

**理由：24分野が互いに強く相関していると、回帰係数の推定が不安定になるから。**

係数 βj が意味するのは「**他の23分野を固定したまま、分野 j だけを1動かしたときの変化量**」。ところが24分野が相関していると、そういうデータが実際にはほとんど存在しない。存在しない状況について係数を推定するので、値が定まらない。

膨らみ方は数式で確認できる。

```
分野 j の係数の分散は、VIF_j 倍になる

VIF_j = 1 / (1 − R²_j)      R²_j ＝ 分野 j を残り23分野で回帰したときの決定係数

  R²_j = 0.5  → VIF = 2   （分散2倍）
  R²_j = 0.9  → VIF = 10  （分散10倍）
  R²_j = 0.95 → VIF = 20  （分散20倍）
```

**分散が膨らむと、係数の符号が反転したり、標本が少し違うだけで値が大きく振れる。** 満足度が高い自治体は多くの分野で高く出るので、24分野で R²_j が 0.8〜0.9 に達する可能性は高い。

**先に相関行列とVIFを見ておかないと、「分野Aが効いている」のか「Aと相関している分野Bが効いている」のかを取り違える。**

**【B】3種類の回帰を回す**

---

**① 正則化回帰（Ridge / Lasso / Elastic Net）**

多重共線性で係数が壊れる問題を、**係数の大きさに罰則を課す**ことで抑える回帰。

```
通常の重回帰 ： 残差二乗和 を最小にする
Ridge       ： 残差二乗和 ＋ λ × Σβj²
Lasso       ： 残差二乗和 ＋ λ × Σ|βj|
Elastic Net ： 残差二乗和 ＋ λ ×( α×Σ|βj| ＋ (1−α)×Σβj² )
```

| | 罰則 | 挙動 |
|---|---|---|
| **Ridge** | 係数の**二乗**和 | 係数を0に近づけるが0にはしない。**相関する分野どうしで効果を分け合う** |
| **Lasso** | 係数の**絶対値**和 | 一部の係数をちょうど0にする＝変数選択。ただし**相関する分野群からは1本だけ残して他を落とす** |
| **Elastic Net** | 両方の混合 | Lassoの変数選択を持ちつつ、**相関する分野群をまとめて残せる** |

**24分野は相関しているので Elastic Net が第一候補。** λ と α は交差検証で決める。

**出るもの：分野ごとの係数 β。**「その分野の偏差値が1上がると、総合スコアが何ポイント上がるか」。

**係数の安定性を確認する（ブートストラップ）**

Lasso / Elastic Net は相関する分野群から一部だけを残すので、**標本がわずかに変わると残る分野が入れ替わる。1回の推定結果を「重要な分野」として提示することはできない。**

```
1. 元データ（自治体 n 件）から、復元抽出で n 件を選び直した標本を作る
2. その標本で Elastic Net を推定する
3. 1〜2 を 1000 回繰り返す
4. 分野ごとに「係数が 0 でなかった回数」を数える
```

- **1000回中 940回** → 標本変動に対して頑健。提言に載せる
- **1000回中 520回** → 偶然と区別できない。載せない

**「なぜこの分野を選んだのか」に数字で答えられるようになる。**

---

**② 階層モデル（マルチレベルモデル／混合効果モデル）**

**何のためのモデルか：データが「自治体ごとにまとまっている」ことを、モデルに組み込むため。**

**問題**：データは「自治体 × 年度」の形になり、同じ自治体の複数年度が別々の行として入る。**同じ自治体の行どうしは互いに似た値になる**（和歌山市の2024年と2025年は近い）。

通常の回帰は「すべての観測が互いに独立」を前提にしている。崩れると、

- **実質的な情報量が行数より少なくなる**（530自治体×3年度＝1590行あっても、独立な情報は1590行分ない）
- にもかかわらず計算上は1590行として扱われるので、**係数の標準誤差が実際より小さく出る**
- 結果、**本当は有意でないものが有意に見える**

**構造**：誤差を2段階に分けて、この相関をモデルに入れる。

```
生活満足度_(自治体 i, 年度 t)
    = β0 + Σ βj × 分野j_(i,t) + u_i + ε_(i,t)

  u_i      ： 自治体 i ごとの切片のズレ（自治体固有効果）   u_i ~ N(0, σ_u²)
  ε_(i,t)  ： 残りの誤差                                    ε   ~ N(0, σ_ε²)
```

**u_i が何を表すかが、このモデルの要。**

**u_i ＝「24分野では説明できない、その自治体だけが持っている水準の高低」。** 地形、気候、歴史、都市構造、交通の便——**観測していない自治体固有の条件が、まとめてここに入る。**

同じ自治体の観測は u_i を共有するので自動的に相関する。その強さは次で測れる。

```
級内相関 ICC = σ_u² / (σ_u² + σ_ε²)

  ICC が大きい → 総合スコアのバラつきの多くが「自治体という単位」で決まっている
  ICC が小さい → 自治体の違いより、同じ自治体内の年度変動のほうが大きい
```

**βj は、u_i を差し引いたうえでの分野の効き目になる。**

**なぜ使うのか（結論）：24分野以外の自治体固有の条件を、一つひとつ特定しなくても差し引けるから。**

08-07に西村さんが挙げた「**病院の数が同じでも、立地や行きやすさが違う**」は、時間で変わらない自治体固有の条件なので **u_i に吸収される。何が潜在的な条件なのかを我々が列挙する必要がない。**

**変量効果と固定効果の違い**（ステップ3で使い分けるので、ここで整理しておく）

| | u_i の扱い | 前提 | 使いどころ |
|---|---|---|---|
| **変量効果**（階層モデル） | 分布 N(0, σ_u²) から来た確率変数として扱う | **u_i が説明変数と相関していない**ことを仮定 | 自治体間の比較情報を残したいとき（**ステップ1**） |
| **固定効果** | 自治体ごとのダミー変数として推定する | u_i と説明変数の相関を**許す**（前提が弱い） | 未観測要因を確実に落としたいとき（**ステップ3**） |

**固定効果のほうが前提は弱いが、自治体間の比較情報を捨てる**（自治体内の変動しか使わない）。ステップ1は自治体間の比較が目的なので変量効果、ステップ3は未観測要因を落とすのが目的なので固定効果。

---

**③ 勾配ブースティング木（XGBoost / LightGBM）**

決定木を多数積み重ねる非線形モデル。**関数の形をあらかじめ指定せずに、非線形性と交互作用を推定できる。**

①②はどちらも「1目盛り上がれば、水準によらず同じだけ総合が上がる」という線形かつ加法的な関係を前提にしている。③はその前提を置かない。見たいのは2つ。

- **逓減（飽和）**：偏差値 35→45 では大きく動くが、55→65 ではほとんど動かない。**「どこに伸び代があるか」に直結する**
- **交互作用**：「雇用・所得が高い」かつ「地域とのつながりが強い」ときだけ大きく上がる

**自治体名は投入しない。** 投入するとモデルが自治体ラベルを記憶し、未知の自治体に汎化しない。

---

**【B'】3つを比べる**

**評価指標**：R² / MAE / RMSE

| 分割 | やること | 何を測っているか |
|---|---|---|
| **GroupKFold（自治体単位）** | 同じ自治体が学習側と評価側にまたがらないよう分ける | **未知の自治体への外挿性能** |
| **時間分割** | 過去年度で学習し、最新年度で評価 | **翌年度への外挿性能** |

**ランダム分割は使わない。** 和歌山市の2024年が学習側、2025年が評価側に入ると、ほぼ同一の情報が両側に存在する。モデルは「和歌山市の値」を覚えているだけで当てられるので、**性能が実力より高く出る。**

**判断基準：③が①②を明確に上回った場合にのみ、「線形・加法モデルでは捉えられない構造がある」と主張する。** 上回らなければ①か②を採用する。

**【C】勝ったモデルから分野の効き目を読む**

**①②が勝った場合**：係数 β をそのまま読む。ステップ3以降の掛け算にそのまま使える。

**③が勝った場合**：**SHAP** で分解する。協力ゲーム理論のシャープレイ値をモデル予測に適用したもので、「ある自治体の予測値が全体平均からどれだけ離れているか」を24分野の寄与に分解する。分解は加法的で、全分野の寄与を足すと予測値と全体平均の差に一致する。

**★SHAPが答えるのは「モデルが予測に何を使ったか」であって、「そこに介入したら何が起きるか」ではない。**「SHAP1位だから手を打てば上がる」とは言わない。**上げられるかどうかはステップ3で測る。**

見るもの：全自治体の平均|SHAP|／和歌山の分解／年度別の順位の安定性／SHAP dependence plot（**逓減の形**）。

#### 何が出るか

| 分野 | β(Q4) | β(Q1) | 1000回中の採用回数 | SHAP順位 | 年度でブレないか | 設問数 | 次へ送るか |
|---|---|---|---|---|---|---|---|
| 例：雇用・所得 | 0.31 | 0.18 | 940回 | 1位 | ブレない | 2 | ○ |

**次へ送る基準は「効き目が大きい × 年度でブレない × 3モデルで結論が揃っている」の3つ。**

**設問数も並べる。** 24分野のうち**9分野は、たった1問の回答からスコアが作られている**（移動・交通／遊び・娯楽／都市景観／自然景観／環境共生／自然災害／自己効力感／教育機会の豊かさ／事業創造）。測定誤差が大きく、係数が0の方向に引っ張られる（希薄化）。**併記しないと、効き目が小さいときに「効いていない」のか「測れていない」のかが区別できない。**

#### 検討して採らなかった案

| 採らなかった案 | なぜ採らないか |
|---|---|
| **相関係数で24分野をランキングする**（08-07に西村さんが提案） | 単相関は「**他の23分野の影響を含んだままの値**」。24分野が相関している以上、**連動している分野が一斉に上位に並ぶ**ので、どれが本体か分からない |
| **通常の重回帰** | **多重共線性があるので係数が壊れる。** VIFの分だけ分散が膨らみ、符号の反転や標本ごとの大きな振れが起きる |
| **主成分回帰を主役にする**（08-07に西村さんが提案） | ★下記 |
| **ドミナンス分析**（鈴木が持ち込んだが撤回） | 「24分野の投入順を全パターン試してR²増分を平均する」手法。順序に依存しない寄与率が出るのは魅力だが、**部分集合が 2²⁴ ＝ 約1,677万通りで厳密計算が不可能** |
| **最初からXGBoostを主役に置く** | 自治体530件に対し説明変数24本では**過学習しやすく、①②が勝つ可能性が十分ある** |
| **データをランダムに学習用と評価用に分ける** | **同じ自治体の別年度が両側に入り、性能が過大評価される** |
| **自治体名をモデルに入れる** | モデルが自治体ラベルを記憶し、**未知の自治体に汎化しない** |
| **目的変数をQ1かQ4の一方に絞る** | **2つで結果が違えば、その差が「地域の施策で動く範囲／動かない範囲」の切れ目を示す** |
| **Q5「5年後の幸福度」を目的変数にする**（08-07に話題に出た） | **任意設問なので実施しない自治体があり欠損する。** 5年後を当てられても打ち手が出ない |

**★主成分回帰を主役にしない理由**

主成分回帰は、24分野を主成分に変換し、上位いくつかの主成分だけを説明変数にする方法。**多重共線性は確かに解消される**（主成分どうしは直交するのでVIFは1）。それでも主役にしない理由は2つ。

**理由1：主成分は目的変数と無関係な基準で選ばれている。** 主成分分析は**説明変数側の分散が大きい方向**を順に取り出すだけで、目的変数との関係を一切考慮しない。総合スコアを説明する情報が第5・第6主成分に入っていても、上位3本で打ち切れば**その情報を捨てる。**（この点だけなら、目的変数との共分散を最大化する PLS回帰 に替えれば改善する。ただし理由2は残る）

**理由2：係数が主成分に対して出るので、分野の識別ができない。** 第1主成分は24分野すべての重み付き和なので、元の分野に戻すと**24分野すべてに薄く分散した重み**になる。「**どの分野に手を打つべきか**」というこの分析の主問いに答えられない。

**ただし、24分野を3グループ（生活環境16／地域の人間関係2／自分らしい生き方6）に集約するのは意味がある。** 分散最大化で機械的に決めた軸ではなく、**デジタル庁の指標設計に基づく事前のグルーピング**なので、「生活環境が効いている」という解釈が成立する。**次元圧縮をやるならこちら。**

#### 決まっていないこと

1. **3グループに集約した分析も並行して回すか。**「大きく言うとどこが効いているか」を先に示せるので発表の導入に向くが、工数は増える
2. **「効き目」を何で示すか。** ①係数 β＝「1目盛り上がると総合が何ポイント」／②説明力の取り分＝「総合の分散の何%を説明しているか」。**ステップ3以降の掛け算には①でないと単位が合わない**が、伝えるには②が直感的。**両方出して使い分けるのが素直**
3. **年代・性別を軸に入れるか**（→ §4-2）

### ステップ2：和歌山では、客観の水準に対してどの分野の主観が低いか

> **08-07 MTGで共有したドキュメントの記載**
>
> 進め方2：「客観の水準に対して、主観的ウェルビングのスコアが下振れているカテゴリは何か。」
> 手段：「数値で確認する。」
>
> **残論点：手段が「数値で確認する」の一言しかない。** 何の数値を、どう並べて、どこからを「下振れ」と呼ぶのかが決まっていない。

#### 何を使うか

主観カテゴリスコア24（偏差値）／客観カテゴリスコア24（偏差値）

#### どう測るか

**結論：分野ごとに単純差を取る。**

```
差_分野j = 和歌山の 主観カテゴリスコア_j − 和歌山の 客観カテゴリスコア_j
```

**主観・客観ともに偏差値（平均50・標準偏差10）なので、そのまま引き算ができる。**

- **差がマイナス** → 客観の水準に対して、住民の実感が追いついていない
- **差が −10** → 客観より主観が **1標準偏差ぶん** 低い

24分野を差の小さい順に並べれば、**下振れ分野のランキングがそのまま出る。**

**あわせて、分野ごとに「主観と客観の相関係数」を全自治体で計算する。**

**これは分野の足切りに使う。** 相関がほぼ0の分野は、**そもそも客観指標が住民の体感を測れていない**ので、差を見ても意味がない。

**相関が低くなる分野は事前に予測がつく。**

| 分野 | 客観KPIの中身 | 相関の予測 |
|---|---|---|
| 買物・飲食／雇用・所得 | 施設カバー率・失業率・所得など**標準的な統計値** | **高い** |
| 都市景観／自然景観／環境共生／多様性と寛容性 | **受賞・条例・宣言の「有無」が過半** | **低い** |

「SDGs未来都市に選ばれたか」は行政の行動であって住民の体感ではない。**こういう分野を「なんとなく違う気がする」ではなく、相関係数という数字で機械的に落とせる。**

#### 何が出るか

| 分野 | 主観 | 客観 | 差 | 主観↔客観の相関 | 下振れか |
|---|---|---|---|---|---|
| 例：デジタル生活 | 37.1 | 53.2 | **−16.1** | 0.62 | ○ |
| 例：自然景観 | 51.8 | 67.4 | **−15.6** | 0.11 | **相関が低いので降りる** |

#### 検討して採らなかった案

| 採らなかった案 | なぜ採らないか |
|---|---|
| **客観の総合スコアと主観の総合スコアを直接比べる** | **客観側に総合スコアが存在しない。** 幸福度・生活満足度は主観アンケート4問だけで構成されている。**必ず24分野を経由するしかない** |
| **優先度スコア＝相関係数 × 差**（08-05の西村案） | 考え方は採用するが、**相関係数と偏差値ポイントを掛けても単位のある量にならない**（順位づけには使えるが大きさが解釈できない）。**「相関係数」をステップ1の係数βに置き換えると、「その分野が全国標準まで回復したとき総合が何ポイント上がるか」という読める数字になる** |
| **ステップ1で重要だった分野に絞ってから差を出す** | 絞ると、**ステップ3で係数βと掛け合わせるときに情報が落ちる。** 24分野すべてで計算しても手間はほぼゼロ |

#### 決まっていないこと

1. **人口規模の影響をどう扱うか。** 単純差には人口規模の効果が入ったまま残る。
   **確認方法**：全自治体で「差」と「人口」の相関を見る。**ほぼゼロなら単純差のままでよい。** 相関があれば、主観を客観と人口で回帰した予測値からのズレ（残差）を使う
2. **主観と客観で偏差値の基準集団が違う点。** 客観は「東京23区および人口10万人以上の自治体」、主観は「人口10万人以上かつ回答数100以上の自治体」を基準に計算されている。基準の集合が違うので、「主観の50」と「客観の50」が同じ意味とは限らない。
   **確認方法**：全自治体で「主観 − 客観」の平均を取る。**0付近ならズレは無視できる。** 大きく偏っていたら、その偏りを引いてから比べる
3. **相関係数の足切りラインをいくつにするか。** 先に決めておかないと、後から都合よく決めたように見える

### ステップ3：その分野の主観は、実際に上げられるのか ★空欄①

> **08-07 MTGで共有したドキュメントの記載**
>
> 進め方3：「そのカテゴリの主観的なウェルビングのスコアをあげることはできるのかできないのか。」
> ※ 共有ドキュメントでは3と4が1項目にまとまっている
> 　「※潜在的に考えられないもの（潜在変数）も考慮した上で。」
> 　手段 → **（空欄）**
>
> **残論点：ここが最大の空欄。** 08-07に「**あげることができるのかできないのかを、どうやって判断するんだろう。判断基準が難しいよね**」となり、「**ここで回答を出すのはやめましょう、各々考えて提案を持ってきた方がよさそう**」で持ち帰りになった箇所。**このステップがその宿題への回答。**

#### 何を判定するのか

**結論：ステップ2で出た「マイナスの差」を、3つのうちどれなのかに仕分ける。**

| | 読み | 打ち手 |
|---|---|---|
| **(a)** | 環境はあるが**届いていない** | 周知・利用促進（**ソフト**）→ ステップ5 |
| **(b)** | **その環境水準での実力値**。この客観水準なら住民はこの程度しか感じない | 環境そのものを上げる（**ハード**）→ ステップ4 |
| **(c)** | **ノイズ**。回答者100人前後の誤差、または客観KPIと主観設問が別物 | **その分野は降りる** |

**なぜ仕分けが必要か：3つで打ち手がまったく違うから。仕分けずに施策の型は選べない。**

08-05に出た「客観が高く主観が低い＝伸び代がある」という読みは、**(a)を暗黙の前提にしている。** これは論証されていない仮定で、**外れていた場合に施策がひとつも出せなくなる。**

#### どう測るか

**結論：「差が大きいか」ではなく「その分野の主観がそもそも動くのか」を測る。**

**3-1. その分野の主観は動くのか（分散分解）**

複数年度のデータで、分野ごとに主観カテゴリスコアの分散を2つに分ける。

```
between分散 ： 自治体どうしの差     ＝ 構造で決まっている部分
within分散  ： 同じ自治体の年次変動 ＝ 動いた部分
```

**within分散が大きい分野 ＝ 主観が動きうる分野。ほぼゼロ ＝ 何をしても動かない分野。**

**★ただしこのままでは使えない。within分散には、回答者数由来の誤差が丸ごと乗っているから。**

主観カテゴリスコアは回答者100人前後の平均から作られている。標本平均の分散は「母分散 ÷ 回答者数」なので、**回答者が少ない自治体ほど年ごとにブレる。** これを「動いた」と読むと、**ただのブレを伸び代と呼ぶことになる。**

**対処：誤差ぶんを差し引く。** 各自治体の年次差分の2乗を、回答数の逆数に回帰する。

```
(主観_t − 主観_{t−1})²  =  α  +  λ × (1/n)  +  誤差

  n         ： その自治体の回答者数
  λ × (1/n) ： 回答者数で説明できるブレ ＝ 測定誤差
  α         ： 回答数によらず残る「本当に動いた分」
```

回答者数が多い自治体ほどブレが小さくなるはずなので、この形で分離できる。

- **α ≒ 0** → その分野の主観は動いていない
- **α が大きい** → 動く余地が実在する

**全自治体のデータを使うので、和歌山1件のブレに引きずられない。**

**3-2. 動いた分は客観で説明できるのか（固定効果パネル）**

```
Δ主観カテゴリ_(i,t) = γ × Δ客観カテゴリ_(i,t) + 年ダミー + ε
```

**差分を取ることで、自治体固有効果 u_i が消える**（時間で変わらないものは引き算で消える）。ステップ1で変量効果を使ったのに対しここで固定効果を使うのは、u_i と説明変数の相関を許したいから。

**3-3. 2つを組み合わせて仕分ける**

| 3-1（動くか） | 3-2（客観で説明できるか） | 判定 | 次へ |
|---|---|---|---|
| 動く（α大） | **γが小さい**（客観と無関係に動いている） | **(a)** 客観の外に主観を動かす要因がある | **ステップ5** |
| 動く（α大） | **γが有意** | **(b)** 主観は客観に連動して動く | **ステップ4** |
| 動かない（α ≒ 0） | — | **(c)** 降りる | 次点の分野へ |

**(a)判定が出た場合、それは「周知・運用で主観が動きうる」ことの実データ上の証拠になる。**「客観がほとんど動いていないのに主観が動いた自治体が実在する」と示せるので、**08-05に出た「客観が高いのに主観が低い＝伸び代」という仮説に、はじめて裏付けが付く。**

#### 検討して採らなかった案

| 採らなかった案 | なぜ採らないか |
|---|---|
| **マイナスの差をそのまま「伸び代」と読む**（08-05の西村案／当初の設計） | **論証されていない仮定。** 同じ数字から(b)と(c)が同じくらい成り立つ。**外れていた場合に施策がひとつも出せなくなる**ので、前提ではなく検証対象に格上げする |
| **客観KPIに閾値を決めて「この閾値より上なら十分にある」と判定する**（08-07に西村さんが出した案） | **閾値の根拠が我々の主観になる。**「病院が何施設あれば十分か」を我々が決めた瞬間、提言全体がその決めに依存する |
| **「人口は増えない」「土地は変えられない」を我々の判断で固定変数にする**（08-07に議論） | 08-07に「**我々の考えで人口を固定するのはやりたくない**」と話した件。**固定効果を使えば決める必要がなくなる。** 時間で動いていない変数は差分で自動的に消えるので、**判断をデータに委ねられる** |
| **within分散をそのまま「動いた」と読む** | **回答者100人前後のサンプリング誤差が丸ごと乗る。** 標本平均の分散は「母分散 ÷ 回答者数」なので、回答者が少ない自治体ほど大きくブレる |
| **単年のデータだけで判定する** | 横断データでは「その分野が動くか」を測れない。**動くかどうかは、動いた実績を見るしかない** |
| **和歌山だけを見て判断する** | n=1なのでブレと本物を区別できない。**全自治体で α と γ を推定してから和歌山を当てはめる** |

#### 決まっていないこと

1. **客観カテゴリスコアが年度で本当に動いているか。** 客観KPIの調査年は2010〜2025で混在しており（「自然の恵み」16本は全て2010年）、**同じ値が使い回されている可能性がある。** その場合 Δ客観 がほぼゼロになり **γ が推定できない。データを落とした直後に最初に確認する**
2. **γ が推定できなかった場合の代替。** 3-1だけで(c)を落とし、(a)(b)の切り分けは横断データに落とす（全自治体の「差」の分布に対して和歌山が何σ外れているか）。**精度は落ちるが成立する。** これで妥協していいか
3. **α の閾値をどこに置くか**
4. **年度が何年分取れるか。** 令和4年度は設問数が違う（160問 vs 50問）うえ、回答数100以上の団体が71しかないので使えない。**実質3時点になる見込み**

### ステップ4：上げるとしたら、どのKPIをどれだけ動かすか ★空欄②

> **08-07 MTGで共有したドキュメントの記載**
>
> 進め方4：「できないなら客観的ウェルビングのなにをあげたほうがいいのか」／「潜在的に考えられないもの（潜在変数）も考慮した上で。」
> 手段 → **（空欄）**
>
> **残論点**：空欄なのに加えて、**「潜在変数も考慮した上で」という条件だけが付いている。** 08-07に西村さんが「**その潜在変数を何にするのかっていうのは結構大切そうですね**」と言った箇所。**何を潜在変数と呼び、どう扱うかが決まっていない。**

#### 潜在変数をどう扱うか

**結論：「潜在変数」と呼ばれているものは4種類あり、それぞれ扱いが違う。分けてから対処する。**

| | 中身 | 例 | 扱い |
|---|---|---|---|
| **(i) 時間で変わらない未観測要因** | その自治体固有の、データに無い条件 | 地形、気候、歴史、都市構造、病院までの行きやすさ | **固定効果で消す。特定する必要がない** |
| **(ii) 時間で変わる共通要因** | 全国一律にかかる外部環境 | コロナ、物価高 | **年ダミーで消す** |
| **(iii) 構成概念としての潜在変数** | 複数の観測項目の背後にある概念 | 「地域とのつながり」＝信頼／活動参加／相談相手／助け合い／愛着 | **確認的因子分析（CFA）／SEM** |
| **(iv) 未観測だが取得できる変数** | いま手元に無いだけで、作れば観測できる | 病院までの実移動時間、駅・バス停の密度 | **GIS等から作って説明変数に足す。潜在変数ではない** |

**西村さんが挙げた「病院の数が同じでも、立地や行きやすさが違う」は (i)。** 一つひとつ特定するのは不可能だが、**差分を取れば時間で変わらないものは全部消える。「特定する」のではなく「消す」ほうが確実。**

**(i) と (iii) は別物。** (iii) は複数の観測項目から統計的に識別できる。(i) は観測項目が無いので識別できない。**「データに無い未知の要因をAIが潜在変数として発見してくれる」ということはない。**

#### 何を使うか

目的変数＝最優先分野の主観カテゴリスコア／説明変数＝**同じ分野の客観個別KPI**（1〜24本、分野による）

**24分野の集約偏差値では「客観_雇用所得を上げる」までしか言えない。** 動かせるのは個別KPI（正規雇用者比率・創業比率・完全失業率など全208本）なので、そこまで降りる。

#### どう測るか

```
最優先分野の主観カテゴリスコア = Σ γ_k × 客観個別KPI_k + 統制変数 + ε
```

| 手順 | やること | 注意 |
|---|---|---|
| 1 | 個別KPIを説明変数に入れて回帰 | **KPIが10本以上ある分野はLassoで絞る**（デジタル生活24本／自然災害23本／自然の恵み16本／環境共生16本） |
| 2 | **各KPIの符号が住民の主観と一致しているか確認** | ★下記 |
| 3 | **逓減・飽和を確認** | 和歌山が既に頭打ち領域なら、上げても主観は動かない → 次点へ |
| 4 | **必要量を逆算** | 主観カテゴリスコアを+1偏差値上げるにはKPIをどこまで動かすか |

**手順2は提言前の必須チェック。** デジタル庁は各KPIに「高いほど良い／悪い」を設定して偏差値を符号反転しているが、**その向きが住民の体感と一致している保証がない。**

| KPI | デジタル庁の設定 | 疑問 |
|---|---|---|
| 人口あたり国民健康保険者医療費 | 高いほど**悪い** | 医療費が高い＝医療にアクセスできている、とも読める |
| 通勤通学に自家用車等を用いない割合 | 高いほど**良い** | 車社会の地方では「車を使えない不便」かもしれない |

**符号が住民の主観と逆なら、そのKPIを「改善」する施策は主観を下げる。**

#### 何が出るか

```
KPI（例：正規雇用者比率）を 1標準偏差 改善
  → 主観カテゴリスコアが γ 上がる          （ステップ4）
    → 主観総合スコアが β × γ 上がる        （ステップ1）
```

**これが現実性フィルタになる。**「生活満足度を+0.1上げるには正規雇用者比率を全国3位相当まで上げる必要がある」と出たら、その施策は提案しない。「全国平均まで上げるだけで+0.15」なら提案できる。

#### 検討して採らなかった案

| 採らなかった案 | なぜ採らないか |
|---|---|
| **24分野の集約偏差値のまま施策を書く** | 「客観_雇用所得を上げる」は**施策になっていない** |
| **208本のKPIを一度に投入する** | 標本数に対して変数が多すぎて過学習し、係数が解釈できない。**分野を1つに絞ってから入れる** |
| **デジタル庁が設定したKPIの符号をそのまま信じる** | 向きが住民の体感と一致している保証がない。**符号が逆なら、改善施策が主観を下げる** |
| **「データに無い未知の要因をAIに潜在変数として発見させる」** | **観測項目から識別できる構成概念(iii)と、観測項目が無い未観測要因(i)は別物。** 後者はどんな手法でも識別できない |
| **潜在変数を特定してから都市間比較の前提にする**（08-07の西村さんの懸念への対処案） | 懸念自体は正しいが、**自治体固有の条件を一つひとつ特定するのは不可能。** 差分を取れば全部消えるので、そちらが確実 |
| **横断データで「客観KPI → 主観 → 総合」の因果を主張する** | 横断なので向きは仮定でしかない。**主張は「効果推定」ではなく「優先順位づけ」に限定する** |

#### 決まっていないこと

1. **CFA／SEM をやるか。** **設問単位の回答が取れないと回せない。** ダッシュボードから取れるのが分野ごとの集約偏差値だけなら、(iii)は扱えない。**まず取れるかを確認してから決める**
2. **GIS・地理データ（(iv)）をどこまで取りに行くか。** 差別化には効くが工数が増える。**8月中に分析を終える制約と両立するか**
3. **KPIの符号がデジタル庁と逆だった場合、どう発表するか。** 指標そのものへの批判になるので言い方を決めたい

### ステップ5：具体的にどんな施策を打つか

> **08-07 MTGで共有したドキュメントの記載**
>
> 進め方5：「そのソリューションを考える。」
> 手段：「うまくいっているところの施策とうまくいっていない施策で今回の主観的ウェルビーイングを向上するために使えるか使えないかを判断する。」
>
> **残論点：「うまくいっているところ」の定義がない。** どの数字がどうなっている自治体を「うまくいっている」と呼ぶのかが決まっていない。08-07に西村さんが「**これも主観的にやったらダメ**」と言った箇所。

#### 何を出すのか

**結論：可動レバー（実際に行政が動かせるもの）まで降りた施策を出す。**

**カテゴリ名をそのまま施策にしない。**「地域とのつながりが重要なので、地域とのつながりを高める」は**政策になっていない。**

```
地域活動への参加障壁を下げる  →  地域活動参加  →  地域とのつながり  →  幸福度
      （施策）                 （可動レバー）    （主観カテゴリ）      （総合）
```

年代別の結果が取れれば、「20〜30代で特に重要」→「**若年層向けに、自治会加入を前提としない短時間・単発型の地域交流機会を増やす**」まで降ろせる。

#### どう測るか（「うまくいっているところ」の定義）

**結論：「主観が高い自治体」ではなく「主観が改善した自治体」を探す。**

**単年で主観が高い自治体を取ると、もともと恵まれていた自治体が並ぶ。** そこの施策を真似ても和歌山では効かない。

```
客観カテゴリスコアがほとんど動いていないのに、
主観カテゴリスコアが大きく上がった自治体
　＝ 環境を変えずに住民の実感を上げることに成功した自治体
```

**これなら「何をしたか」が施策として実在するはず。** ステップ3の計算をそのまま流用できるので、追加の手間はほぼゼロ。

| 順 | やること |
|---|---|
| 1 | 上記の条件で候補自治体を抽出 |
| 2 | 人口規模・客観水準が和歌山と近いものに絞る |
| 3 | 行政計画・広報・Webサービス・住民向け事業を **Web資料＋LLMで定性調査**（08-05に西村さんが提案した手順そのまま） |
| 4 | **施策の実施時期が特定できたら、主観スコアの推移と重ねる** |

**手順4まで行けたら強い。**「2024年にこの施策を始めた自治体で、翌年に主観スコアがジャンプした」という図が1枚出せれば、相関の話が一段上がる。

**空振りしたときの意味も決めておく。** 調べて「特別なことは何もしていない」だったら、それは失敗ではなく**(b)判定の傍証。** ステップ4に切り替える。**どちらに転んでも施策が出る構造**になっているのが、この設計の狙い。

#### 検討して採らなかった案

| 採らなかった案 | なぜ採らないか |
|---|---|
| **主観が高い自治体を「お手本都市」にする** | **もともと恵まれていた自治体が並ぶ。** そこの施策を真似ても和歌山では効かない。「高い」ではなく「**改善した**」で選ぶ |
| **カテゴリ名をそのまま施策にする** | 「地域とのつながりを高める」は**政策になっていない** |
| **施策アイデアを2人のブレストで出す** | 08-07に西村さんが言った通り「**これも主観的にやったらダメ**」。実在する自治体の施策から持ち帰る |
| **感度分析を行う** | **06-23に不要と判断済み。** ROI算出のストーリーに吸収されるため |
| **人口規模・客観水準でのマッチングを「統計的に必要」と説明する** | ステップ3で自治体固有の条件は既に差し引かれているので**統計的には重複した手続き。** それでも重ねるのは「和歌山と同じくらいの規模で客観水準もほぼ同じ◯◯市では」という形にしないと伝わらないから。**統計上の必要ではなくコミュニケーション上の必要**と正直に書く |
| **自治体の優劣ランキングとして提示する** | ガイドブックに「自治体同士の過度な比較は避け、自身のまちの特徴を読み取ることを主目的としてください」とある。**施策を学ぶための事例選定であることを明示する** |

#### 決まっていないこと

1. **(a)判定が1分野も出なかったらどうするか。** 全分野が(b)か(c)だと、提言は「環境投資しかない」になる。**それは和歌山県が実行できる提言なのか。** 08-05に「職種で切ると実行できない提言になる」と言ったのと同じ問題が別の形で戻ってくる
2. **定性調査をどこまでやるか。** 3〜5自治体×行政計画を読むのは工数が重い。LLMにどこまで任せるか
3. **ROIの分母（施策費用）をどう取るか。** 施策単位の予算が公開されているとは限らない

**08-07に共有したドキュメントのWBSは県ベースで書かれている**（「和歌山県のQ1」「他県の主観／客観」）ので、**明示的に上書きが要る。**

**要確認**：和歌山県内で回答数100以上の自治体が何件あるか。人口10万人以上は和歌山市のみとみられ、**県内比較ができるかがここで決まる。**

### 4-2. 年代・性別を軸に入れるか

**入れられれば、ステップ1で「誰にとって重要か」が測れ、ステップ5の施策が「若年層向けに」まで降りる。**

ただし**令和7年度に追加された属性データはダッシュボードに未反映**という記載がある。3分岐になる。

| ダッシュボードの状態 | 分析単位 | できること |
|---|---|---|
| 年代×性別のクロス集計が取れる | 自治体 × 年度 × 年代 × 性別 | **「誰に効くか」が実測で言える** |
| 年代・性別が独立フィルタのみ | **年代分析と性別分析を分離する** | 混ぜると同じ回答者が重複して入るため |
| 属性が取れない | 自治体 × 年度 | 年代別は不可。**人口構成による直接標準化**で近似（下記） |

**属性が取れない場合の代替**：全国平均の属性別スコアは公表されている（40代が谷、70代以上が山、女性>男性）。これと和歌山の人口構成で標準化する。

```
期待される主観総合 = Σ（和歌山の属性別人口構成比 × 全国平均スコア）
実測 − 期待 = 人口構成では説明できない「和歌山固有」の低さ
```

**固有分がほぼゼロなら、施策の主張が根本から変わる**（高齢化構成の問題であって政策の問題ではない、という結論になる）。**計算は数十分。属性データの有無にかかわらず早期に回す価値が高い。**

**アクション**：デジタル庁への属性データ照会は、**決める前に送っておけばいい**（返答待ちが発生するので早い方がいい）。
