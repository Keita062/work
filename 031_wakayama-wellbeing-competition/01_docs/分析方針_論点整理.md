## 3. 経緯 — なぜこの決定が必要になったか

### 08-05に西村氏が提示した「仕事に着目するのをやめた方がいい」理由

1. **公開データに「都道府県 × 職種」単位のウェルビーイング値が存在しない。** 目的変数が取れない以上、機械学習も統計処理も成立しない
2. **目的変数を自分たちで推論・合成してから回すのは信憑性がない。** 重回帰で係数を決めてWB値を作っても、それは自分たちが作った結果でしかない。生成AIでのデータ合成も、目的変数が分からない以上は不可
3. 都道府県単位のWB値は存在するが、**職種の違いを考慮できず提案が抽象的になり、和歌山県が実行できない提言になる**

### 西村氏の代替案（08-05提示）

1. 目的変数 = 主観的ウェルビーイング
2. **客観的WBが高いのに主観的WBが低い指標には伸び代がある**という仮説
3. 横軸＝客観と主観の差、縦軸＝主観的WBとの相関、の2次元散布図に24指標をプロット。**右上（差が大きく相関も高い）の指標に着目**。優先度スコア＝相関係数×差
4. **客観プロファイルが似ている市を抽出**し、主観が高い「成功している市」と和歌山を比較。差の要因をWeb資料＋LLMで解析して政策提言にする

西村氏本人が「これで進めようという話ではなく、提案の1つとして受け取ってほしい」と述べている。**確定方針ではない。**

### 4.2 偏差値の定義と基準集団 ★ここが効く

```
偏差値 = ±(当該自治体の数値 − 平均値) / 標準偏差 × 10 + 50
（数値が高いほど悪い状態を表すKPIはマイナスを使用）
```

| | 基準集団 |
|---|---|
| **客観指標** | **東京23区および人口10万人以上の自治体**の数値をベースに算出。**人口10万人未満の都市は、上記都市の平均値と標準偏差を適用**して算出 |
| **主観指標** | **人口10万人以上かつ回答数100以上の自治体**をベースに算出。人口10万人未満または回答数100未満は、上記の平均値と標準偏差を適用 |

**含意**：人口10万人未満の自治体の偏差値は「同規模自治体の中での相対位置」ではなく、大都市を基準にした**外挿値**。和歌山県内で人口10万人以上は和歌山市のみ（約35万人）とみられ、**県内の他市町村はすべて外挿**になる。→ D5（分析単位）と§5-Q4（似ている市の比較）に直撃する。

ガイドブック自身も「自治体同士の過度な比較は避け、自身のまちの特徴を読み取ることを主目的としてください」と明記している。**比較を軸に据える設計は、指標の設計思想とややズレる**点は自覚しておく。

## 5. 論点 — 西村案への引っかかりと、その潰し方

08-05のMTGで鈴木が言語化できなかった違和感を4つに分解したもの。**MTGではこの順で出す。**

### Q1. 「差」が何を意味しているのかが1つに決まっていない

客観偏差値と主観偏差値の差が生まれる原因は少なくとも3種類ある。

| 差の正体 | 中身 | 施策の余地 |
|---|---|---|
| **(a) 実態のズレ** | 環境は整っているのに住民に届いていない・使われていない・知られていない | **ある**（西村案が想定しているのはこれ） |
| **(b) 測定のズレ** | 客観KPIと主観設問がそもそも別のものを測っている | ない |
| **(c) 期待水準のズレ** | 主観は「自分の期待に対してどうか」の相対評価 | ない |

**(b)が想像以上に効いている可能性が高い**（§4.4より）。具体例：

- 医療・福祉の客観8KPIのうち2つは**人口あたり国保医療費・後期高齢医療費で符号反転**（高いほど偏差値↓）。住民は医療費の多寡で「医療機関が充実している」とは答えない
- 環境共生の客観16KPIのうち10個が**SDGs未来都市・ゼロカーボン表明等の「表明・採択の有無」**。行政の行動であって住民の体感ではない
- 多様性と寛容性も客観11KPIのうち6個が**条例の有無**。主観は「どんな人の意見でも受け入れる雰囲気がある」
- 都市景観・自然景観はほぼ全部が**受賞・指定の有無**

**潰し方**：24指標を同じ土俵に乗せず、**全国530自治体で客観↔主観の相関を見て、対応していないカテゴリを機械的に落とす**。主観的な足切りに見えるが、相関という客観基準で落とせる。

### Q2. 因果の向きを認めた瞬間に、打ち手がデータの外に出る ★最重要

ガイドブックp.5-7で**デジタル庁自身が「客観指標＝暮らしやすさ（アウトプット）→ 主観指標＝幸福感（アウトカム/インパクト）」というロジックモデル**を明示している。よって「客観が原因側、主観が結果側」という西村氏の整理は**設計思想として正しい**。鈴木が08-05に言った「主観こそ真のWBで客観は裏付け」は取り下げてよい。

ただしその因果を認めると、こうなる。

- **客観→主観の因果を認めるなら、主観を上げる打ち手は「客観を上げること」**。しかし「差が大きい指標」は既に客観が高いので、上げる余地が小さい
- **「差」に着目するなら、打ち手は客観の外側**（運用・周知・使いやすさ・住民の認知）にある。しかしそれは24指標のどこにも入っていない

つまり**分析で選んだ指標に対して、施策は分析の外側から持ってこないといけない構造**。西村氏が「成功している市の要因をWeb資料からLLMで解析する」と言ったのは、この外側を取りに行く話であり認識としては正しい。だが結果として**分析パートは「どこを見るか」を決めるだけで、提言の中身は定性調査が担う**ことになる。

**潰し方（§6-B）**：**「客観がほとんど動いていないのに主観が動いた自治体」を年度パネルで全国から探す。**
- 見つかれば → 「客観の外側の要因で主観は動く」がデータで示せ、外側から施策を持ってくる正当性が立つ。**西村案の最大の弱点が最大の武器に変わる**
- 見つからなければ → 「差」に着目する路線自体を撤回する材料になる

**どちらに転んでも判断材料になるので、これを最優先で回す。**

### Q3. 提案から「人」が消えている

当初のRQには**「地域の就労者の」**という主語があった。新案は「和歌山市の24指標のうち差が大きく相関が高いものを選ぶ」で、**市町村平均値しか使わないため原理的に「どの層に効くか」が言えない**。

応募要件が「データから得られるエビデンスに基づく施策提案かつ応募者が発案したオリジナルなもの」である以上、**「誰に効くか」が言えない提案は弱い**。08-05に「決裁者が納得する気がしない」と言った根はここ。

**潰し方**：
- ガイドブックp.11の記載を根拠に**属性データを照会**（D6）
- 取れなくても、§4.3の**全国平均の年代別・性別の傾向**（40代が谷・女性>男性）と和歌山県の年齢構成を突き合わせれば、層の議論の入口にはなる

### Q4. 「似ている市」の成立条件が示されていない

「客観プロファイルが似ている＝同じポテンシャル」は前提として重い。

- **偏差値の基準集団は人口10万人以上＋東京23区**（§4.2）。人口10万人未満は外挿値。和歌山県内で基準集団に入るのは和歌山市のみとみられる
- 客観KPIの調査年が2010〜2025でバラバラ。**時点の揃っていないベクトルで「似ている」を測っている**
- 「似ている」の定義（距離・重み）で結論が変わる
- ガイドブック自身が「自治体同士の過度な比較は避けよ」と書いている

**潰し方**：**マッチング（似た市を探す）をやめて回帰の残差にする。** 全国530自治体で `主観偏差値 ~ 客観偏差値` をカテゴリごとに回帰し、和歌山市の残差を見る。「客観条件を揃えたうえで主観がどれだけ低いか」が1つの数字で出て、**「似ている」の恣意性が消え、n=530を全部使える**。西村案と狙いは同じで仮定が少ない。人口規模は統制変数に入れる。

## 6. 分析案

### A. 全国530自治体で「客観条件を揃えた主観の残差」を出す（土台）

西村案の「差」と「似ている市の抽出」を1本の回帰に統合する。

1. カテゴリごとに `主観偏差値 ~ 客観偏差値 (+ 人口規模)` を全国530自治体で回帰
2. 決定係数を見て、**客観↔主観の対応が取れていないカテゴリを機械的に落とす**（Q1の足切りがここで済む）
3. 残ったカテゴリで和歌山県内自治体の**残差**を算出
4. 残差が**総合幸福度Q1／生活満足度Q4にどれだけ効くか**を見る

- 買えるもの：西村案の狙いを仮定を減らして実行。「似ている市」の定義問題が消える
- コスト：低（データさえあれば1日）
- **前提**：全国530自治体×24カテゴリの主観・客観偏差値が入手できること（§4.5）

### B. 4年度パネルで「客観が動いていないのに主観が動いた自治体」を探す（勝負どころ）

Q2の決着に必要。**方針の生死を分ける検証。**

1. R4〜R7の4時点で自治体×カテゴリの主観偏差値の変化量を出す
2. 同期間の客観偏差値の変化量と突き合わせる
3. **客観がほぼ横ばいなのに主観が有意に動いた自治体**を抽出
4. その自治体がその期間に何をしたかをWeb資料＋LLMで定性調査

- 買えるもの：「客観の外側の要因で主観は動く」の実証。和歌山への提言が根拠のある打ち手になる
- コスト：中（年度別データの取得＋自治体の名寄せ）
- **制約（重要・先に明記する）**：各年度で回答者が違うインターネットモニター調査で母集団構成比を考慮していない。主観の変化が「実態の変化」か「回答者構成の変化」かは切り分けられない。変化幅が大きいものだけを扱う等の防御が必要
- **制約2**：客観KPIの調査年が2010〜2025で混在しており（§4.4）、そもそも「客観の年次変化」がほとんど無い可能性がある。**これは事前に確認が必要**（もし客観がほぼ全自治体で不変なら、この設計自体が「客観一定・主観変動」の自明な結果になる）
- **制約3**：対象自治体がR6 684→R7 530に減少。R4は160問版で設計が異なる。接続可能性は要検証

### C. 「雇用・所得」を軸に当初RQを救う

**「仕事に着目する」路線は完全には死んでいない。** 24カテゴリの1つに**雇用・所得**があり、主観・客観の両方が揃っている。

- 主観2問：「やりたい仕事を見つけやすい」「適切な収入を得るための機会がある」
- 客観9KPI：完全失業率／若年層完全失業率／正規雇用者比率／高齢者有業率／高卒者進路未定者率／市区町村内で従業している者の割合／創業比率／納税者あたり課税対象所得／人口あたり生活保護受給者数
- 隣接：事業創造（主観1・客観8）、教育機会の豊かさ（主観1・客観7）

**やること**：全国530自治体で「雇用・所得」の主観が総合幸福度Q1・生活満足度Q4にどれだけ効いているかを、他23カテゴリと並べて順位づけする。

- 買えるもの：06-23からの宿題**「なぜ仕事なのか」にデータで答えが出る**。効いていれば当初RQの正当性が立ち、効いていなければ潔く撤退できる。**職種別ができないというだけで「仕事」自体を捨てるのは早い**という主張の根拠
- コスト：低（Aとほぼ同じ計算で出る）
- 補足：SSDSE 03テーマ（業種別完全失業率のLCA）と地続きで、完全失業率まわりの知見を持ち込める

### D. 「なぜ和歌山か」をデータで埋める（発表の導入・必須）

06-23で宿題になったまま止まっている論点。24指標の偏差値レーダーで和歌山の凹凸を出す。

- 特に**自然災害の客観23KPI**（外水氾濫・高潮・土砂災害・地震動・津波＋避難救助・要配慮者支援）は、南海トラフと土砂災害を抱える和歌山で全国でも尖った位置に出る可能性が高く、「なぜ和歌山を対象にするか」の答えになりうる
- 分析としては軽いが**8/17の内定者研修発表にはこれが要る**ので優先度は高い
- **和歌山市単体なら手作業転記でも作れる**ため、§4.5が解けなくても実行可能

### E. 属性データの照会（並行して仕込む）

ガイドブックp.11「令和7年度は研究者等も活用できるように属性データを追加した／ダッシュボードには現時点では反映されていません」を根拠にデジタル庁へ問い合わせる。

- 取れれば Q3（人が消えた）が解ける
- **返答待ちが発生するので、動くなら今日中**
