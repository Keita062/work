## 1. 前処理・ステップ0〜4：分析内容と結果

### 前処理　分析に使うデータと、その制約

- **データ**：デジタル庁 地域幸福度（Well-Being）指標。主観データ全区分・全年度95,968行（1,912地域）から、「全体」行・2023〜26年度・回答者数30人以上・区（政令市の区・東京23区）を除く・同じ年度の客観データがそろう、の条件で絞り、**2,116行（678市町村×2023〜26年度）**を分析対象とした。
- 2022年度は対象地域が1,333で、2023年度以降（1,912）と調査の範囲が違うため除いた。2023〜26年度の行の55%は回答者0人。
- **客観スコアの2026年度は、2025年度と全地域で同じ値**（デジタル庁の更新時期の関係で、実質再掲）。
- **和歌山で使えるのは6市だけ**（和歌山市・田辺市・橋本市・岩出市・海南市・紀の川市）。残る24町村はどの年度も回答者が4人以下。田辺市は2023年度、海南市は2023・2025年度が回答者30人未満で使えない。
- 個別KPI（ガイドブック記載の14分野37本を一次統計から再構成）は**1時点**。欠測は補完せず、計算ごとに列がそろう市町村だけを使う。

### ステップ0　地域をまとめる

- **方法**：構造を表す6変数（人口（対数）・人口密度（対数）・高齢化率・財政力指数・第1次産業就業者割合・可住地面積割合）を標準化し、k-means法で678市町村を6類型に分けた。シルエット係数は3〜8類型で0.21〜0.26とほぼ横ばいのため、解釈しやすさと安定性で6に決めた（乱数を変えたときの一致度0.995〜1.00）。
- **結果**：和歌山6市は4類型に散らばる。

| 類型 | 市町村数 | 和歌山 |
| --- | ---: | --- |
| 大都市・中核市 | 82 | 和歌山市 |
| 大都市圏の住宅都市 | 130 | — |
| 市域の広い地方中心都市 | 169 | 橋本市 |
| 平野部の中小都市 | 145 | 岩出市 |
| 農業が盛んな小都市 | 66 | 海南市・紀の川市 |
| 山林の多い地方小都市 | 86 | 田辺市 |

- 医療・福祉、買物・飲食、移動・交通、雇用・所得の実感は、類型だけで43〜63%が説明できる。**幸福度は類型でほとんど差がない**（類型で説明できるのは4%）。
- **結論**：分野ごとの実感の36%は類型で決まる。以降はすべて、同じ類型の市町村と比べる。

### ステップ1　和歌山の立ち位置

- **方法**：6市の類型構成から、県の主観24分野平均の見込み値を出し、実際の値と比べた。6市それぞれの類型内での位置（下から何%か）も出した。
- **結果**：全国の主観平均45.3、和歌山の類型構成からの見込み値44.5、実際の和歌山は42.4。**全国との差2.8のうち、類型構成で説明できるのは0.8（27%）**。
- 和歌山市の主観平均は全国では41%だが、**大都市・中核市の中では5%**。回答者数が最も多いため、県全体の実感を押し下げる最大の要因になっている。
- 田辺市・海南市は、全国では下位4分の1でも類型の中では平均並み（54〜55%）。ただし**田辺市の自己効力感は類型内でも2%**。
- 幸福度は県全体で類型構成からの見込み（6.41）をやや上回る（6.49）。弱いのは幸福度ではなく分野ごとの実感。
- **結論**：県の実感が全国より低い主因は、大都市の中で下位5%にいる和歌山市。

### ステップ2　ターゲットの市

- **方法**：数字（全国・類型内での位置）と、各市の総合計画の両方から判断した。
- **結果**：

| 市 | 幸福度（類型内%） | 主観平均（類型内%） | 判定 |
| --- | ---: | ---: | --- |
| 田辺市 | 42 | 54（自己効力感は2） | **主ターゲット** |
| 和歌山市 | 36 | 5 | **副ターゲット** |
| 橋本市 | 73 | 27 | 対象外 |
| 岩出市 | 51 | 42 | 対象外 |
| 海南市 | 83 | 55 | 対象外 |
| 紀の川市 | 90 | 80 | 対象外 |

- 田辺市は基本理念が「幸せを実感できるまちづくり」で、分析の受け皿がある。和歌山市は第5次長期総合計画が2026年度で満了し、次期計画の策定期にある。
- **結論**：ターゲットは田辺市（主）と和歌山市（副）。

### ステップ3　上げる分野（西村氏の STEP 1 に相当）

- **方法**：幸福度を主観24分野で説明する重回帰のR²を、各分野に配分した寄与度（LMG）。類型の平均を引いたデータ（1,500通り）と、和歌山市・田辺市の類型だけのデータでも計算し、全国（3,000通り）と比べた。
- **結果**：

| 分野 | 類型を揃えた全国 | 大都市・中核市（和歌山市） | 山林の多い地方小都市（田辺市） | 全国（参考） |
| --- | ---: | ---: | ---: | ---: |
| 健康状態 | 27%（1位） | 20%（1位） | 19%（1位） | 25%（1位） |
| 自己効力感 | 23%（2位） | 15%（2位） | 18%（2位） | 22%（2位） |
| 住宅環境 | 13%（3位） | 8%（4位） | 15%（3位） | 12%（3位） |
| 地域とのつながり | 5%（4位） | **10%（3位）** | 5%（6位） | 5%（5位） |
| 説明力 R² | 0.49 | 0.51 | 0.53 | 0.51 |

- **結論**：上げるべき分野は健康状態・自己効力感・住宅環境で、類型を揃えても変わらない。大都市では地域とのつながりが3位に上がる。

### ステップ4　下振れの場所（西村氏の STEP 2 に相当）

- **方法**：地域×年度ごとに主観24分野・客観24分野をそれぞれ行内でz化し、「主観−客観」を出す。その市の類型の平均を引き、2023〜26年度を平均した。
- **結果**：

| 市 × 分野 | 類型で比べた下振れ | 類型内順位 | 全国で見た下振れ（参考） |
| --- | ---: | ---: | ---: |
| 田辺市 × 自己効力感 | −0.86 | 23／86 | −2.24（71／678） |
| 和歌山市 × 地域とのつながり | −0.66 | 17／82 | −0.87（83／678） |
| 橋本市 × 健康状態 | −1.13 | 40／169 | −0.99（171／678） |

- 田辺市×自己効力感の全国での下振れのうち、6割は山林の多い地方小都市に共通するもの（類型平均で−1.38）。ただし実感の水準そのものは類型内2%で、田辺市固有の低さが残る。
- **結論（重点カテゴリー）**：**和歌山市×地域とのつながり**（類型内でも下位21%）と、**田辺市×自己効力感**（水準が類型内2%）。

## 2. ステップ5・6：設計（西村氏案）

### 設計の背景（0929・0930の論点）

1. 当初のステップ5は「改善候補を伸ばすと**主観スコア**が動くか」を見る設計だった。しかし主観分野と幸福度の関係はステップ3で**関連**として確かめただけで、因果は確かめていない。このままだと最終アウトプットが「重点分野の実感を上げる施策」で止まり、**幸福度が上がるとは言えない**（0929提案）。
2. そこで目的変数を幸福度に替える案が出たが、09-29 MTGで「幸福度を上げる要因を探すなら、重点カテゴリーを先に絞る必要がないのでは」という指摘が出た。
3. **解決策（0930）**：重点カテゴリーで絞るのは「24分野を同じ深さで掘るのは広すぎるから」なので、絞り込みは残す。そのうえで、改善候補Xについて次の**2本を両方**推定し、**両方に正の影響を持つXだけを最終候補にする**。
   - ① X → 重点カテゴリーの主観スコア
   - ② X → 幸福度

### ステップ5　改善候補を絞る

| 項目 | 内容 |
| --- | --- |
| 目的 | 改善候補のうち、重点カテゴリーの実感と幸福度の**両方**に正の影響を持つと考えられるものに絞る |
| 入力 | 「改善候補の抽出」で出た候補（4A：既存の客観指標、4B：追加要因） |
| 手法（第1候補） | **固定効果モデル**（自治体×年度のパネル）。自治体ごとの変わらない特徴と、年度ごとの全国共通の変化を取り除き、**同じ自治体の中でXが変わったときに目的変数がどれだけ変わったか**を推定する |
| 推定式 | ① 重点カテゴリーの主観 = β₁·X + 自治体効果 + 年度効果 + 誤差<br>② 幸福度 = β₂·X + 自治体効果 + 年度効果 + 誤差 |
| 判定 | β₁ > 0 かつ β₂ > 0 の X を最終候補とする（分母の向きが逆のKPI、例：失業者数は符号を反転して読む） |
| 根拠 | パネルデータに適している（地域特性の単純比較ではなく、自治体内の変化を見る）。地域の因果効果を固定効果で推定した先行研究として Chetty and Hendren（2016） |
| 注意 | 固定効果モデルを使っても因果が自動的に示されるわけではない。交絡・逆因果の可能性を確認し、因果として解釈できる設計かを検討する。主観分野→幸福度の因果（媒介分析）までは今回扱わない |
| 分かること | 何を改善すると、重点カテゴリーの実感と幸福度がそれぞれどの程度変わると考えられるか |

### ステップ6　改善余地の確認

| 項目 | 内容 |
| --- | --- |
| 目的 | ステップ5で残った候補について、和歌山（ターゲットの市）で数値を伸ばす余地があるかを確認する |
| 方法 | 各候補の和歌山での現状値と、比較対象（同じ類型の市町村など）の分布を並べ、どこまで伸ばせるかを見る |
| 分かること | 実際に改善可能な候補はどれか |
| 次へ | ステップ7で、ステップ5の効果（β）とステップ6の改善可能幅を掛け合わせ、目標値を置いたときの重点カテゴリーの実感と幸福度の変化を試算する |

ステップ6の材料は、アーティファクトの「改善候補（個別KPI）」の表（市の値・類型中央値・類型内%）がそのまま使える。

### 分析対象の変更（0930）

0930残論点では、ステップ5以降の分析対象を次のように変える案になっている。

1. 2022年度のデータは除く（主観カテゴリーが10個存在しないため）。
2. 回答者数0のデータを除く（「全体」行で幸福度が欠損している行はすべて回答者数0）。
3. **年代×性別の行で分析する**。年代×性別によって幸福度や主観評価に大きな差が確認されたため（`Nishimura/src/newbasic.ipynb`）。
4. 年代×性別の行は回答者数が少ない（n<20 が86.3%）ため、**n≥5・10・20・30・50 の5つの基準で同じ分析を回す感度分析**を行い、係数の向き・大きさ・信頼区間・結論が安定する最小の基準を採用する。

## 3. つなぐときに決める必要があること

ステップ0〜4の結果とステップ5・6の設計をつなぐうえで、次の4点は**どちらかに合わせる必要がある**。

1. **ステップ5の説明変数に年度の変化があるか。** 固定効果モデルは、自治体の中で X が年度ごとに変わっていないと推定できない。アーティファクトで改善候補に挙げた**個別KPIは1時点**しかないため、そのままでは固定効果モデルに入らない。年度で動くのは客観24分野のスコアだが、**2026年度は2025年度の再掲**なので、実質2023〜25年度の3時点になる。
   - 客観スコアの年度間の動き（2023〜25年度・1,912地域。全体のばらつきのうち、同じ地域の中で年度ごとに変わる部分の割合）：

     | 分野 | 年度間の変化の割合 | 備考 |
     | --- | ---: | --- |
     | 地域行政・遊び・娯楽・自然の恵み・自然災害 | 0% | 3年間すべての地域で同じ値。固定効果では推定できない |
     | 公共空間 | 0.1% | ハード型の分野だが、ほぼ動かない |
     | 住宅環境 | 1.8% | 2割の地域は3年間同じ値 |
