# 和歌山県 主観的ウェルビーイング向上のためのデータ分析：全体設計書

## プロジェクトの目的
和歌山県の主観的ウェルビーイング（住民が実際に感じている幸福度・生活満足度）を向上させるために、どんな手を打つべきかを、地域幸福度（Well-Being）指標のデータから導き出す。

## データソース
- デジタル庁「地域幸福度（Well-Being）指標」ダッシュボード（https://well-being.digital.go.jp/dashboard）
- 都道府県・市区町村・年度を選択し、主観的ウェルビーイングと客観的ウェルビーイングそれぞれ24カテゴリーの値を取得可能
- スコア仕様：主観・客観ともに全国調査結果をもとに偏差値化（平均50・SD10）。24カテゴリーは同一スケール上にあり、カテゴリー間の直接比較が可能
- 24カテゴリー構成：
  - 生活環境（16）：医療・福祉／買物・飲食／住宅環境／移動・交通／遊び・娯楽／子育て／初等・中等教育／地域行政／デジタル生活／公共空間／都市景観／自然景観／自然の恵み／環境共生／自然災害／事故・犯罪
  - 地域の人間関係（2）：地域とのつながり／多様性と寛容性
  - 自分らしい生き方（6）：自己効力感／健康状態／文化・芸術／教育機会の豊かさ／雇用・所得／事業創造

## 全体の進め方（5ステップ）
1. 主観総合スコアに対して、24カテゴリーは何が一番寄与しているか
2. 客観水準に対して、主観スコアが下振れているカテゴリーは何か
3. そのカテゴリーの主観スコアを（客観を動かさずに）上げられるか
4. 上げられない場合、客観指標の何を上げるべきか（潜在変数も考慮）
5. 具体的なソリューションを立案する

---

## ステップ1：主観総合スコアへの24カテゴリー寄与度分析

### 目的
主観的ウェルビーイングの総合スコアに対して、主観指標の各カテゴリー（24項目）は何が一番寄与しているのか。

### 分析単位・データ設計
- 1行 = 1自治体（市区町村）× 1年度
- 対象範囲：全国の市区町村×全調査年度をプール（和歌山県内だけだとサンプル数が不足するため）
- 目的変数 Y：主観的ウェルビーイング総合スコア（4設問から算出）
- 説明変数 X₁〜X₂₄：主観指標の24カテゴリースコア

### 不採用とした手法
単純相関分析：2変数間の関係しか分からず、他カテゴリーの影響を排除できないため「見せかけの寄与」を過大評価しやすい。多重共線性の事前チェック用途に留める。

### 採用手法

**Step A：データ準備（共通）**
全サンプルに対してX（24カテゴリー）・Yを一括で標準化（z化）。標準化はElastic Net・LMG双方で同一データを使用し比較を公平にする。CV（交差検証）はハイパーパラメータ選定のみに使用。

**Step B：Elastic Net回帰**
1. GroupKFold交差検証：グループ＝自治体コード。同一自治体の複数年度データが訓練/検証に分割されて漏洩するのを防ぐ
2. l1_ratio・α（正則化強度）をグリッドサーチし、GroupKFoldでのテスト誤差（MSE）最小の組み合わせを採用。grouping effectを重視しl1_ratioはRidge寄り（0.1〜0.3程度）を優先検討
3. 選定パラメータで標準化済み全データに再学習（refit）→ 標準化偏回帰係数を取得
4. |β_i|の絶対値で降順ランキング。符号は方向、大きさは他23カテゴリーを一定とした純効果。β_i≈0は「無関係」でなく「他の相関カテゴリーに情報が吸収された」可能性があるためLMGと突き合わせる

**Step C：LMG相対重要度分析**
1. ベースは正則化なしの通常OLS重回帰
2. モンテカルロ近似（24!通りは計算不可能）：ランダム投入順序でのR²増分を数千〜1万回試行し平均。全カテゴリー合計＝フルモデルR²と一致することを検算
3. 各カテゴリーの値を「フルモデルR²に占める割合（%）」に変換。符号を持たないためElastic Netの符号で方向性を補う

**Step D：2手法の統合判断**
1. Elastic Netの|β|順位とLMGの%順位を作成
2. Spearman順位相関係数ρを算出
3. ρが高い（目安0.7以上）→ 上位カテゴリーをそのまま採用。ρが低い・順位が大きくズレる場合 → 因子群単位（生活環境／地域の人間関係／自分らしい生き方）で解釈するか、高相関な変数群をセットで報告

### 最終アウトプット形式
| カテゴリー | Elastic Net係数(β) | 順位① | LMG寄与率(%) | 順位② | 順位差\|①-②\| |
|---|---|---|---|---|---|
| （24行）| | | | | |

「寄与が大きい要素」＝①②両方で上位（目安：上位5位以内）かつ順位差が小さいカテゴリー。フルモデルのR²も併記。

### 未確定・要検討点
- LMGのモンテカルロ試行回数（5,000〜10,000回を目安）
- GroupKFoldの分割数（5分割を例示）

## ステップ2：客観水準に対して主観スコアが下振れているカテゴリーの特定

### 目的
客観の水準に対して、主観的ウェルビーイングのスコアが下振れているカテゴリーは何か。

### 定義方針：同一自治体内での相対比較
単純に「主観偏差値−客観偏差値」を取らない理由：ある自治体・年度の主観調査は、回答者の気分・調査設計等により24カテゴリー全体が底上げ／底下げされること（レベル効果）があり、単純差分だと「特定カテゴリーが本当に下振れている」のか「その年の主観データ全体が低め」なのか区別できない。そこで行（自治体×年度）全体の水準をキャンセルし、その自治体の中での相対的な強弱パターンのみを見る。

### Step 2-A：データ準備
1行 = 1自治体×1年度。各行に24カテゴリーの客観偏差値・主観偏差値が横に並ぶ。

### Step 2-B：行内での相対化（2種類を併用）

**①順位ベース**
客観偏差値24個を行内で1〜24位に順位化（客観順位_i）、主観偏差値も同様（主観順位_i）。
Δrank_i = 客観順位_i − 主観順位_i。正の値が大きい＝客観的には上位のはずが主観では下位＝「下振れ」。

**②行内z化ベース（メイン）**
客観z_i = (客観偏差値_i − 行内客観平均) / 行内客観SD、主観z_iも同様。
gap_i = 主観z_i − 客観z_i。大きく負＝そのカテゴリーは自治体内の相対パターンとして見たとき、客観位置づけより主観位置づけが低い＝「下振れ」。順位より情報量が多く統計検定に使いやすいためメイン指標とする。

### Step 2-C：和歌山県内での集約
和歌山県内の全市町村×全年度でgap_iを計算し、カテゴリーiごとに平均・SDを算出。
有意性検定：対応のあるt検定（分布が歪む場合はWilcoxon符号順位検定）で、平均gapが0と有意に異なるか確認。有意に負＝そのカテゴリーは県内で系統的に「下振れ」。

### Step 2-D：可視化・出力
24カテゴリー×「平均Δrank」「平均gap（z差）」「市町村間SD」「p値」の一覧表。カテゴリー別の箱ひげ図で、県内一律の傾向か一部市町村のみかを確認。

### 出力表イメージ
| カテゴリー | 平均Δrank | 平均gap（z差） | SD（市町村間） | p値 | 下振れ判定 |
|---|---|---|---|---|---|
|（24行）| | | | | |

「下振れ」＝平均gapが負かつp値が有意水準（例：0.05）を下回るもの。ここで抽出されたカテゴリーがステップ3の対象。

## ステップ3：下振れカテゴリーの主観スコアは独立して上げられるか

### 目的
Step2で「下振れ」と判定されたカテゴリーについて、その主観スコアを（客観指標を動かさずに）上げられるか。

### 問いの言い換え
そのカテゴリーの主観スコアのうち、客観スコアだけでは説明できない「余地」（残差）がどれだけあるか。余地が大きい→Step4を飛ばしStep5へ。余地が小さい→Step4へ。

### Step 3-A：カテゴリー単体の説明力（クロスセクション）
対象：Step2で下振れ判定されたカテゴリー。データ：全国市区町村×年度をプール。
単回帰：主観偏差値_i = a + b・客観偏差値_i + ε → 決定係数R²を算出。
- R²が高い（目安0.5〜0.6以上）→ 客観がほぼ主観を決めている＝単独で動かす余地は小さい
- R²が低い → 客観以外の要因（潜在変数）で主観が動く余地が大きい

### Step 3-B：残差分析（お手本自治体の抽出）
Step3-Aの回帰式から各自治体×年度の残差を計算。和歌山県内市町村の残差を確認（下振れ判定と整合するはず）。全国データから、客観偏差値が近い水準にもかかわらず残差が大きく正の自治体を抽出＝「同じ客観条件でも主観を高く保てている」ロールモデル候補（Step5で定性調査の対象）。

### Step 3-C：パネル（時系列）での裏付け
和歌山県内の複数年度データがある市町村で、Δ主観_i、Δ客観_iを計算。客観がほぼ変わらないのに主観が大きく動いた年があれば、その年の出来事を定性確認することで「客観を変えずに主観を動かした実例」の直接証拠になり得る（年度数が少ない場合は参考情報）。

### Step 3-D：判定基準
| 判定 | 条件 | 次のステップ |
|---|---|---|
| Yes（独立して上げられる） | R²が低い、または残差の大きいお手本自治体が存在する | Step4を飛ばしStep5へ |
| No（客観に強く縛られる） | R²が高く、お手本自治体もほぼ存在しない | Step4へ |

R²が中程度など混在するケースは「客観改善」と「コミュニケーション施策」を並行検討。

### 出力形式
カテゴリーごとに：R²、残差の和歌山県内平均・分布、ロールモデル自治体候補（3〜5件）、パネル分析結果、最終判定（Yes/No/中間）を一覧化。

## ステップ4：客観指標の何を上げるべきか（潜在変数を考慮）

### 対象
Step3で「No」と判定されたカテゴリー。

### 前提
客観指標自体、24カテゴリーそれぞれが複数の個別オープンデータ指標から構成された合成偏差値。「客観の何を上げるべきか」に答えるには、カテゴリーの中身を分解し、どの個別指標が主観に効いているかを特定する必要がある。加えて、個別指標だけでは説明しきれない潜在変数の検討も必要。

### Step 4-A：対象カテゴリーの客観指標を構成要素に分解
ダッシュボード下部（またはLWC指標利活用ガイドブック）から、対象カテゴリーを構成する個別オープンデータ指標を洗い出す（例：「医療・福祉」なら病床数、医師数、福祉施設数など）。各指標が偏差値化されているか確認。

### Step 4-B：個別指標レベルでの寄与度分析
カテゴリー内の個別指標数は少ない（数個〜十数個程度）ため、Step1と同じ枠組み（重回帰／Elastic Net＋LMG）を個別指標を説明変数、対象カテゴリーの主観偏差値を目的変数にして実施。変数が少なく多重共線性が弱ければ通常の重回帰＋VIFチェックのみでも可。出力：個別指標ごとの標準化係数・寄与率ランキング。

### Step 4-C：逆因果・タイムラグの考慮
「主観が高いから予算がついて客観指標が改善する」という逆方向の因果もあり得るため、可能ならラグを導入：今年の主観偏差値 = f(前年の客観個別指標)。パネル年度数が少ない場合は参考情報にとどめる。

### Step 4-D：潜在変数（オープンデータに現れない要因）の検討
- お手本自治体との定性比較：個別指標の内訳比較、広報・住民参加施策・SNS発信等の定性調査
- 自由記述・アンケート単純集計の活用：テキストマイニング（頻出語・感情分析）で客観データに出ない不満・満足の理由を拾う
- 周辺自治体との比較認知：近隣・過去との相対的な変化トレンドを参考情報として確認
- 因子分析／PCAでの探索：個別指標群では説明されない主観側の変動パターンの有無を確認（仮説生成用）

これらは統計的な証明というより、Step5のソリューション立案のための仮説材料として位置づける。

### 出力形式
カテゴリーごとに：個別指標の寄与度ランキング表（ラグ有無での頑健性）、逆因果チェックの結果、潜在変数に関する定性的な仮説リスト。

## ステップ5：ソリューション立案

### Step 5-A：カテゴリーごとの分析結果の統合サマリー
| 項目 | 内容 |
|---|---|
| カテゴリー名 | 例：地域とのつながり |
| Step1での総合寄与度 | 順位・寄与率（%） |
| Step2での下振れ度 | gap（z差）の大きさ＝伸びしろ |
| Step3の判定 | Yes／No／中間 |
| Step4の主要因（Noの場合） | 寄与度上位の個別客観指標 |
| 潜在変数の仮説 | お手本自治体の特徴、自由記述からの示唆等 |

Step1の「総合寄与度」×Step2の「下振れ度」の掛け算（または散布図）で、優先順位の一次スクリーニングを行う。総合スコアへの影響が大きく、かつ下振れが大きいカテゴリーほど投資対効果が高い＝優先着手候補。

### Step 5-B：Yes／Noでソリューションの型を分岐

**Yes（主観を独立して上げられる）カテゴリー**
コミュニケーション・体感・情報提供・参加機会に関する施策が中心。
- お手本自治体（Step3-B）の施策内容を定性調査し、応用可能な要素を抽出
- 施策の型：情報の非対称性を埋める（行政広報の見直し等）、参加機会を増やす（住民参加型イベント・ワークショップ）、体験の質を上げる（既存資源のマップ化・SNS発信等、ハード投資なし）

**No（客観指標側の改善が必要）カテゴリー**
Step4-Bで特定した寄与度の高い個別客観指標をターゲットにしたハード・制度面の施策。
- 個別指標の性質（インフラ投資系／制度・運用系／人員配置系）で実現可能性・コスト構造が異なるため、指標ごとに予算規模・リードタイムを概算で付記
- 潜在変数の仮説がある場合は、それを補完する施策（Yes型施策の併用）も併記

### Step 5-C：優先順位付け（インパクト×実現可能性マトリクス）
- 縦軸：インパクト＝Step1の寄与率 × Step2の下振れ度
- 横軸：実現可能性＝コスト・リードタイム・所管部署の調整難易度（定性3段階評価）
右上（高インパクト・高実現可能性）から着手。実現可能性の評価は県庁・市町村へのヒアリングで補正するのが望ましい。

### Step 5-D：効果検証の設計（PDCA）
- 対象カテゴリーの主観偏差値・客観偏差値を継続モニタリング指標に設定
- 施策実施前後でStep2のgap（z差）が縮小したかを追跡
- 年度・市町村数が十分あれば、施策先行実施市町村と未実施市町村の比較（疑似DID分析）も検討

### Step 5-E：最終アウトプット形式
1. サマリー：優先着手カテゴリー（インパクト×実現可能性マトリクス）
2. カテゴリー別詳細：Step1〜4の分析結果＋具体的ソリューション案＋想定コスト感
3. モニタリング計画：継続的に追うべき指標と次回調査での検証方法
