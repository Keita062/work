# 分析設計 — 和歌山の主観的ウェルビーイング向上施策

> **目的**：デジタル庁 地域幸福度（Well-Being）指標の主観データ・客観データを用いて、**和歌山の主観的ウェルビーイングを向上させる施策**を導くための分析設計。
> **位置づけ**：[`分析方針_論点整理.md`](分析方針_論点整理.md) が「何を決めるか」の論点整理であるのに対し、本書は**決まった後に何をどう回すか**の設計書。

## 0. この文書の前提

- デジタル庁 地域幸福度指標の**主観データ・客観データの数値が入手できている**ことを前提とする（入手経路の検討は [`分析方針_論点整理.md`](分析方針_論点整理.md) §4.5 を参照）
- 指標の構造・尺度・調査設計は [`../00_context/02_guidebook_concept.pdf`](../00_context/02_guidebook_concept.pdf)（ガイドブック2章）の p.11〜p.20 を直接確認した内容

- **KPI本数は市区町村版で確認したもの**。都道府県版は一部異なる可能性がある（可住地面積あたり学校数など、都道府県単位では意味が変わる指標があるため）

## 1. データの構造

### 1.1 用語の定義（本書ではこの4語のみ使用する）

「主観指標」「客観指標」という語は階層の違うものを指してしまうため、本書では以下の4語に統一する。**「総合スコア」と単独で書かない**（主観側にしか存在しないため、§1.2 を参照）。

| 用語 | 中身 | 個数 | 出所 | 尺度 |
|---|---|---|---|---|
| **主観総合スコア** | 幸福度Q1・町内幸福度Q2/Q3・生活満足度Q4 | 4 | **アンケート調査** | 生値（0〜10点）※偏差値表示の有無は要確認 |
| **主観カテゴリスコア** | 24分野の「地域の◯◯をどう感じるか」 | 24 | **アンケート調査**（46問） | **偏差値** |
| **客観カテゴリスコア** | 24分野の実態 | 24 | **オープンデータ**（208KPI） | **偏差値** |
| **客観個別KPI** | 完全失業率・正規雇用者比率など | 208 | **オープンデータ** | 元単位 |

**デジタル庁の正式名称との対応**（ガイドブック p.12・p.13）：

- **主観指標** ＝ 【アンケート調査】から測る「**ウェルビーイングの因子**」＝ 市民のウェルビーイング
- **客観指標** ＝ 【オープンデータ】から測る「**暮らしやすさの因子**」＝ 暮らしやすさ（Liveability）

**尺度について**（p.15）：

> 主観指標・客観指標ともに、データを偏差値化しています。

したがって**主観カテゴリスコアも客観カテゴリスコアも、比べられる単位（偏差値）に揃っている**。両者を同じレーダーチャートに重ねられるのはこのため。一方、主観総合スコアはガイドブック上では生の平均値（令和7年度 幸福度6.44）で示されている（§1.4）。

### 1.2 客観総合スコアは存在しない ★設計上の分岐点

**ダッシュボード上に客観側の総合値は無く、ガイドブック2章にも定義が無い。** 幸福度・生活満足度Q1〜Q4は主観アンケートのみで構成される（p.14）。

これは書式上の都合ではなく、**分析の組み方を規定する制約**である。

> **「暮らしやすさ全体 → 幸福感全体」を直結で分析することはできない。必ず24分野を経由する。**

つまり以下の2段に分けることは、分析者の好みではなく**データ構造上の必然**である。

```
客観カテゴリスコア(24)  →  主観カテゴリスコア(24)  →  主観総合スコア
        ↑                          ↑                        ↑
   オープンデータ            アンケート46問            アンケート4問
        └────── 知りたいこと2 ──────┘└──── 知りたいこと1 ────┘
```

なお**この向き（客観→主観）はデジタル庁自身のロジックモデルと一致する**（p.11）。客観指標は「手段」側（スマートシティ・DX・インフラ）の測定、主観指標は「目的」側（市民の幸福感・暮らしやすさ）の測定として設計されている。

| | 設問文 | 分類 | 令和7年度 全国平均 |
|---|---|---|---|
| **Q1** | 現在、あなたはどの程度幸せですか？ | 地域の幸福 | **6.44** |
| Q2 | あなたの町内（集落）の人々は、大体において、どれぐらい幸せだと思いますか？ | 地域の幸福 | 6.32 |
| Q3 | 自分だけでなく、身近な周りの人も楽しい気持ちでいると思う | 地域の幸福 | — |
| **Q4** | 住んでいる地域の暮らしに満足している | 生活満足度 | **6.68** |

### 1.6 客観カテゴリスコアの作られ方（雇用・所得を例に）

```
ステップ1  和歌山の「完全失業率」を全自治体の中で偏差値化      → 例 43.2
           ※ 失業率は高いほど悪いので符号反転（高い自治体ほど偏差値が低い）
ステップ2  同じ処理を残り8本にも適用
           正規雇用者比率 → 48.1 ／ 納税者あたり課税対象所得 → 41.5 ／ 創業比率 → 45.0 …
ステップ3  9本を集約して1つの数字にする                       → 客観_雇用所得 = 44.8
```

**偏差値の定義**（p.16）：

```
偏差値 = ±(当該自治体の数値 − 平均値) / 標準偏差 × 10 + 50
        （数値が高いほど悪い状態を表すKPIはマイナスを使用）
```

**基準集団**（p.16）：

| | 基準集団 |
|---|---|
| 客観指標 | **東京23区および人口10万人以上の自治体**。人口10万人未満は上記の平均・標準偏差を適用 |
| 主観指標 | **人口10万人以上かつ回答数100以上の自治体**。それ未満は上記の平均・標準偏差を適用 |

**50が全国平均、10が1標準偏差。** 客観_雇用所得が44.8なら「基準集団の平均より約0.5標準偏差ぶん劣位」。**ステップ3の集約ルール（単純平均か加重平均か）は要確認**（§11 U4）。

## 2. 知りたいこと

本書の分析はこの6本で構成する。**2-B と 5 は「下振れ＝伸び代」という仮定を検証するために後から追加したもの**（→「なぜ 2-B と 5 を追加したか」）。

### 知りたいこと1：どの分野を改善すれば、主観総合スコアが一番効率よく上がるか

**理由**：医療・買い物・雇用・子育てなど24分野すべてを均等に改善する予算も人員もない。**「主観総合スコアに最も強く結びついている分野（てこの原理が働く分野）」に絞り込む**必要がある。

**使うデータ**：全自治体の「主観カテゴリスコア24列」と「主観総合スコア（幸福度Q1／生活満足度Q4）」。

### 知りたいこと2：和歌山で「客観の水準に対して主観が下振れしている分野」はどこか

**理由**：全国の標準ライン（この客観水準ならこの主観になるはず）から和歌山がどれだけ外れているかを、24分野それぞれで測る。**この時点では「なぜ下振れているか」は判断しない**（それは知りたいこと2-B）。

**使うデータ**：全自治体の「客観カテゴリスコア」と「主観カテゴリスコア」。

> **用語について**：この下振れを当初「環境はあるのに実感が追いついていない」と書いていたが、それは**解釈をひとつに決め打ちした表現**だった。中立に「下振れ」と呼び、解釈は次項で判定する。

### 知りたいこと2-B：その下振れは「伸び代」なのか、「その環境水準での実力値」なのか ★追加

**理由**：知りたいこと2で出た負の残差を、そのまま「伸び代がある」と読むのは**論証されていない仮定**である。同じデータから少なくとも3つの解釈ができ、**どれかによって打つべき施策の型が正反対になる**。

| 解釈 | 中身 | 打ち手 |
|---|---|---|
| **(a) 届いていない** | 環境はあるが、認知・利用されていない | 周知・利用促進・使いやすさ（**ソフト**） |
| **(b) その環境水準での実力値** | この客観水準では住民はこの程度しか感じない。回帰線まわりの自然な散らばりの範囲 | **環境そのものをさらに上げる**（**ハード**） |
| **(c) ノイズ／測定のズレ** | 回答者が約100人で誤差が大きい。または客観KPIと主観設問が別物を測っている | 打ち手なし。**この分野は降りる** |

**当初の設計は(a)を暗黙の前提にしていた。** (b)なら周知施策では動かず、(c)なら何をしても動かない。**判定しないまま施策を選ぶことはできない。**

**使うデータ**：知りたいこと2の残差（できれば R5〜R7 の3時点）、全自治体の残差分布。

### 知りたいこと3：影響の大きさ × 和歌山の凹み で、最優先に投入すべき分野はどこか

**理由**：単に主観が低い分野を選んでも、それが主観総合スコアに関係なければ意味がない。逆に主観総合スコアに効く分野でも、和歌山で既に十分満足されているなら改善の余地がない。**「影響が大きく」かつ「和歌山で下振れしている」分野**こそが最優先ターゲット。

**使うデータ**：知りたいこと1の影響度と、知りたいこと2-Bで**補正済みの**負の残差。

### 知りたいこと4：最優先分野の「お手本都市」はどこで、何をしているか

**理由**：2-Bで**(a)**と判定された場合の打ち手を探す。具体的にどんな施策（PR・イベント・デジタル化・手続き改善）で主観が上がるのかはデータだけでは分からないため、同じような環境下で住民の実感を上げている都市のやり方を学ぶ。

**使うデータ**：全自治体の客観カテゴリスコアと、知りたいこと2の残差。

### 知りたいこと5：環境を上げるとしたら、どのKPIをどれだけ動かせばよいか ★追加

**理由**：2-Bで**(b)**と判定された場合、打ち手は周知ではなく**環境そのものを上げること**になる。しかし「客観_雇用所得を上げる」は施策にならない。**動かせるのは個別KPI**（正規雇用者比率・創業比率など）である。

さらに、**「環境を上げれば主観が上がる」こと自体が自明ではない**。以下3点が未検証のまま。

1. 個別KPIのうち、どれが実際に主観と結びついているか
2. **デジタル庁が設定したKPIの符号（高いほど良い／悪い）が、住民の主観と一致しているか**
3. 関係が飽和していないか（すでに頭打ちなら、上げても主観は動かない）

**2 が特に重要。** 例えば医療・福祉では「人口あたり国保医療費」が**高いほど偏差値が下がる**設定になっている。だが医療費が高い＝医療にアクセスできている、とも読める。**符号設定が住民の主観と逆なら、そのKPIを「改善」する施策は主観を下げる。**

**使うデータ**：最優先分野の主観カテゴリスコアと、同じ分野の客観個別KPI群。

### 全体のつながり

```
[1] 影響度の順位づけ ─┐
                      ├─► [3] 優先度スコア ─► 最優先分野を確定
[2] 下振れ分野の抽出 ─┘                            │
      │                                            │
      └─► [2-B] 下振れの正体を判定 ────────────────┤
             │                                     │
             ├ (a) 届いていない ───────────────────┴─► [4] お手本都市の定性調査
             │                                          → ソフト施策（周知・利用促進）
             │
             ├ (b) その環境水準での実力値 ─────────────► [5] KPIの用量反応

             └ (c) ノイズ／測定のズレ ─────────────────► その分野は降りる
```

**2-B が分岐点。** ここで(a)か(b)かが決まらないと、[4]（お手本都市＝ソフト施策）に進むのか [5]（KPI改善＝ハード施策）に進むのかが選べない。**当初の設計は(a)へ直行していた**が、その前提には根拠がなかった。

### なぜ 2-B と 5 を追加したか

当初の設計は「客観が高いのに主観が低い ＝ 周知不足 ＝ ソフト施策で安く伸ばせる」という筋書きだった。しかしこれは**同じデータの別解釈を排除していない**。

> 環境があるのに主観が追いついていないのではなく、**「その環境水準では、主観はその程度にしかならない」**という解釈が同じくらい成り立つ。
> であれば、主観を上げるには**環境そのものを動かす**しかない。

この読みが正しい場合、当初設計では**施策がひとつも出せない**（お手本都市を探しても「特別なことは何もしていない」で終わる）。したがって、

- **2-B** で3つの解釈を切り分ける検証を入れ、
- **5** で「環境を上げる」側の打ち手（どのKPIを、どれだけ）を用意した

**どちらに転んでも施策が出せる構造**になった点が、この追加の意味である。

## 3. 分析設計

### 分析1：主観総合スコア ← 主観カテゴリスコア24（分野の影響度を出す）

```
幸福度Q1     ~ 主観_医療福祉 + 主観_買物飲食 + … + 主観_事業創造   （24列）
生活満足度Q4 ~ 同上
```

答えるのは **「和歌山の住民の『幸せですか』という答えを左右しているのは、どの分野の実感か」**。

**手順**：

1. **主観カテゴリスコア24列は相互に強く相関する**（生活満足度が高い自治体は多くの分野で高く出る）。通常の重回帰では多重共線性により係数の破綻や符号の逆転が起きるため、**OLSは使わない**
2. **Elastic Net**（正則化により共線性を抑制）と**ドミナンス分析／相対的重要度分析**（指標間の重複した影響を分解して純粋な貢献度を割り出す）の2手法を用いる
3. **ブートストラップ1000回**で係数の安定性を確認。符号が安定しない分野は「影響度不明」として順位づけしない
4. Q1（幸福度）とQ4（生活満足度）の**両方で実施**。満足度のほうが地域環境と繋がりやすく、幸福度は個人要因が強いため、重みは異なるはず。**両者の差自体が結果になる**

**出力は2種類**（§4 で両方使う）：

| 出力 | 手法 | 意味 | 用途 |
|---|---|---|---|
| **寄与率（%）** | ドミナンス分析 | R²への貢献の分解。合計100% | 24分野の**順位づけ**＝知りたいこと1の答え |
| **回帰係数 β** | Elastic Net | 主観カテゴリスコアが1ポイント上がると主観総合スコアが何ポイント上がるか | **分析3の優先度スコア計算** |

### 分析2：主観カテゴリスコア ← 客観カテゴリスコア（下振れの所在）

24分野それぞれで**別々に**回帰する。

```
主観_雇用所得 ~ 客観_雇用所得 + 人口規模 + 高齢化率
```

**手順**：

1. 全自治体のデータから「**客観的な環境がこれくらいのレベルなら、主観の実感はこのくらいになるはずだ**」という標準ライン（予測直線）を回帰で計算する
2. その標準ラインに和歌山の客観カテゴリスコアを当てはめ、「**和歌山で本来期待される主観カテゴリスコア**」を算出
3. 「実際の主観カテゴリスコア」から「期待される主観カテゴリスコア」を引き、**大きなマイナスの残差がある分野**を下振れ分野として抽出する（**この時点では「伸び代」と呼ばない**。それは分析2-Bの判定後）

**出力は2つ**：

| 出力 | 意味 | 使い道 |
|---|---|---|
| **R²** | 客観カテゴリスコアが主観カテゴリスコアをどれだけ説明するか | 低い分野は**環境を動かしても実感は変わらない**。ハード施策を提案してはいけない |
| **残差** | 客観条件を揃えたうえでの実感の上振れ／下振れ | 負に大きい ＝ **下振れ**（伸び代かどうかは分析2-Bで判定） |

**「似た自治体を探して比べる」ではなく回帰の残差を使う理由**：全自治体を母数として使え、「似ている」の定義（距離・重み）に結果が依存しない。人口規模の統制も回帰の中で処理できる。

**R²が低く出そうな分野は事前に予測がつく**（§7）。例：自己効力感の主観は「自分のことを好ましく感じる」1問だが、客観側の材料は**首長選挙投票率・市区町村議会投票率・転入超過割合・完全失業者数**の4本。この2つが繋がるとは考えにくい。**分析2はこうした分野を、主観的な判断ではなくR²という数字で落とせる**点に価値がある。

### 分析2-B：残差の正体を判定する ★追加

負の残差を「伸び代」と読んでよいかを、**4つのチェックで(a)(b)(c)に切り分ける**。

| # | 検証 | 方法 | 判定 |
|---|---|---|---|
| **V1** | **残差の経年安定性** | R5・R6・R7の3時点で同じ回帰を回し、和歌山の残差の符号と大きさが一貫するか | 3年とも同符号・同程度 → (a)か(b)。**符号が振れる → (c)** |
| **V2** | **残差の分布上の位置** | 全自治体の残差の標準偏差 σ を計算し、和歌山の残差が何σ分外れているかを見る | **\|残差\| < 1σ → ただの散らばり＝(b)**。2σ以上外れる → (a)の可能性 |
| **V3** | **残差と客観水準の関係** | 残差を客観カテゴリスコアに回帰（またはLOESSで可視化） | **系統的な負の傾き → (b)**。環境が良い自治体ほど期待も高く主観が下振れる（適応）。周知では動かない |
| **V4** | **残差の分野間相関** | 和歌山の24分野の残差が全部負に寄っていないか | **全分野で負 → (c)**。その自治体の回答者が全般的に辛口なだけ |

**V2 が最も安く、最も効く。** 「残差が −3偏差値」と言っても、全自治体の残差の標準偏差が 5 なら、**それはただの散らばりであって伸び代ではない**。この確認が当初の設計に完全に欠けていた。**V2 は単年データだけで実行できるので、最初に回す。**

**V4 は補正としても使う。** 各分野の残差から「その自治体の全分野平均残差」を引くと、自治体単位の回答傾向（＝固定効果）が抜け、**分野固有の下振れだけ**が残る。**分析3の優先度スコアにはこの補正後の残差を使う。**

**V1 は年度パネルが必要**（R5〜R7の共通自治体）。取れない場合は V2・V3・V4 の3つで判定する。V1が無くても判定は成立するが、(c)の切り分け精度は落ちる。

**判定結果の使い分け**：

| 判定 | 次に進む先 |
|---|---|
| **(a) 届いていない** | 分析4（お手本都市 → ソフト施策） |
| **(b) その環境水準での実力値** | **分析5（KPIの用量反応 → ハード施策）** |
| **(c) ノイズ／測定のズレ** | その分野は降りて、優先度スコアの次点へ |

### 分析3：優先度スコア＝影響度 × 凹み（最優先分野の特定）

分野ごとに **「影響度の強さ」×「補正後の負の残差の大きさ」** を掛け算し、最もスコアが高い分野を最優先ターゲットとして確定する。

**この掛け算には単位の問題がある。** 定義は §4 に分けて記述する。

### 分析4：お手本都市の特定と定性調査（(a)判定の場合）

**手順**：

1. 最優先分野において、和歌山と**客観カテゴリスコアが統計的に近い自治体グループ**を抽出する
2. そのグループの中で、**客観条件は和歌山と同等なのに主観カテゴリスコアが突出して高い（プラスの残差が最大の）自治体**を「成功ベンチマーク都市」として特定する
3. その都市の**行政計画・広報施策・Webサービス・住民向け事業**を定性的に調査し、和歌山に移植できる具体的な施策アイデアを導く

抽出の定義と注意点は §6 に記述する。

**空振りしたときの意味**：お手本都市を調べて「特別なことは何もしていない」だった場合、それは失敗ではなく**(b)の傍証**である。分析5へ切り替える。

### 分析5：個別KPIの用量反応（(b)判定の場合）★追加

最優先分野に絞って、客観カテゴリスコアの中身（個別KPI）に降りる。

```
主観_雇用所得 ~ 完全失業率 + 若年層完全失業率 + 正規雇用者比率 + 高齢者有業率
              + 高卒者進路未定者率 + 市区町村内で従業している者の割合 + 創業比率
              + 納税者あたり課税対象所得 + 人口あたり生活保護受給者数
```

**手順**：

1. 最優先分野の個別KPIを説明変数にして回帰する。**KPIが10本以上ある分野（デジタル生活24・自然災害23など）はLassoで絞る**
2. **各KPIの符号を確認する。** デジタル庁が設定した「高いほど良い／悪い」の向きと、住民の主観との関係が一致しているか
   - **一致しないKPIがあれば、それを『改善』する施策は主観を下げる**。これは提言前に必ず潰す
   - 「不便にした方が主観が上がる」という直感に反する結果が出た場合も、切り捨てずに解釈を試みる（例：車社会で公共交通利用率を上げても満足度が下がる、など）
3. **非線形性の確認**：2次項またはLOESSで、関係が飽和していないかを見る。**和歌山が飽和領域にいるなら、環境を上げても主観は動かない**ので、その分野は降りて次点へ
4. **必要量の逆算**：主観カテゴリスコアを+1偏差値上げるには、そのKPIをどこまで動かす必要があるか

**出力**：`γ_j` ＝ 「KPI_j が1標準偏差改善すると、主観カテゴリスコアが何ポイント上がるか」。これに §4 の β を掛ければ、**主観総合スコアまで効果が伝播する**。

```
KPI_j を 1標準偏差 改善
  → 主観カテゴリスコアが γ_j 上がる          （分析5）
    → 主観総合スコアが β × γ_j 上がる        （分析1）
```

**現実性フィルタとして機能する**：「主観総合スコアを+0.1上げるには、正規雇用者比率を全国3位相当まで上げる必要がある」と出たら、その施策は提案しない。

## 4. 優先度スコアの定義 ★実装前に潰しておく箇所

**「影響度 × 凹み」を素直に実装すると単位が合わない。**

- ドミナンス分析の出力は「R²への**寄与率（%）**」
- 分析2の残差は「**偏差値ポイント**」

この2つを掛けても、意味のある量にはならない（順位づけには使えるが、大きさの解釈ができない）。

### 解決：分析1から回帰係数 β も取り出す

```
優先度スコア_k  =  β_k  ×  |負の残差_k|
```

こう定義すると、次のように**解釈可能な1つの量**になる。

> **その分野の主観カテゴリスコアが全国の標準ラインまで回復したとき、主観総合スコアが何ポイント上がるか**

- `β_k`：主観カテゴリスコアが1ポイント上がると主観総合スコアが何ポイント上がるか（分析1のElastic Net）
- `|負の残差_k|`：和歌山が標準ラインからどれだけ下振れしているか（分析2）
- 単位が揃うため、**24分野を同じ尺度で横並び比較できる**
- そのまま**効果量＝ROIの分子**として使える

### 使い分け

| 目的 | 使う出力 |
|---|---|
| 「どの分野が主観総合スコアに効くか」を1〜24位に順位づけする（知りたいこと1の答え） | **寄与率（%）** |
| 「どの分野に投資すべきか」を凹みと掛け合わせる（知りたいこと3の答え） | **β** |

### 現実性シナリオを添える

残差を100%埋めるのは非現実的なので、**「残差の30%／50%を埋めた場合」のシナリオ**を併記する。これにより「主観総合スコアを+0.1ポイント上げるには、この分野の実感をどこまで戻す必要があるか」が言え、**提言を絞り込む根拠が分析から出る**。

> 注：`β` の単位は主観総合スコアの尺度に依存する。ダッシュボード上で主観総合スコアが偏差値か生値（0〜10点）かによって解釈の文言が変わるため、§11 U3 を先に確定させる。

## 5. 分析2の解釈 — 2軸診断マトリクス（優先度スコアの補助図）

分析2の残差を1枚の図にする。**縦＝客観カテゴリスコア（実態）／横＝残差（実感の上振れ・下振れ）**、円の大きさ＝分析1のβ。

| | **残差 −**（実感が下振れ） | **残差 ＋**（実感が上振れ） |
|---|---|---|
| **客観 高** | **① 環境は高いが実感が低い**<br>→ **分析2-Bで(a)(b)(c)を判定してから施策の型を決める** | ④ 強み。維持と対外発信 |
| **客観 低** | **② 環境も実感も低い**<br>→ 環境の改善（ハード）。分析5でKPIを特定 | ③ 触らない（期待水準が低い可能性） |

### ①象限の読み方 ★当初の誤り

当初この図には「**① あるのに届いていない → 周知・利用促進**」と書いていた。**これは解釈をひとつに決め打ちした誤りである。**

①に落ちた分野は、少なくとも次の3つのどれかであり、**図の位置だけでは区別できない**。

| | ①に落ちた理由 | 打ち手 |
|---|---|---|
| **(a)** | 環境はあるが認知・利用されていない | ソフト（周知・利用導線） |
| **(b)** | **その環境水準では、主観はその程度にしかならない** | **ハード（環境をさらに上げる）** |
| **(c)** | 回答者数が少なくノイズ／客観KPIと主観設問が別物 | 打ち手なし。降りる |

**特に(b)は①象限で起きやすい。** 客観水準が高い自治体ほど住民の期待も高く、主観が相対的に下振れる（適応）ためである。**この場合、周知施策をいくら打っても主観は動かない。**

→ **分析2-BのV1〜V4で判定してから、分析4（ソフト）か分析5（ハード）かを選ぶ。**

**位置づけ**：最優先分野の確定は §4 の優先度スコア（数値）で行う。この図は**その分野が①か②かを見るための可視化**であり、**施策の型は図ではなく分析2-Bの判定で決める**。

## 6. 分析4のベンチマーク自治体の抽出

### 抽出の定義

「客観データが近い」を曖昧にしないため、以下で定義する。

```
1. 最優先分野の客観カテゴリスコアが 和歌山 ± 3偏差値 の自治体を抽出
2. さらに人口規模が近いもの（例：同一人口階級）に絞る
3. 残ったグループの中から、分析2の残差が大きい順に上位3〜5件
```

### この手続きの位置づけ（重要）

**分析2の回帰で人口規模は既に統制されている。** そのため残差ランキングの上位を取るだけでも「同じ客観条件で主観が高い自治体」にはなり、統計的にはマッチングは重複した手続きである。

それでもマッチングを重ねるのは、**提言の説得力のため**。

> 「和歌山と同じくらいの人口規模で、雇用環境の客観水準もほぼ同じ◯◯市では、住民の実感が和歌山より大きく高い。何が違うのか」

という形にしたほうが、決裁者に対して圧倒的に伝わる。**統計的な必要ではなく、コミュニケーション上の必要**として実施する、と文書に明記しておく。

### ガイドブックの注意書きへの対処

ガイドブック p.16 には次の記載がある。

> 多くの人に馴染み深い「偏差値」という言葉が、「競争」や「ランキング」を想起させがちですが、自治体同士の過度な比較は避け、自身のまちの特徴を読み取ることを主目的としてください。

本分析の分析4は**自治体の優劣をランキングする目的ではなく、施策を学ぶための事例選定**である。提出資料でもこの立場を明示し、ベンチマーク都市を「優れた自治体」ではなく「**同条件で成功している参照事例**」として扱う。

### 定性調査の対象

行政計画（総合計画・分野別計画）／広報施策／Webサービス・アプリ／住民向け事業・イベント／議会議事録。可能なら**その施策の開始時期と、主観カテゴリスコアの年次変化のタイミングが一致するか**まで確認する。

## 7. 主観カテゴリスコアの品質は分野で一定ではない

### 設問数のばらつき

24分野のうち、**9分野は設問1問だけ**から主観カテゴリスコアが作られている。

> 移動・交通／遊び・娯楽／都市景観／自然景観／環境共生／自然災害／自己効力感／教育機会の豊かさ／事業創造

一方で地域とのつながり・多様性と寛容性は5問、住宅環境は3問。

**含意**：1問由来のスコアは測定誤差が大きい。**分析1で影響度が低く出ても「効いていない」のか「測れていない」のかを区別できない。** 結果表には必ず設問数を併記し、1問由来の分野を低く評価しすぎないようにする。

### 客観KPIの性格のばらつき（分析2のR²の事前予測）

客観カテゴリスコアの中身は分野によって性格が大きく異なり、**R²が低く出る分野はある程度予測できる**。

| 分野 | 客観KPIの性格 | 分析2のR²予測 |
|---|---|---|
| 買物・飲食 | 商業施設徒歩圏カバー率・飲食店数 | **高い**（主観設問と対応が明快） |
| 医療・福祉 | 8本のうち2本が**人口あたり医療費で符号反転** | 中〜低 |
| 都市景観 | 5本のうち4本が**受賞・条例・協定の有無** | **低い** |
| 自然景観 | 11本のほぼ全部が**国立公園・百選等の有無** | **低い** |
| 環境共生 | 16本のうち10本が**SDGs未来都市・ゼロカーボン表明等の有無** | **低い** |
| 多様性と寛容性 | 11本のうち6本が**条例の有無** | **低い** |
| 自己効力感 | 首長選挙投票率・議会投票率・転入超過割合・完全失業者数 | **低い** |
| 雇用・所得 | 9本すべてが標準的な統計値（失業率・所得・雇用形態） | **高い** |

**「表明・採択・受賞の有無」は行政の行動であって住民の体感ではない。** 分析2はこれをR²という客観的な基準で落とせる。

### KPIの調査年が混在している

客観個別KPIの調査年は2010〜2025でバラバラ（「自然の恵み」16本は全て2010年、「保育所への距離」「空家率」は2018年）。

- **単年横断の分析（分析1〜4）では実害は小さい**
- **年度パネルに手を出す場合のみ致命的**。「客観の年次変化がほとんど無い」可能性があるため、パネル化の前に必ず確認する

## 8. 「誰に効くか」は個票が無くても部分的に埋まる

属性別の個票は現時点でダッシュボードに反映されていないが、**全国平均の属性別スコアは公表されている**（40代6.10が谷、70代以上7.04が山、女性>男性）。これと和歌山の人口構成で**直接標準化**ができる。

```
期待される主観総合スコア = Σ（和歌山の属性別人口構成比 × 全国平均スコア）
実測 − 期待 = 人口構成では説明できない「和歌山固有」の低さ
```

- **固有分がほぼゼロなら、施策の主張が根本から変わる**（高齢化構成の問題であって政策の問題ではない、という結論になる）
- 分析1・分析2の統制変数の設計にも直結する
- 計算自体は数十分。**早期に回す価値が高い**

なお令和7年度は属性データが追加されており（p.17）、デジタル庁への照会で個票が得られれば、この節は推計ではなく実測に置き換えられる。

## 9. リスクと対処

| リスク | 中身 | 対処 |
|---|---|---|
| **サンプルサイズ** | 案B（都道府県版47件）を選ぶと、分析1に説明変数24本は載らない。分析4も母数不足 | **案Aまたは案Cを推奨。** 案Bを選ぶ場合は正則化を強め、分析4は簡略版に落とす |
| **偏差値の基準集団** | 客観は東京23区＋人口10万人以上、主観は人口10万人以上かつ回答数100以上がベース。**人口10万人未満は大都市基準の外挿値**。530自治体には10万人未満が多数含まれる | 人口規模を統制変数に入れる。加えて**人口10万人以上のサブサンプルのみで再推定**し、結論が変わらないことを確認 |
| **因果を主張できない** | 分析2は横断データなので「客観→主観」は仮定 | ガイドブックのロジックモデル（p.11）が同じ向きを採用していることを根拠として引用しつつ、**主張は「効果推定」ではなく「優先順位づけ」に限定**する |
| **適応（期待水準）バイアス** | 客観水準が高い自治体ほど住民の期待も高く、実感が上がりにくい可能性 | **分析2-BのV3で正面から検証する**（リスクではなく判定材料に格上げした）。系統的なら2次項を追加 |
| **残差＝伸び代とは限らない** | 負の残差は(a)届いていない／(b)その水準での実力値／(c)ノイズ のどれでもありうる | **分析2-BのV1〜V4で判定する。** 判定前に施策の型を決めない |
| **KPIの符号が主観と逆の可能性** | デジタル庁が設定した「高いほど良い／悪い」が住民の体感と一致しない場合、改善施策が逆効果になる | **分析5の手順2で全KPIの符号を確認する。** 提言前の必須チェック |
| **回答者が毎年違う** | インターネットモニター調査で母集団構成比を考慮していない | 単年横断の分析では影響しない。**分析2-BのV1（経年比較）でのみ問題**になるため、変化幅が大きいものだけを扱う等の防御が必要 |

- **手順4はV2から始める。** V2は単年データだけで数十分で回り、「そもそも和歌山の残差は他の自治体の散らばりと比べて特別か」という最も基本的な問いに答える。ここで「1σ以内」と出たら、**その分野は(b)であり、分析4に進んではいけない**
- 6a と 6b は排他ではない。分野ごとに判定が違えば両方走る
