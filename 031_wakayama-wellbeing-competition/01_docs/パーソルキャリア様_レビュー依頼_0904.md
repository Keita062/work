## 4. 分析の目的

> ## 和歌山県の住民が実際に感じている幸福度（主観的ウェルビーイング）を上げること。

---

## 5. 目的を叶えるための方法

### 方法

> ## 分析から政策提言までを行う。

**理由：** 目的を叶えるには、**データドリブンで幸福度を向上させる施策が何なのかを明確にし、手を打つこと**が必要だからです。施策が明確になっていなければ手は打てず、手を打たなければ幸福度は上がりません。したがって、分析だけでも提言だけでもなく、**分析から政策提言までを一続きで行うこと**を方法とします。

### この方法をとった後の状態

分析から政策提言までを終えたとき、次の4点を言える状態になっていることを目指します。

| # | 言えるようにすること | それが言えると何ができるか |
|---|---|---|
| **1** | **どの分野に手を打つべきか**（優先順位と、その根拠） | 予算を振り向ける先が決まる |
| **2** | その分野は、**周知・運用で実感を上げられるのか／環境そのものを変えないと上がらないのか** | 打つべき施策の型（ソフト／ハード）が決まる |
| **3** | 環境を変えるなら、**どの指標を、どこまで動かすのか** | 施策のターゲットと目標値が決まる |
| **4** | その打ち手で、**幸福度がどれだけ動くと見込めるのか** | 費用対効果を示して意思決定にかけられる |

この4点が埋まれば、**「和歌山県はここに、こう手を打つべき」**という形で提言に落ちます。逆に、ここが埋まらない設計は目的を達成しません。

## 6. 収集するデータ

### 6-1. 使うデータ

> ## デジタル庁「地域幸福度（Well-Being）指標」ダッシュボード

**市区町村単位**で、**住民の実感（主観指標）と地域の環境水準（客観指標）が、同じ24分野の枠組みで並んで取れる**のがこのデータの特徴です。全国約530自治体分が公開されています。

### 6-2. このデータで何が分かるか

| 取れるもの | 分かること |
|---|---|
| **幸福度**（0〜10の総合スコア） | 住民が全体としてどれだけ幸せを感じているか。**これを目的変数にする** |
| **主観24分野**（住民の実感） | 24分野それぞれについて、住民が実際にどう感じているか |
| **客観24分野**（環境の水準） | 同じ24分野について、地域の環境が客観的にどの水準にあるか |
| **客観の個別KPI**（208本） | 客観24分野が、どの具体的な指標から成り立っているか |
| **年代別の内訳** | 主観側は**全分野が年代別に取れる**ため、同じ自治体でも年代によって実感がどう違うかを見られる |

主観と客観が同じ枠組みで並ぶため、**「環境はあるのに、住民の実感が伴っていない分野」を特定できます。** これが本分析の起点です。

**24分野の内訳**

- **生活環境（16）**：医療・福祉／買物・飲食／住宅環境／移動・交通／遊び・娯楽／子育て／初等・中等教育／地域行政／デジタル生活／公共空間／都市景観／自然景観／自然の恵み／環境共生／自然災害／事故・犯罪
- **地域の人間関係（2）**：地域とのつながり／多様性と寛容性
- **自分らしい生き方（6）**：自己効力感／健康状態／文化・芸術／教育機会の豊かさ／雇用・所得／事業創造

### 6-3. データの出所

| 区分 | 出所 |
|---|---|
| **主指標（主観）** | **すべて住民アンケート。** デジタル庁が全国の自治体で実施 |
| **客観指標** | **官庁統計から合成。** 国交省「都市モニタリングシート」、厚労省「医療費の地域差分析」、総務省「社会・人口統計体系」等。**原出典まで公開されている** |
| **環境変数（統制用）** | 総務省（人口・高齢化率・財政力指数）。**ダッシュボードの外から足す**変数で、自治体間の条件差を吸収するために置く |

### 6-4. 目的変数と分析単位

| 項目 | 内容 |
|---|---|
| **目的変数** | **幸福度**（0〜10の生値）。コンペのテーマ名に一致させる |
| **説明変数** | 主観24分野・客観24分野（いずれも偏差値）、客観の個別KPI（実数）、**環境変数**（人口・高齢化率・財政力指数などの地域条件。自治体間で条件を揃えるための統制変数として置く） |
| **分析単位** | **1行 ＝ 1自治体 × 1年度 × 1年代** |
| **対象** | **推定は全国の自治体、診断の対象は和歌山。** 全国データで「同水準の自治体ならこのくらい」という物差しを作り、それを和歌山に当てる |

## 7. 分析設計

### 7-1. この資料で使う言葉

分析設計の説明に入る前に、以下の5語を定義します。

| 言葉 | 指すもの |
|---|---|
| **幸福度** | **目的変数。** 住民に直接たずねた0〜10の総合スコア |
| **主観スコア** | 24分野それぞれの、**住民の実感**の値（偏差値） |
| **客観スコア** | 24分野それぞれの、**地域の環境水準**の値（偏差値） |
| **客観的構成値** | 客観スコアを組み立てている**個別KPI**（24分野あわせて208本） |
| **追加要因** | 客観的構成値に含まれていないが、主観スコアに関係している可能性のある要因（情報の届き方、予約のしやすさ、運用など） |

### 7-2. 全体の流れ

**分析は9ステップですが、かたまりで見ると4つです。**

```
①  どの分野を扱うかを決める                      STEP 1・2
              ↓
②  その分野の実感が、環境の数字で説明できるかを判定する    STEP 3・4
              ↓          ← ここで進む道が2つに分かれる
③  何をどこまで動かすと、実感がどれだけ動くかを出す       STEP 5・6・7
              ↓
④  行政が打てる手に翻訳する                      STEP 8・9
```

| | STEP | やること | ここで分かること |
|:---|:---|:---|:---|
| **①**<br>分野を<br>絞る | **1** | 24分野の**主観スコア**と**幸福度**の関連性を確認する | 幸福度と関連が大きい分野はどれか |
| | **2** | **重点カテゴリー**を選定する | そのうち、和歌山が優先的に扱うべき分野はどれか |
| **②**<br>道を<br>分ける | **3** | 重点カテゴリーの**主観スコア**を、**客観的構成値**で説明できるかを確認する | 環境の数字で説明がつく分野か、つかない分野か |
| | **4A** | **【説明できる場合】** 客観的構成値をそのまま改善候補として扱う | 改善候補（既存のKPI） |
| | **4B** | **【説明できない場合】** 追加要因を探索し、改善候補に加える | 改善候補（既存のKPI ＋ 追加要因） |
| **③**<br>効き目を<br>見積もる | **5** | 改善候補のうち、伸ばすと実感が動きそうなものに絞り込む | 効きそうな候補はどれか |
| | **6** | 和歌山に、その数値を伸ばす**余地**があるかを確認する | 実際に動かせる候補はどれか |
| | **7** | 候補に目標値を置き、**主観スコア**の変化を試算する | どこまで動かすと、実感がどれだけ動くか |
| **④**<br>施策に<br>する | **8** | **行政施策**の介入可能性と時間軸を整理する | 短期・中期・長期のどれで打てる手か |
| | **9** | 政策提案とロードマップを作成する | 和歌山が、何を、いつやるべきか |

※ **改善候補** ＝ STEP 4A では「客観的構成値」、STEP 4B では「客観的構成値」に加えて探索した「追加要因」を指します。

### 7-3. 設計の要は STEP 3 の分岐

同じ「主観スコアが低い」でも、背景は2通りあります。

| | 状況 | 意味すること |
|---|---|---|
| **ケースA** | 客観スコアが低く、主観スコアも低い | **環境そのものが足りていない**可能性がある |
| **ケースB** | 客観スコアは一定水準だが、主観スコアは低い | **既存の客観指標では、実感の低さを説明しきれていない**可能性がある |

この2つを分けずに進めると、**打ち手が「施設を増やす」一辺倒になり、和歌山が実行できない提言になります。** そこで STEP 3 で「主観スコアを客観的構成値でどこまで説明できるか」を先に確かめ、道を分けます。

| ルート | 判定 | 次にやること | 想定される政策の型 |
|---|---|---|---|
| **ルートA** | 説明できる | STEP 4A：個別KPI（客観的構成値）まで掘り下げる | **ハード寄り**（環境の水準そのものを上げる） |
| **ルートB** | 説明できない | STEP 4B：客観環境が同程度の自治体を集めて群間比較し、追加要因を探す | **ソフト寄り**（周知・運用・使いやすさを上げる） |

**ルートBは「相関が低いから捨てる」の逆で、「既存指標では測れていない領域」として拾い上げるための道です。** ここに、他チームとの差別化になりうる定性データ・地理データの活用が入ります。
