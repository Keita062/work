## 1. 定量的な定義

**「法人個人双方から選ばれている」＝ 法人KPI・個人KPI の両方でリクルートと同等以上**

| | KPI | 操作的定義 |
|---|---|---|
| 法人KPI | 各年度の就職者数 | 無期雇用 ＋ 4か月以上の有期雇用の就職者数 |
| 個人KPI | 年間登録者数 | その年度に登録・申込をした転職希望者数 |

※ KPIは両社とも実数が公表されているものに限る。推計値はAs Isに記載しない。

## 4. GAP（個人KPI）

| | 数値 | 算出 |
|---|---|---|
| As Is（FY23） | 176万人 | |
| To Be（2030年度） | 202万4,000人 | |
| **GAP** | **26万4,000人** | 2,024,000 − 1,760,000 |

### GAPの分解

```
   年間登録者数  ＝  市場の転職希望者数  ×  リーチ率
```

| | 数値 | 算出・出典 |
|---|---|---|
| 市場の転職希望者数 | **534万人** | 24万（年収1,000万〜）＋80万（600〜1,000万）＋430万（400〜600万）／IR-DAY p.14 |
| パーソルキャリアのリーチ率 | **33.0%** | 176万 ÷ 534万 |
| リクルートのリーチ率 | **37.9%** | 202.4万 ÷ 534万 |
| **差** | **4.9ポイント** | |

**GAP 26万4,000人 ＝ リーチ率 約5ポイント分。**

※ 複数サービス併用があるため、全社のリーチ率合計は100%を超える。

---

## 5. Issue

リーチ率が 4.9ポイント低い原因。

- **① 第一想起で負けている**
  転職サービス利用率は doda 31%、リクルートエージェント 49% で **18ポイント差**。
  転職を考えた時点で候補に入っておらず、訪問・登録の母数に乗らない。
  〔民間調査・2023年10月／参考値〕

- **② サイト訪問は取れているのに、登録に至っていない**
  求人サイト訪問数ランキングは **1位 doda**（2023年10月〜2024年3月）。
  訪問で上回りながら年間登録者数では下回る＝**訪問→登録の転換で落としている**。
  〔IR-DAY p.17（SimilarWeb）〕

- **③ ハイクラス層を取り切れていない**
  市場534万人のうち年収600万超は **104万人（19.5%）**。
  doda本体の主要ターゲットは年収400〜600万のボリューム層で、この層のカバーが構造的に薄い。
  〔IR-DAY p.14〕

- **④ 登録者が離脱している**
  FY2025 4Q に doda・doda X の ID統合で一部ユーザーが離脱し、増加分を打ち消している。
  〔パーソルHD 2026年3月期通期決算〕

- **⑤ 転職顕在層にしか接点がない**
  市場534万人のうち **358万人（67%）が未リーチ**。
  転職を決めた人を受け止める設計のため、その手前の層に接点がない。
  〔IR-DAY p.14〕

---

## 6. Solution

| Issue | Solution |
|---|---|
| ① 第一想起で負けている | **転職顕在化の前段に接点を作る。** 年収診断・キャリア相談を入口にし、転職を考える前から想起される状態をつくる |
| ② 訪問→登録で落としている | **登録導線の改善。** 登録ステップの削減、診断コンテンツから登録への直結、AIによる求人提示の前倒し |
| ③ ハイクラス層が薄い | **doda X の母集団拡大。** ハイクラス層へのマーケ投資、スカウト体験の改善 |
| ④ 登録者が離脱している | **ID統合の離脱リカバリ。** 統合後ユーザーの再活性化、doda ⇔ doda X の相互回遊設計 |
| ⑤ 潜在層に接点がない | **PERSOL MIRAIZ による潜在層の掘り起こし。** キャリア自律支援・コミュニティを転職の前段に置き、母集団の器を広げる |

※ Solution ⑤ は、パーソルキャリアが中長期戦略方針の3本柱の1つに掲げる「集めるチカラ」の強化（IR-DAY p.32, p.35）と整合する。

※ リクルートの年間登録者数は毎年 r-agent.com 法人向けサイトの注記から取得できるため、GAPの推移をトラッキングする運用を別途つくる。
