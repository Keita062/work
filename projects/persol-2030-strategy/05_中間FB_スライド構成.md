## 0. この資料の設計方針

### 0-1. 本資料のゴール

中間フィードバックの場で、以下の**2点について指摘をもらう**ことを目的とする。

1. **我々が置いた「選ばれる」の定量定義に対して、どう思うか**
2. **発散させた5つの課題のうち、どれを本命に絞るべきか**

この2点に答えてもらうための資料であり、**それ以外の情報は載せない**。
解決策（④）と1か月の行動（⑤）は次回の中間FBで扱う。

### 0-2. 全体構成と時間配分

持ち時間は14分。**発表10分・質疑4分**で組む。

| # | セクション | 枚 | 時間 |
|---|---|---|---|
| A | タイトル／アジェンダ／FB依頼 | 3 | 1.0分 |
| B | 前提（定義・To Be/As Is・GAPの分解） | 3 | 3.0分 |
| C | リサーチ内容（ファクト） | 1 | 1.5分 |
| D | 今考えている課題（発散） | 3 | 3.5分 |
| E | クロージング | 2 | 1.0分 |
| - | Appendix | 3 | 質疑で使用 |
| | **合計** | **12（＋Appendix 3）** | **10分** |

## B. 前提 ── 定義／あるべき姿／現状（3枚）

### スライド4 ─ 「選ばれる」の定義

- **見出し**: `「選ばれる」の定義 ── 法人／個人それぞれで置いた`
- **レイアウト**: **法人／個人の2カラム。** 各カラムに「定量指標」と「定性・状態」を書く
  - ※「定性で合意したこと」「定量への落とし込み」という切り方はしない
- **本文（9/4 研修共有ドキュメント「①前提（「選ばれる」の定義）」より）**

  | | 法人視点 | 個人視点 |
  |---|---|---|
  | **定量指標** | doda等人材サービスにおける**就職率・定着率**、日本企業全体におけるパーソルサービスの**シェア率** | **登録者数、転職成功率、キャリア選択の幅**、プラットフォーム全体の生涯価値（LTV） |
  | **定性・状態** | 単なる採用にとどまらず、**育成・人員配置・組織開発まで一括して任される状態**、および長期的・継続的な契約関係（LTV・NPS向上） | **キャリアのあらゆるフェーズにおいて選ばれ、中長期的に利用され続ける状態** |

- **上段（細い帯・1行）**: 人材サービスのスコープ
  `データが取れている範囲：リクルートエージェント ／ パーソル（doda）　｜　時間軸：2030年度`
  - 出典: 9/4 研修共有ドキュメント「人材サービスのスコープ／とれているデータ」
- **下段（帯・1行）**: 9/4に収束させた結論
  **「選ばれる」＝ 決定率が高い状態（リクルートに数値で上回る状態）**
  - 出典: 9/4 研修共有ドキュメント memo「選ばれる定義 ＝ 決定率が高い状態／リクルートに数値で上回る状態」、
    およびホワイトボード「② 選ばれるの定義 → 決定率が高い → 今より向上」
- **注意**
  - **要素を4段以上に積まない。** 詰め込むと読めなくなる

### スライド5 ─ あるべき姿と現状 ★数字の核

- **見出し**: `あるべき姿（2030）と現状 ── GAPは 個人26.4万人／法人2.7万人`
- **KPIの定義（8/24 研修共有ドキュメント「法人個人双方から選ばれる／keita」で確認済み）**
  - 法人KPI ＝ **各年度の就職者数**（無期雇用 ＋ 4か月以上の有期雇用の就職者数）
  - 個人KPI ＝ **年間登録者数**（その年度に登録・申込をした転職希望者数）
  - → **議事録の記載と一致。変更なし**
- **列の順番は「あるべき姿 → 現状 → GAP」。** 見出しの語順に合わせる

  | | あるべき姿 To Be 2030 | 現状 As Is（パーソル） | GAP |
  |---|---|---|---|
  | 個人KPI：年間登録者数 | **202万4,000人** | **176万人**（FY23） | **26万4,000人** |
  | 法人KPI：就職者数 | **87,754人** | **60,307人**（令和7年度） | **27,447人** |

  - **To Be の置き方**: リクルートの現在値に並ぶことを2030年の到達点とする（リクルート横ばい前提）
- **ビジュアル案**
  - 上下2段の横棒バー（現状バー＋GAP分をハッチングで継ぎ足す）
- **注意**
  - 年度がそろっていない（FY23 vs 令和7年度）ことを脚注で明示する

### スライド6 ─ 決定率の出し方

- **見出し**: `GAPを、登録者数と決定率に分けて見る`
- **レイアウト**: **式の展開だけ。** 内訳の棒グラフや配分（%）は載せない
- **本文（式 → 代入 → 差 の順で組む）**
  1. **式を置く**: 就職者数 ＝ 年間登録者数 × 決定率
  2. **変形する**: 決定率 ＝ 就職者数 ÷ 年間登録者数
     - ※ 公表指標ではなく、**実数2つからの逆算値**
  3. **代入する**（表1枚）

     | | 就職者数 | 年間登録者数 | 決定率 |
     |---|---|---|---|
     | パーソル | 60,307人 | 1,760,000人 | 3.43% |
     | リクルート | 87,754人 | 2,024,000人 | 4.34% |

  4. **差を出す**: **0.91ポイント**
- **載せないもの**
  - **GAP 27,447人の内訳（登録者数の差／決定率の差／相乗効果）と、その棒グラフ・%表示**
  - **「ここで言えること／言えないこと」のボックス**
  - **強調のための色分け**（リクルートだけ青、0.91ポイントだけ赤 など）。色は使わず同じ扱いにする
- **注意**
  - 決定率が**逆算値**であることだけは、脚注で必ず残す

### スライド7 ─ リサーチで分かったこと

- **見出し**: `リサーチで分かったこと`

  - **個人**

  - **市場**
    - 2030年に全国で **644万人** の人手不足

### スライド8 ─ 課題マップ（全体像）

- **見出し**: `いま挙がっている課題は5つ ── まだ発散段階です`
- **本文（5つを縦に並べる。9/4ドキュメントの課題名そのまま）**
  1. 登録者数・プラットフォーム規模の格差と未リーチ層への接触不足
  2. 登録者から成果（就職・決定）への転換力の低さ
  3. 点の支援（単発関係）によるLTVの低さと、一貫したトータルソリューションの不備
  4. 求人「量」の劣勢と、定着・活躍など「質」を証明・評価する手段の不足
  5. HiPro（副業・フリーランス）の規模感と、dodaからの連携ストーリーの脆弱さ
- **載せないもの**
  - **GAPの内訳（母数の差33%／転換力の差58%／相乗効果9%）。** 根拠が説明できないので出さない
- **各課題に添えるタグ**
  - 課題1・2 … 定量定義と接続する
  - 課題3・4・5 … 定量定義の外側
- **自分から言うべきこと**
  - **課題3・4・5は、我々が置いた定量定義と接続していない**
  - **課題5だけ粒度が違う**（HiProという1サービス単体の話）

### スライド9 ─ 課題1・2（定量定義と直結する課題）

- **見出し**: `課題1・2 ── 定量定義と直接つながる2つ`
- **課題1：登録者数・プラットフォーム規模の格差と未リーチ層への接触不足**
  - 内容（ドキュメントの記載どおり）: リクルートに対して個人登録者数（26.4万人差）や
    法人シェア率で劣っており、転職希望者の67%（358万人）と接点が持てていない
  - 発案: リーダー（課題1）／まい（サブ課題1-1・1-3）／けーた（個人data）
  - 深掘りの論点（かな）: 認知・第一想起／集客チャネル・顧客接点／求人数・企業数による
    登録魅力度／獲得できている年代・職種・地域
  - ホワイトボードで出た仮説: 登録時の入力コスト・UI（年収レンジ）・Web上の企業名表示
- **課題2：登録者から成果（就職・決定）への転換力の低さ**
  - 内容（ドキュメントの記載どおり）: 母数の差だけでなく、登録者から就職に至る決定率
    （パーソル3.43% vs リクルート4.34%）そのものに0.91ポイントの構造的な弱さがある
  - 発案: まい（サブ課題1-2）／けーた（法人data）
  - 深掘りの論点（かな）: 紹介できる求人数／求人紹介→応募率／応募→書類→面接→内定の通過率／
    内定→承諾・入社率／CA・法人営業の支援体制・生産性
  - ホワイトボード・みおの仮説: CAの質（専門性／雑務量）／最終意思決定までが遅い

### スライド10 ─ 課題3・4・5（定量定義の外側）

- **見出し**: `課題3・4・5 ── 定量定義の外側にある3つ`
- **課題3：点の支援によるLTVの低さと、トータルソリューションの不備**
  - 人材紹介事業単体では転職時のみの「点の支援」で終わり、転職しない期間の接点が少なく、
    顧客生涯価値（LTV）を高められていない
  - 発案: リーダー／まい／みお／かな
- **課題4：求人「量」の劣勢と、「質」を証明・評価する手段の不足**
  - 求人掲載数（30万件 vs 80万件）では競合に勝てず、高い定着率（94.5%）や入社後の活躍度を
    法人側に客観的に示すデータ・手段が不足している
  - 発案: リーダー／まい／みお
- **課題5：HiProの規模感と、dodaからの連携ストーリーの脆弱さ**
  - HiProは急成長しているが全社LTVを支えるには規模（10万人）が小さく、dodaからの実際の流入率
    （クロスユース率）が不明。また利用者の7割が現職会社員であり、「転職後の受け皿」という
    ストーリーとズレがある
  - 発案: まい
