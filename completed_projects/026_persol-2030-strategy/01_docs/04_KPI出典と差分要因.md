# KPIの出典と差分要因

> [01](01_定量定義とGAP分析.md) 第10章「① 登録者を就職に変える割合が0.91ポイント低い」を破棄して書き直したもの。
> **公開情報で言えることと、内部データがないと言えないことを分けて書いている。**

---

- **個人**
  - data
    - 年間登録者数
      - リクルートエージェント
        - 202万4,000名（出典：[LINK](https://www.r-agent.com/business/)　注記※2「2025年4月1日〜2026年3月31日の間に申し込みをいただいたサービス登録者数」）
      - パーソル
        - 176万人（出典：[LINK](https://www.persol-group.co.jp/ir/upload_file/m005-m005_09/IRDAYCareerJP.pdf) p.10「転職希望者数 176万人（YoY+7%）」　脚注「FY23累計」）
      - GAP
        - 26万4,000人
      - ※ 2つは定義がずれている
        - リクルート＝エージェント単体・FY2025 ／ パーソル＝Career SBU全体（人材紹介＋求人メディア＋DR）・FY2023
        - パーソル側のほうが分母が広く、2年古い
  - 要因
    - 未リーチ
      - 転職希望者のうち doda に登録していない人
      - →358万人
      - 転職希望者534万人 − doda年間登録176万人（出典：[LINK](https://www.persol-group.co.jp/ir/upload_file/m005-m005_09/IRDAYCareerJP.pdf) p.14　パーソルキャリア2022年市場調査）
    - 同じ市場に対するリーチ率で4.9ポイント負けている
      - パーソル　176万 ÷ 534万 ＝ **33.0%**
      - リクルート　202.4万 ÷ 534万 ＝ **37.9%**
      - →GAP 26万4,000人は、**リーチ率を4.9ポイント上げれば埋まる**
    - 検討の候補に入る段階で差がついている
      - 「5年以内に利用した転職サービス」　doda **31%** ／ リクルートエージェント **49%**（**18ポイント差**）
      - 〔[マイ転職ストーリー 2023年10月調査・有効回答402名](https://www.value-press.com/pressrelease/325888)　民間調査の参考値。併用があるため各社合計は100%を超える〕
    - ここから先は公開データでは特定できない
      - 両社の認知度・第一想起率 → 非開示
      - 両社のサイト訪問数の実数 → 順位データはあるが実数がなく、比較カテゴリも揃わない
      - 両社の広告投下量 → セグメント別は非開示
      - →**「選ばれている量の差」までが言えること。「なぜ選ばれていないか」は断定できない**
  - 解決策
    - 358万人を3層に分ける（性質が違うので同じ施策では取れない）
    - **A｜併用未獲得層**：他社に登録済みだが doda は未登録 → **乗り換えではなく併用させる**
      - 乗り換え訴求をやめる。「今のサービスはそのままで、doda を"自分で探す用"に足す」に変える
      - 他社で作成済みの職務経歴書をアップロードするだけで登録完了にする（入力項目ゼロ）
      - 独占求人を登録前に一部見せる。併用する理由を先に提示する
      - 武器：**転職サイトとエージェントを1つのIDで使えるのは doda だけ**（出典：[LINK](https://www.persol-group.co.jp/ir/upload_file/m005-m005_09/IRDAYCareerJP.pdf) p.15-16）
      - 測定：新規登録者に占める他社併用者の比率／職務経歴書アップロード経由の登録数
    - **B｜未行動層**：転職希望はあるがどこにも登録していない → **顕在化させる**
      - 年収診断・キャリア診断・市場価値診断を**登録不要**で提供し、結果の保存で会員化する
      - PERSOL MIRAIZ のキャリア自律支援・コミュニティを転職意思決定の**前段**に置く（出典：[LINK](https://www.persol-group.co.jp/ir/upload_file/m005-m005_09/IRDAYCareerJP.pdf) p.32, p.35「集めるチカラ」の強化）
      - 「転職しない選択肢」を含むキャリア相談を提供し、顕在化したときの第一想起を取る
      - 測定：診断コンテンツ実施数 → 会員登録の転換率／非転職目的での登録者比率
    - **C｜休眠層**：過去に登録したが当年は稼働していない → **再活性化する**
      - 賞与支給後・期初・昇給発表後など、転職検討が再燃する時期に絞って接触する
      - 「今のあなたの市場価値」を、前回の登録情報と年収相場データ（約60万件）から個別提示する
      - doda・doda X の ID統合で離脱したユーザーに個別に再接触する
      - 測定：休眠会員の再稼働率／再接触あたりの獲得単価（新規獲得単価との比較）
    - 目標配分（**各層の規模が未測定のため仮置き**）
      - A 13万2,000人（50%）／B 7万9,000人（30%）／C 5万3,000人（20%）＝ 26万4,000人
      - 358万人に対する獲得率 **7.4%**
    - 最初にやること
      - **Phase 0：3層の規模を実測する。** ここが決まらないと配分に根拠がない
      - 詳細 → [03_未リーチ358万人の獲得企画.md](03_未リーチ358万人の獲得企画.md)

- **法人**
  - data
    - 就職者数
      - リクルート
        - 87,754人（出典：[LINK](https://jinzai.hellowork.mhlw.go.jp/)　有料職業紹介事業者の報告値のうち「4か月以上有期および無期」の就職者数　かつ許可番号：13-ユ-317880）
      - パーソル
        - 60,307人（出典：同上　許可番号：13-ユ-304785）
      - GAP
        - 27,447人
      - ※ この出典を使う根拠
        - リクルートが「転職決定数No.1」の根拠として同じデータを注記※1に挙げている（出典：[LINK](https://www.r-agent.com/business/)）
        - リクルートの自社公表は「約8万5,000名」。定義差で行政報告値と約2,750人ずれる → **比較は行政報告値で揃える**
  - 要因
    - **step1｜決定率を変数として置く**
      - わかっているのは「就職者数」と「年間登録者数」の2つだけ
      - 就職者数 ＝ 年間登録者数 × 決定率　… ①
      - ①を変形すると　**決定率 ＝ 就職者数 ÷ 年間登録者数**
        - パーソル　60,307 ÷ 1,760,000 ＝ **3.43%**
        - リクルート　87,754 ÷ 2,024,000 ＝ **4.34%**
        - 差　**0.91ポイント**
      - ※ **決定率は両社とも公表していない。**上の式で逆算して出した変数
    - **step2｜GAP 27,447人を①の2つの変数に配分する**
      - 登録者数の差による分　（2,024,000 − 1,760,000）× 3.43% ＝ **9,046人（33%）**
      - 決定率の差による分　1,760,000 ×（4.34% − 3.43%）＝ **16,001人（58%）**
      - 2つが同時に動く分　264,000 ×（4.34% − 3.43%）＝ **2,400人（9%）**
      - 合計 27,447人
      - →GAPは「登録者数」と「決定率」の**2つの負け**でできている
    - **要因①｜登録者数が26万4,000人少ない（9,046人分）**
      - 内容は個人の要因と同じ（リーチ率33.0% vs 37.9%／利用経験率31% vs 49%）
      - 母数が少なければ、決定率が同じでも就職者数は少なくなる
    - **要因②｜決定率が0.91ポイント低い（16,001人分）**
      - わかること：0.91ポイントの**一部は定義差で説明できる**
        - 分母の範囲が違う
          - パーソル176万人＝Career SBU全体の「転職希望者数」（人材紹介＋求人メディア＋ダイレクトリクルーティング）
          - リクルート202.4万人＝「リクルートエージェント」単体への申込者数
          - →パーソルの分母には**エージェントを使っていない人が含まれうる**。分母が広ければ決定率は下がる
        - 年度が違う（パーソルFY2023／リクルートFY2025）
          - doda会員数は +11.3%/年で増えている（FY25Q4 1,006万人・出典：[LINK](https://www.persol-group.co.jp/ir/upload_file/m009-/FY2025Q4presentation.pdf) p.26）
          - →分母を新しくすると決定率はさらに下がる。**年度ずれは差を小さく見せてはいない**
      - **わからないこと：どの工程で落ちているかは内部データがないと判別できない**
        - 登録 → 面談 → 求人紹介 → 応募 → 選考 → 内定 → 入社 のうち、次のどれなのかが分からない
          - そもそも接触できておらず面談に至っていない
          - 面談はできているが紹介できる求人がない
          - 紹介はできているが応募・選考で決まらない
          - 意思決定できずに離脱している
        - 両社とも工程別の歩留まりを開示していない
        - →**「供給能力が足りない」とは言えない。**打ち手を決めるには社内データが要る（→解決策 ①）
      - 参考｜会社自身の見立て（**GAPの原因の証明ではない**）
        - パーソルはFY2028目標に「カウンセリング実施率 1.2倍」「登録決定率 1.3倍」を掲げている（出典：[LINK](https://www.persol-group.co.jp/ir/upload_file/m009-/20260703_release_IRDAY2026.pdf) p.15）
        - →会社は登録〜カウンセリングの工程に伸びしろがあると見ている、ということまでは言える
    - **要因ではないと確認できたもの**
      - 手数料率：パーソル31.7〜33.1% ／ リクルート31.4〜33.4%（令和7年度・職種別）→ **価格ではない**
      - 6か月以内離職率：パーソル5.49% ／ リクルート5.97% → **紹介の質でもない**
  - 解決策
    - 必要な伸びは2つだけ
      - 年間登録者数　176万人 → 202万4,000人（**×1.15**）
      - 決定率　3.43% → 4.34%（**×1.27**）
      - 87,754 ＝ 2,024,000 × 4.34% なので、この2つが揃えばGAPは埋まる
    - **① 要因②（16,001人）に対して：まず落ちている工程を特定する**
      - 打ち手より先にデータを取る。工程が違えば打ち手が全く変わるため
        - 登録 → 面談実施 → 求人紹介 → 応募 → 選考通過 → 内定 → 入社 の**各歩留まりを社内データで出す**
        - 「**エージェント経由の登録者だけ**」を分母にした決定率を出す（定義差を消す）
        - この2つで、0.91ポイントのうち**定義差の分と実力差の分が分離できる**
      - 分離したあとに打ち手を決める（今の段階では特定の施策に決め打ちできない）
        - 面談に至っていないなら → 一次対応の自動化・面談キャパシティ
        - 紹介できる求人がないなら → 求人の確保と占有
        - 選考で決まらないなら → 採用要件定義の上流支援・選考通過率の改善
      - 目標水準は既存計画で足りる
        - 会社計画の「登録決定率1.3倍」が達成できれば 3.43% × 1.3 ＝ **4.45%** でリクルート（4.34%）を上回る
        - →**新規施策ではなく、既存の中計を完遂できるかの問題**
    - **② 要因①（9,046人）に対して：未リーチ層を取りに行く**
      - 個人の解決策（A 併用／B 顕在化／C 休眠再活性化）をそのまま実行する
      - 必要なのは ×1.15＝+26万4,000人、358万人の7.4%
    - **③ 2つを同時に管理する**
      - 併用促進（A）で登録者を増やすと、**他社で決まる人も増えるため決定率は下がりうる**
      - →登録者数と決定率は片方だけ見ない。**就職者数＝登録者数×決定率 の両方で追う**
      - 生産性を「売上÷人員」だけでなく「**決定数÷人員**」でも見る
        - 現在の公表定義は「売上÷人員」（出典：[LINK](https://www.persol-group.co.jp/ir/upload_file/m009-/FY2025Q4presentation.pdf) p.26）
        - 単価が上がれば件数が減っても数字は良くなるため、法人KPIの悪化が指標に映らない
      - FY2028のKGIは「売上収益YoY+7〜10%」「調整後EBITDAマージン20%以上」のみで**件数目標がない**（出典：[LINK](https://www.persol-group.co.jp/ir/upload_file/m009-/20260703_release_IRDAY2026.pdf) p.14）
        - →法人KPI＝就職者数で勝つなら、**件数をKGIに入れる必要がある**

## 補足

- **「登録者を就職に変える割合が0.91ポイント低い」を破棄した理由**
  - 決定率がどこから出た数字か書いていなかった（実数ではなく、就職者数÷登録者数で逆算した変数）
  - 就職者数＝登録者数×決定率なので、そのままでは**現象の言い換え**にしかならない
  - 登録者数のGAP（26万4,000人）と**二重計上**になっていて、どちらの寄与か分からない
  - → step1（導出）→ step2（配分）→ 要因①②、の順に書き直した

- **「供給能力が足りない」という書き方も破棄した理由**
  - 根拠にしていたのは「カウンセリング実施率1.2倍目標」「フロント人員△9.2%」の2つ
  - どちらも事実だが、**それが決定率の低さの原因である証明にはならない**
  - CAが接触できていないのか、紹介まで進んで決まっていないのかは、**工程別の内部データを見ないと判別できない**
  - → 会社の見立てとして「参考」に落とし、断定をやめた

- **参考：観測できる事実（因果は主張しない）**
  - doda会員数 +11.3%（1,006万人）に対し、人材紹介のフロント人員は △9.2%（2,729人）（FY2025Q4）
  - 就職者数が初めて減った令和7年度（−0.7%）は、人員を9.2%減らし生産性（売上÷人員）を15.9%上げた年
    - FY2023 人員2,355人／就職者56,434人（+21.0%）
    - FY2024 人員3,005人／就職者60,747人（+7.6%）
    - FY2025 人員2,729人／就職者60,307人（**−0.7%**）
  - ハイクラス（年収600万円以上）の転職希望者は104万人、ボリューム層（400〜600万円）は430万人
  - ※ リクルート側の人員数は非開示のため、**両社比較はできない**

- **前提とリスク**
  - To Beはリクルート横ばい前提。Indeedとの統合（インディードリクルートパートナーズ・2025年4月〜）で伸びれば目標は上振れする
  - 市場534万人はパーソルの2022年市場調査。2026年時点の実態とずれる可能性がある
  - 「今後2〜3年は企業の厳選採用傾向は継続」（IR DAY 2026 p.13）→ ボリューム層の決定は取りにくい環境が続く

- **まだ取れていない数字**
  - パーソルの年間登録者数 FY2024・FY2025（IR-DAY 2024 p.10 のFY23 176万人が最後の開示）
  - パーソルの「転職希望者数」の正式定義（脚注は「FY23累計」のみで対象範囲の記載なし）
  - 両社の工程別歩留まり（登録→面談→紹介→応募→内定→入社）
  - リクルートエージェントのコンサルタント数（非開示）
  - 株式会社リクルート（13-ユ-313011）の令和6年度以前の就職者数（詳細ページがサーバーエラー）
  - 人材サービス総合サイトの再取得（2026-08-24取得のまま。日曜22:00〜翌8:00は定期メンテ）
