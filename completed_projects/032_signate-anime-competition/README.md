# SIGNATE

SIGNATE主催のデータ分析コンペティションをまとめるフォルダです。今後SIGNATEの別コンペに参加する場合は、`signate_anime/` と同様にこの直下へ新しいフォルダを追加してください。

## フォルダ構成

### `signate_anime/`
小説・アニメ系テキストデータを扱うコンペの分析（旧フォルダ名のタイポ `sigante_anime` を修正済み）。

- `Data/` — 配布データ（`base_stories.tsv` 等）
- `tutorial/` — チュートリアル用ノートブック
- `Analysis_file_1st/` 〜 `Analysis_file_4th/` — 提出ごとの分析イテレーション（回を追うごとに手法を発展させている）
- `output/` — 提出用CSVの出力先

各 `Analysis_file_*` 内のノートブックはそのフォルダの `README.md`（存在するもの）で内容を確認できます。
