# 03_unemployment_lca_gis（業種別完全失業率×潜在クラスモデリング×GIS地理分析）

## 目的
業種別の完全失業率を規定する潜在的要因を、業種の労働特性（賃金・勤続年数・労働時間・倒産件数）から潜在クラスモデリング（LCA、主手法）で明らかにし、都道府県別の産業構成比を介した地理レイヤー（曝露度算出・空間統計・マッピング）を統合して、業種特定に基づく解決方法を検討する。

詳細な要件定義・確定事項サマリは [`docs/要件定義書.md`](docs/要件定義書.md)（7章に確定事項一覧、8章に分析実行プラン）を参照。

## 状況
要件定義はほぼ確定し、分析実行プラン（8章、Step 0〜5、タスク表レベルまで詳細化済み）まで作成済み。Step 0（データ収集）から着手する段階。

**確定した設計の要点**：
- 分析単位は業種（全国・詳細業種）を主軸とし、都道府県は産業構成比を介した「高リスク業種クラスへの地域曝露度」という地理レイヤーとして統合する
- 完全失業率はLCAの指標に含めず、クラス決定後の事後比較として扱う（トートロジー回避）
- 空間統計（Moran's I等）は最初から実施予定に含める
- `02_industry_labor_economics` のOLS分析も並行して行ってよい
- 観測変数の候補は幅広く収集する方針（4.2節）で確定。最終的にどう組み合わせて潜在変数にするかはStep 1の統計解析後に判断
- 追加調査により、国勢調査で「産業大分類×都道府県」の就業者構成比が確認でき、地理レイヤーの精度を格上げ（当初の1次/2次/3次のみから）
