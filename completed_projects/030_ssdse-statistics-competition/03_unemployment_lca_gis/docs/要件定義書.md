## 3. 次期サイクルの戦略

課題の重大度・緊急度・依存関係（第2章）に基づき、次期サイクルを3段階で進める。

**第1段階（最優先）：全変数の年次化でdistalとLTAの土台を固める**
- C2（業種別×都道府県の真の失業率＝年次）とC3（全10観測変数を2019-2025で年次化）を並行して着手する。両者は同じ統計（労働力調査・雇用動向調査・職業安定業務統計等）の年次版を探索する点で作業が重なるため、データ収集を共同で行う。**完全失業率の県別年次化を最優先**とし、時系列distal／時系列潜在クラスの前提を確保する。

**第2段階：因果への接近**
- 第1段階で取得した時系列データを用いて、C6（t→t+1の時系列順序を組み込んだdistal分析）に着手する。C2・C3が未解消のまま着手すると被説明変数・説明変数のいずれかが断面のままになるため、着手順序を厳守する。

**第3段階：モデルのソフト化と統計的頑健性の確認**
- **C8（所属確率の層化＝モデルのソフト化）**は、C3の年次化で変数・時間変動が増えた効果を確認したうえで実装する（M1→M2の順）。GMM共分散の full/tied 化・正則化、または本来のカテゴリLCA化を試し、層状のソフトな所属確率が得られるかを検証する。
- C1（観測変数拡充）、C4（K再選定）、C7（感度分析）は、第1・2段階の結果に影響されうるため後段に置く。特にC4はサンプル数が変わるとBIC最小Kも変わりうるため、C2・C3のデータ拡充後に再実施する方が効率的。C5（年次アライン）はC3（M1）に統合済み。

この段階分けは第10章のPDCAテーブルの実行順序にそのまま対応する。

## 4. リサーチクエスチョン（更新版）

**業種別・都道府県別の労働市場は、労働特性からどのような潜在的な型（潜在クラス）として規定されるか。その型は地理的にどう分布し、時間とともにどう遷移（LTA）するか。型と（業種別の）完全失業率の関係は、時系列順序（t→t+1）と交絡の調整のうえでどう説明できるか。これらを踏まえ、業種特定に基づく具体的な対策にどう結びつくか。**

前版（改訂版）§2からの変更点：
- 「完全失業率」を明示的に**業種別（前職産業別×都道府県）の真の完全失業率・年次(2019-2025)**（C2で取得予定）に更新する。取得できない場合は県レベル年次にフォールバックする旨を維持。
- 「調整済みの関連」を「**時系列順序（t→t+1）と交絡の調整のうえでの関連**」に強化する（C6）。
- 型（潜在クラス）の所属は**単一クラスへの決め打ちではなく、層状のソフトな所属確率**として推定する（C8）。

## 5. 分析設計の変更点

各節は第2章の課題番号に対応する。

### 5.1 業種別×都道府県の完全失業率の取得（C2対応・distal）
- 労働力調査の詳細集計・産業別雇用者/失業者統計等から、**前職産業別×都道府県**の完全失業者数の取得可否を再調査する（**年次2019-2025**）。
- 取得できた場合：`失業率 = 失業者 ÷ 労働力人口` を業種別・都道府県別・年次で算出し、distal outcomeを現行の県レベル（全産業・2020単年）から差し替える。
- 取得できない場合：**県レベルの完全失業率を年次(2019-2025)化**したものをdistalとして用い（M1で必須取得）、「業種別の真の失業率は取得不能」と明記し続ける。＝どちらに転んでも**distalは年次化する**（時系列distalの前提）。

### 5.2 全観測変数の年次化（M1／C3対応・C5統合）
- **方針（対話で確定）**：現行10観測変数を**すべて2019-2025で厳密に時系列化**する（賃金系のみ時変・他は断面値の全年複製をやめる）。
- 変数別の年次取得（Step0'でWeb検証）：
  - **完全失業率・有効求人倍率・人口密度・高齢化率**（県）＝毎年公表 → 年次取得（容易）。
  - **離職率・入職率**（県×産業）＝雇用動向調査を各年取得（県×産業クロスの粒度を要確認）。
  - **就業構成（女性/高齢/若年就業比率・就業シェア）**（県×産業）＝国勢調査は5年毎のため、**労働力調査（地域・年次）で年次代替**、または**年次で取得可能な代替変数へ置換**する（対話で確定した方針）。中間年をどうしても埋められない変数のみ補間可とし、補間フラグを付す。
- 取得・年次化できた変数から順にパネルを時系列化し、LTAを再推定して滞留確率（現行0.96-0.97）の変化を確認する。

### 5.3 時系列順序（t→t+1）の組み込み（C6対応、第1・2段階完了後に着手）
- 5.1・5.2で時系列化できたデータを用い、「先の期(t)の労働特性・LCAクラス → 後の期(t+1)の完全失業率」の向きでdistal分析を再設計する。
- 交絡（人口密度・高齢化率・有効求人倍率）は引き続き共変量として調整する（`方針書_業種別LCA再設計.md` 第2章の因果戦略を継承）。
- 到達点の線引き（主張水準）は「時系列順序づけと交絡調整のうえでの調整済みの説明」までとし、実験的因果は主張しない方針を維持する。

### 5.4 観測変数の拡充（C1対応、第3段階）
- 現行、単一変数の構成概念（PC1賃金処遇・PC3労働需給・PC4労働時間負荷）を複数変数化できないか、職業安定業務統計・雇用動向調査の追加表を精査する。
- 複数変数化できた構成概念は構成概念PCAを再実行し、第1主成分の寄与率を確認する。

### 5.5 K選定の再評価（C4対応、第3段階）
- C2・C3でレコード数・変数が変わった後、K=2〜7（必要に応じてK=8以上も）でAIC/BIC/相対エントロピーを再算出する。
- K=5（可視化用）とK*（BIC最小）の乖離が縮小するか確認し、縮小しない場合はK=5固定の理由（レーダー可視化目的）を維持する。

### 5.6 年次アラインの更新（C5対応→M1に統合）
- C5（年次ずれ）はM1（5.2＝全変数の年次化）に統合済み。就業構成・年齢構成は5.2の方針（労働力調査で年次代替／変数置換／必要時のみ補間）で年次化する。
- 国勢調査2025公表後は、就業構成・年齢構成の断面を2020→2025に更新し、5.2の年次系列の精度を上げる（第3段階の追補）。

### 5.7 頑健性・感度分析（C7対応、第3段階）
- 比率補完あり/なし版、大都市圏（東京都等）除外版、年次補間あり/なし版を比較し、クラス構成・上位県順位・distal関連の頑健性を確認する（前版（改訂版）§3.8の感度分析方針を実行に移す）。

### 5.8 所属確率の層化＝モデルのソフト化（M2／C8対応、第3段階）
- **問題**：連続主成分に対するGMM（diag, K=5）は分離が鋭く（相対エントロピー0.86-0.92）、各都道府県の所属確率がほぼ単一クラスに集中して「層」にならない。
- **方針（対話で確定：モデルをソフト化）**：
  1. GMMの共分散構造を **diag→tied/full** に変更し、`reg_covar`（正則化）を強めてクラス境界を緩める。
  2. 効果が不十分なら、観測変数をカテゴリ/順序尺度に離散化した**本来のLCA（項目反応確率）**へ変更し、参照論文と同じソフトな所属確率を得る。
  3. **年平均で潰さず**、都道府県×年ごとの所属確率も保持して層状の分布を確認する。
- **検証**：複数クラスに％が分散する県が増えるか（支配確率<0.9の割合）、加重失業率（個別リスク）の分解が解釈可能かを確認する。
- **留意**：型が本来明瞭に分かれている場合、緩めすぎは人為的になりうるため、分離度（エントロピー）とのトレードオフを明記する。M1（5.2）で変数・時間変動が増えた効果を先に見てから実装する。

## 8. 事前決着事項

前版（改訂版）§6の6項目を継承しつつ、次期サイクルで新たに想定される限界を追加で事前決着する。

**継承（既存6項目、要約）**：①賃金等の県×産業非公表→比率補完＋フラグ、②年次解像度の薄さ→年次ウェーブ＋補間、③県×産業指標の欠損→欠損>20%は除外、④K=5の統計非最適→K=2〜7を必ず報告、⑤前職産業ベースの失業率→分母＝労働力人口、非公表なら県レベルにフォールバック、⑥観察データの因果限界→「調整済みの説明・動学的記述」に主張水準を固定。

**追加（次期サイクル分・改訂版3で確定）**：
1. **業種別失業率が取得できない場合**：C2は「取得トライ→不可なら**県レベルの完全失業率を年次(2019-2025)化**して維持」を事前ルール化する（2020単年には戻さない）。取得可否の探索は1スプリント以内で判断。
2. **M1で変数ごとに年次取得可否が分かれる場合**：年次化できた変数から順次時系列化しつつ、**年次化できない変数は年次取得可能な代替変数への置換を検討**する（就業構成が典型）。どうしても不可なら補間フラグ付きで補間、または当該変数を落とす。
3. **t→t+1分析でサンプルが小さくなる場合**（時系列が揃う年数が少ない）：最低限のサンプル数を確保できない場合は、断面distalとの併記にとどめ、時系列順序の主張は「参考」扱いとする。
4. **K再選定でK=5と結果が大きく変わる場合**：レーダー可視化との整合を優先しK=5を主版としつつ、K*版を統計的頑健性チェックとして併記する（現行方針の継続）。
5. **M2（層化）でモデルを緩めても層が出ない／緩めすぎで解釈不能になる場合**：共分散のfull/tied化・正則化・カテゴリLCA化を段階的に試し、**分離度（エントロピー）と層の見やすさのトレードオフを明記**する。どうしても層が出ない場合は「データ上、型が明瞭に分かれている」という結果として受け入れ、連続リスクスコア（加重失業率）で濃淡を補助表示する。
