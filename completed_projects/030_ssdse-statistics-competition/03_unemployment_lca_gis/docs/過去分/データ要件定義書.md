## 3. 多重共線性・ばらつき分析結果

### 3.1 相関行列（Pearson r）

|  | unemployment_count | bankruptcy_count | 勤続年数 | 超過実労働時間数 | 所定内給与額 |
|---|---|---|---|---|---|
| unemployment_count | 1.000 | 0.831 | -0.057 | -0.219 | -0.390 |
| bankruptcy_count | 0.831 | 1.000 | 0.062 | -0.237 | -0.339 |
| 勤続年数 | -0.057 | 0.062 | 1.000 | -0.048 | 0.255 |
| 超過実労働時間数 | -0.219 | -0.237 | -0.048 | 1.000 | -0.587 |
| 所定内給与額 | -0.390 | -0.339 | 0.255 | -0.587 | 1.000 |

### 3.2 高相関ペア検出結果

| ペア | 相関係数 | 判定 |
|---|---|---|
| unemployment_count ↔ bankruptcy_count | 0.831 | 中程度相関（0.7 < r < 0.9） |

**結論**: |r| > 0.9 の高相関ペアなし。すべての LCA 入力変数を同時投入可能。

### 3.3 年別ばらつき検証（CV 分析）

| 変数 | 高ばらつき業種率 (CV > 0.3) | 判定 |
|---|---|---|
| bankruptcy_count | 11% | Year pooling OK |
| 勤続年数 | 0% | Year pooling OK |
| 超過実労働時間数 | 0% | Year pooling OK |
| 所定内給与額 | 0% | Year pooling OK |

**結論**: 複数年プール方式（要件定義書3.4節方法1）の採用を確認。

## 7. 用語定義

| 用語 | 説明 |
|---|---|
| **LCA (Latent Class Analysis)** | 観測変数から隠れたクラスを抽出する統計手法 |
| **Distal Outcome** | LCA のクラス分類後に測定される外的変数（ここでは失業者数） |
| **多重共線性** | 説明変数間の高い相関（LCA では問題になりにくいが確認は重要） |
| **CV (Coefficient of Variation)** | 標準偏差 ÷ 平均。年別ばらつきの大きさを判定 |
| **BIC (Bayesian Information Criterion)** | モデル比較用の情報量基準。低いほど良い |
