## 詳細解釈

### クラス特性の比較

**Class 1**（n=19観測値）
- **特徴**：中小規模・安定型
  - 倒産件数が少ない（平均108件）→ 経済的に安定した業種
  - 勤続年数が高い（15.05年）→ 従業員の離職率が低い
  - 超過実労働時間が少ない（10.98時間）→ 過労がない健全な職場
  - 給与が高い（439千円）→ 労働生産性が高い

- **該当業種**：農・林・漁・鉱業、金融・保険業
  - 農・林・漁・鉱業：小規模で安定、従業員定着率高、給与水準維持
  - 金融・保険業：専門職、高給与、安定雇用

**Class 2**（n=62観測値）
- **特徴**：大規模・変動型
  - 倒産件数が多い（平均1186件）→ 経済変動に敏感な業種
  - 勤続年数が低い（13.84年）→ 人的流動性が高い
  - 超過実労働時間が多い（14.07時間）→ 労働強度が高い傾向
  - 給与が低い（353千円）→ 低スキル労働の比率が高い可能性

- **該当業種**：サービス業他、卸売業・小売業、製造業ほか
  - サービス業他：非正規雇用割合が高く、人的流動性が大きい
  - 卸売業・小売業：季節変動・販売変動に左右される
  - 製造業：経済サイクルの影響を受けやすく、採用・離職が激しい

### ターゲット業種がClass 2に統一される理由

ターゲット業種（サービス業他、製造業、卸売業・小売業）がすべてClass 2に属するのは、以下の共通特性による：

1. **失業者数の変動が大きい**（Step 2での選定基準）
   - 経済サイクルに敏感な業種が集中
   - 企業倒産件数の変動が大きい

2. **労働市場の不安定性**
   - 人的流動性が高く、雇用調整が容易
   - 景気悪化時に失業が急増する傾向

3. **分析の有効性**
   - Step 2で「失業者数の変動が複合的に大きい」と判定されたのは、
     これらが経済変動により敏感だからである
   - LCAにより、その不安定性の根底にある労働特性プロファイルが
     可視化された

### クラス間の労働特性の乖離度

Class 1 と Class 2 の差は以下の通り：
- **倒産件数の差**：1078件（Class 2がClass 1の約11倍）
- **給与の差**：86千円（Class 1の方が高い）
- **勤続年数の差**：1.21年

これは、雇用の質（給与・安定性）と雇用の量（流動性・倒産影響）の明確な対比を示しており、
LCAにより二つの異なる産業生態系が識別された。
