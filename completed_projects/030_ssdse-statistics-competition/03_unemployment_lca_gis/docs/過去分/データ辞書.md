## 3. 完全失業率データ（計算済み）
**ファイル名**: `data/processed/unemployment_rate_by_industry.csv`

| 項目 | 内容 |
|---|---|
| 計算方法 | （失業者数 ÷ 労働力人口）× 100。労働力人口 = 就業者数 + 失業者数（国勢調査の業種別就業者数を集約） |
| 時間範囲 | 2005, 2010, 2015, 2020年（国勢調査に準拠） |
| 地域範囲 | 全国（全国の集計） |
| 業種粒度 | **業種（9分類）**（失業者数データと統一） |
| 主要変数 | 就業者数（人）、失業者数（人）、労働力人口（人）、完全失業率（%） |
| 行数 | 36行（9業種 × 4年度） |
| 結合キー | **業種、年度** |
| 備考 | **LCAに投入する際は、この完全失業率を「指標」に含めない**（distal outcome として事後比較のみ）。理由：要件定義書 3.2節の「トートロジー回避」 |

## データ統合の主要軸（結合キー）

### 業種側テーブル（全国粒度）
- **結合キー**: 業種（9分類）、年度
- **含まれるテーブル**: 失業率、労働特性、倒産件数、学歴別給与
- **対応する国勢調査コード**: 上記「業種マッピング」参照

### 地理側テーブル（都道府県粒度）
- **結合キー**: 都道府県、年度
- **含まれるテーブル**: 国勢調査（都道府県別産業構成比）、GIS地理データ
- **業種側との統合**: 都道府県別産業構成比（国勢調査）× 業種LCAの「業種→クラス」対応表 から「高リスククラスへの地域曝露度」を算出

## 補足：年度の整合性と扱い方

| テーブル | 利用年度 | 注記 |
|---|---|---|
| 国勢調査 | 2005, 2010, 2015, 2020年 | 5年ごと。最新は2020年 |
| 失業者数 | 2014, 2018, 2019, 2020年以降 | 最新データが利用可能。LCA投入時は複数年をプール |
| 失業率（計算済み） | 2005, 2010, 2015, 2020年 | 事後比較用。LCA指標には含めない |
| 労働特性 | 2014, 2018, 2019, 2020年 | LCA指標として使用 |
| 学歴別給与 | 2006～2025年 | 最長の時系列。LCA用に特定年度を選択 |
| 倒産件数 | 複数年 | LCA指標として使用 |

**方針**：要件定義書 3.4節に従い、「両データを無理に同一年に揃える必要はなく、それぞれのレイヤーで入手可能な最大範囲を使う」。業種LCAは複数年をプール（3.4節「方法1」を最初に試行）し、年別横断面LCAへの移行は Step 1の「複数年ばらつき検証」で判定する（3.4節参照）。
