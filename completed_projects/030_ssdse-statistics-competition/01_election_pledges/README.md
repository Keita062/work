# 01_election_pledges（選挙公約テキスト分析）

## 目的
2025年衆議院・参議院選挙における各政党の公約テキストを分析し、「2025年の日本の有権者が直面する社会課題は何か、政党の政策優先度とどう対応しているか」を、テキスト分析（言及率）とSSDSE公的統計（社会指標）の突き合わせから明らかにしようとしたテーマ。

## 結論（一区切り）
- 第1優先課題: 地域経済格差による生活困窮（地方創生の言及率が最高、食料支出格差10.6%と対応）
- 第2優先課題: 高齢化社会への不安（医療・介護、社会保障の言及率が上位）
- 第3優先課題: 労働条件と生活保障の統合的課題（部分的対応にとどまる）

詳細な根拠は [`事前分析の結論.md`](事前分析の結論.md)、分析全体の方針は [`分析計画.md`](分析計画.md) を参照。

## 状況
この結論を踏まえてコンペのテーマを一度決定したが、その後 [`../02_industry_labor_economics/`](../02_industry_labor_economics/README.md)（産業別労働経済分析）へ方針転換し、本テーマは一区切りとなっている。再開する場合は下記フォルダの続きから着手できる。

## フォルダ構成（時系列順の作業ログ）
- `data/` — 公約テキストの元データ（衆議院・参議院、公的データ）
- `04_28/` — Phase1（テキスト前処理・言及率抽出）〜Phase3a（社会統計との相関分析）の実装。`results/` に成果物・レポート
- `05_11/` — データ準備の再整理（`docs/research_planning.md` に方針）
- `05_12/` — 完全失業率データの追加検討（`データ方針書.md`）
- `election/` — 公約データ本体（`2025_shu/`, `2025_san/`）、NLP分析ノートブック、統計分析計画・解釈レポート
- `results/` — 統合分析結果（トピックモデリング、RQ別集計等）
- `scripts/` — `extract_manifesto.py`（公約抽出）、`election/`（データローダー・分析パイプライン一式）
