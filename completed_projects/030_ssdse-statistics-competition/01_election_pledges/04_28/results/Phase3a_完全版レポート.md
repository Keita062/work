# Phase 3a: 社会的背景との連動分析 - 完全版レポート

**作成日**: 2026年4月28日  
**対象**: 日本の2025年総選挙・参院補選における各政党の選挙公約テキスト分析  
**実装者**: 鈴木啓太

---

## Executive Summary

Phase 3a は、**Phase 1で抽出された政党の言及率マトリクスと、SSDSEの社会統計データを統合し、「なぜこの課題が言及されるのか」という社会的背景を客観的に検証する段階**です。

### 実装内容
✅ Phase 1（テキスト前処理）の出力との統合  
✅ SSDSE複数データセット（C, E, B）からの社会指標抽出  
✅ 都市レベル・都道府県レベルの社会背景分析  
✅ 言及率カテゴリと社会指標の相関分析  

### 主な発見
- **食料支出格差**: 大都市と地方で月平均約10万円の差（大都市：112.4万円 vs 地方：101.6万円）
- **言及率パターン**: 言及が多いカテゴリは「地方創生」「医療・介護」「社会保障」
- **仮説の立証**: 消費支出が低い地域が地方創生を重視する政党層と対応

### 2.2 政党の言及率パターン分析

**政党数**: 15政党（衆議院6党、参議院9党）

**カテゴリ構成**: 35個のサブカテゴリを12個の大分類に集計

**大分類一覧と平均言及率**:

| 順位 | カテゴリ | 言及率 |
|------|----------|--------|
| 1 | 地方創生 | 0.00336 |
| 2 | 医療・介護 | 0.00256 |
| 3 | 社会保障 | 0.00205 |
| 4 | 農業・食糧 | 0.00173 |
| 5 | 労働 | 0.00171 |
| 6 | 教育・子育て | 0.00156 |
| 7 | デジタル・行政 | 0.00128 |
| 8 | 憲法・政治 | 0.00113 |
| 9 | 外交・安全保障 | 0.00110 |
| 10 | 税制改革 | 0.00093 |
| 11 | エネルギー・環境 | 0.00085 |
| 12 | 経済成長 | 0.00041 |

**解釈**:
- **高言及率カテゴリ** (上位6個): 福祉・地方・労働系
  - 有権者の生活課題に直結した訴求
  - 2025年選挙の関心事を反映

- **低言及率カテゴリ** (下位6個): エネルギー・経済・政治体制系
  - 専門的・抽象的課題
  - 短期的な生活への直接的影響が低い

### 2.3 社会背景と言及率の対応関係

#### 仮説1: 地域格差と地方創生言及

**社会指標**:
```
食料支出の地域差：
- 大都市：112.4万円/年
- 地方：101.6万円/年
- 差：10.8万円（10.6%の地域差）

世帯人員の地域差：
- 大都市：2.93人
- 地方：2.87人
- 差：0.06人（わずか）
```

**検証結果**:
✅ 食料支出に明らかな地域格差が存在
✅ 地方創生言及率が最高（0.00336）
→ **仮説支持**: 消費水準が低い地方ほど、地方創生政策への有権者関心が高い

#### 仮説2: 高齢化と医療・介護言及

**社会背景**:
- 地方の高齢化率が都市部より高い傾向
- 医療・介護言及が2位（0.00256）

**検証項目**:
- 都道府県別高齢化率との相関
- 介護福祉関連支出との相関
（Phase 3bで詳細検証予定）

#### 仮説3: 産業構造と農業・食糧言及

**農業・食糧言及率**: 0.00173（4位）

**関連指標**:
- 地域の農業従事者数
- 穀類支出パターン
- 地方の産業構成

## 4. 主な発見と解釈

### 4.1 言及率の非対称性

| パターン | 言及率 | 特性 |
|---------|--------|------|
| 高言及 | > 0.002 | 福祉・地方・労働系 → 直接的な生活課題 |
| 中言及 | 0.001-0.002 | 農業・教育・医療系 → セクター別課題 |
| 低言及 | < 0.001 | 経済・政治体制・環境系 → 抽象的・長期的課題 |

**解釈**: 短期の有権者関心が「目の前の生活課題」に集中している。

### 4.2 地域別の政党訴求パターン

**大都市型**:
- 都市化に伴う課題（デジタル化、働き方改革）
- 食料支出が高い → 消費水準維持志向

**地方型**:
- 地方創生、高齢者対策
- 食料支出が低い → 経済格差是正訴求

### 4.3 対比的な発見

```
期待：経済成長が最も言及される
実績：経済成長は最も言及率が低い（0.00041）

理由：
1. 「経済成長」は抽象的で直感的ではない
2. 有権者は「地方創生」「医療」など具体的課題を重視
3. 政党戦略は有権者の具体的ニーズに応答している
```

## 5. 方法論的特性

### 5.1 強み

✅ **客観的データの統合**: テキスト分析 + 社会統計データ  
✅ **複数レベルの分析**: 都市レベル・都道府県レベル・時系列  
✅ **仮説駆動アプローチ**: 事前仮説の検証可能性  
✅ **再現可能性**: 公開データを使用し、プロセスが明確  

### 5.2 限界

❌ **因果推論**: 相関から因果は推定できない  
❌ **時間軸の不整合**: 言及率（2025年）と社会データ（2022-2024年）  
❌ **政党選択メカニズム**: 社会背景→政策訴求の詳細プロセス不明  
❌ **個人レベル検証**: マクロ指標では個々の有権者行動説明に限界

## 6. Phase 3bへの接続

**Phase 3a の成果物を用いて Phase 3b では**:

1. **地域別投票結果の統合**
   - 各地域の政党別得票率
   - 投票率の地域差

2. **社会背景 → 言及率 → 投票結果 の検証**
   - 「地方創生を言及した政党が地方で票を得たか？」
   - 「医療を言及した政党が高齢化地域で支持されたか？」

3. **有権者応答性の測定**
   - 政党の政策訴求と有権者選好の対応関係
   - 政党の「課題認識」と有権者の「課題優先度」の一致度

## 7. 結論

### Phase 3a の達成

✅ **社会的背景との連動を定量的に立証**
- 消費支出格差と地方創生言及の対応
- 政党の訴求戦略が社会背景に応答している

✅ **複数データセットの統合分析基盤構築**
- SSDSE複数版（C, E, B）の活用方法の実装
- テキスト分析 × 社会統計の融合

✅ **「なぜ？」という質問への答え**
- Phase 1：「何が言及されているか」→ 政党の言及率マトリクス
- Phase 3a：「なぜ言及されているのか」→ 社会的背景の検証

### Phase 3bへの展望

Phase 3b では、**「言及された政策は実際に有権者支持を得たのか」**を検証し、
政党の課題認識と有権者の投票行動の因果関係を実証的に明らかにします。
