# 民意の本質的課題特定：統計分析計画

**作成日**: 2026年4月28日  
**目的**: 衆議院・参議院の選挙公約データと社会統計から、政治ノイズを除外し、有権者が本当に求めている課題を特定する  
**対象データ**: 2025年衆議院選挙公約 + 2026年参議院選挙公約 + 時系列統計指標 + 選挙結果データ

---

## 背景と問題設定

### 既存分析の限界

既に実施されたNMFトピック分析（RQ-1～RQ-4）では、公約テキストの言及頻度に基づいて課題の優先度を判定していた。しかし、以下の問題がある：

1. **テキスト量による絶対的バイアス**
   - 自民党: 37,960字 vs 日本保守党: 54字
   - 言及度数の直接比較が不公平

2. **政治的修辞の混入**
   - 「推進」「実現」「強化」など、全政党が使う虚像的キーワード
   - これらが統計ノイズになっている

3. **「民意」と「政党の言及」の乖離検証がない**
   - 政党が言及する課題が、本当に有権者が求めているか不明

### 本分析の立場

本分析では、**外部データとの照合を通じて「民意」を検証する**ことで、上記の問題を解決する。政治ノイズを完全に除外するのではなく、「民意と一致しているか」をデータドリブンに判定する。

## Phase 1: テキスト前処理

目的：公約テキストから政治的修辞・構造的ノイズを除去し、実質的な政策内容を抽出する。

### Step 1: 全政党共通スローガンの除去

**背景**:  
全政党が同一の表現（「〜を推進する」「〜を実現する」など）を繰り返す。これは「課題の重要性」ではなく「言文体」の差異であり、分析ノイズである。

**方法**:  
全政党の80%以上で出現するキーワードを完全に除去する。

**実装手順**:

```python
# 1. 形態素解析で全政党テキストを分解
# 2. 名詞・動詞・形容詞のみを抽出（助詞・助動詞は除外）
# 3. 各キーワードが出現した政党数を集計
# 4. 全政党数の80%以上に出現 → 除去対象
# 5. 除去対象キーワードをテキストから削除
```

**出力例**:

```
除去対象キーワード（8政党中6党以上で出現）:
- 「推進」（8/8政党）
- 「実現」（8/8政党）
- 「強化」（8/8政党）
- 「改革」（7/8政党）

処理前：「経済成長を推進して、脱炭素社会の実現を強化します」
処理後：「経済成長」「脱炭素」（修辞を削除）
```

**期待される効果**: テキスト量の政党間バイアスを30～50%削減。

---

### Step 3: 言及率による正規化

**背景**:  
テキスト長が異なると、課題の「言及度数」も自動的に異なる。例えば、テキスト長が10倍の政党は、単純には「言及度数」も10倍になりやすい。

**方法**:  
各課題について、「言及度数 / 全テキスト単語数」で言及率を計算。これにより、テキスト長の差を中和する。

**言及度数（言及数）の定義**:

各課題の言及度数は、以下のロジックで計算する：

1. **キーワードハイアラーキーの自動抽出**
   - NMFトピック分析結果を利用して、実際の公約テキストから課題ごとのキーワードを抽出
   - 各親カテゴリ（課題）に対して、複数の子キーワード（表現バリエーション）をマッピング
   - 例：「エネルギー」→ [電力, 原発, LNG, CCS, 再生可能, ...]

2. **キーワード出現回数のカウント**
   - Step 1で修辞除去済みのテキストに対して形態素解析を実施
   - 各子キーワードに対して**前方一致検索**を行う
     - 例：「電力」で検索すると「電力系」「電力供給」も該当
   - マッチした単語は親カテゴリに統一してカウント

3. **複数キーワード出現時の処理**
   - **案A（採用）**：各子キーワードを独立してカウント
   - 例：「電力とLNGの供給を拡大」→ エネルギー言及度数：2

4. **言及率の計算**
   - 言及率 = 各課題の言及度数 / テキスト全単語数
   - 結果は0～1の範囲で標準化

**実装手順**:

```python
# 1. ハイアラーキーの自動抽出（NMF結果から構築）
# 2. 各政党のテキストを形態素解析
# 3. 全単語数を集計
# 4. 各課題のキーワード出現をカウント（前方一致）
# 5. 言及率 = 言及度数 / 全単語数

# 出力：政党 × 課題 のマトリクス
# 各セルの値：言及率（0～1）

例：
        経済成長  医療・介護  エネルギー
自民党    0.32      0.08       0.12
立憲民主  0.18      0.22       0.15
参政党    0.28      0.05       0.35
```

**採用した決定項目**:
- ✅ キーワード重複時の処理：各子キーワードを独立してカウント（案A）
- ✅ キーワード出現形態：前方一致も可能（案B）
- ✅ ハイアラーキー構築方法：実際の公約テキストから自動抽出（案B）

**期待される効果**: テキスト長による絶対的バイアスが完全に中和され、政党を横並びで比較可能に。

---

### Step 4: 複合キーワードの統一

**背景**:  
「脱炭素」「脱炭素社会」「カーボンニュートラル」など、同じ概念が複数の表現で言及されると、重複カウントが発生する。

**方法**:  
キーワードハイアラーキーを定義し、複数の表現を親キーワードで統一。

**実装手順**:

```python
# 1. キーワードハイアラーキーを定義

keyword_hierarchy = {
    'エネルギー': [
        'エネルギー', '電力', '原発', '再生可能', 
        'エネルギー安全保障', '火力', 'LNG', 'CCS'
    ],
    '脱炭素': [
        '脱炭素', 'CO2削減', 'カーボンニュートラル', 
        '温暖化対策', '気候変動対策'
    ],
    '経済成長': [
        '経済成長', 'GDP', '成長戦略', '生産性向上', '競争力'
    ],
    # ... その他の課題
}

# 2. テキスト中のすべてのキーワードを親カテゴリに統一
# 3. 複合概念の重複が解消される
```

**出力例**:

```
処理前：「脱炭素社会を実現し、CO2削減を推進する」
処理後：「脱炭素」（2回カウント）→「脱炭素」（1回にカウント）
```

**期待される効果**: 同一概念の重複カウントが除去され、課題別の言及度数が正確になる。

### 分析方法

#### Step 1: 公約作成時期の社会指標を抽出

各政党の公約が作成された時期（通常、衆議院選挙では8月～9月）の社会指標値を記録する。

```python
# 例）2025年衆議院選挙の場合
# 公約作成時期：2025年8月～9月

# その時期の指標値：
social_indicators_at_pledge_creation = {
    '労働・雇用': {
        'unemployment_rate': 2.6,  # 2025年9月
        'job_opening_ratio': 1.23,  # 2025年9月
        'wage_growth': -0.5,  # 前年同月比（%）
    },
    'エネルギー': {
        'power_stress_index': 8.5,  # 逼迫度スコア（通常3～5）
        'electricity_price': 32800,  # 円/kWh
        'renewable_energy_ratio': 22.5,  # %
    },
    '医療・介護': {
        'healthcare_expenditure': 1850000000000,  # 月間総額（円）
        'age_65_ratio': 29.1,  # %
    },
}
```

#### Step 2: 各指標を「通常値からの乖離度」に変換（zスコア化）

```python
# 例）失業率：
# - 2年間（2024年1月～2025年9月）の失業率の平均値：2.3%
# - 標準偏差：0.4%
# - 2025年9月の失業率：2.6%
# - zスコア = (2.6 - 2.3) / 0.4 = 0.75

# zスコアの解釈：
# - zスコア = 0：通常値
# - zスコア > 1：やや異常
# - zスコア > 2：明らかに異常
# - zスコア < -1：通常値より低い（良い方向）
```

#### Step 3: 「課題の社会的背景強度」を計算

各課題について、複数の関連指標のzスコアを統合して、「その課題には社会的背景があるか」を判定する。

```python
def calculate_social_background_strength(topic, indicators_dict):
    """
    特定の課題について、社会的背景強度を計算
    
    出力：
    - background_strength：0～1（0 = 背景なし、1 = 強い背景）
    - direction_consistency：-1～1（各指標が同じ方向に動いているか）
    - individual_zscores：各指標のzスコア
    """
    
    # topic と indicators のマッピングを定義
    topic_indicator_mapping = {
        'エネルギー・環境': [
            'power_stress_index',
            'electricity_price', 
            'renewable_energy_ratio'
        ],
        '労働・雇用': [
            'unemployment_rate',
            'job_opening_ratio',
            'wage_growth'
        ],
        '医療・介護': [
            'healthcare_expenditure',
            'age_65_ratio'
        ],
        # ... 他の課題
    }
    
    if topic not in topic_indicator_mapping:
        return None
    
    relevant_indicators = topic_indicator_mapping[topic]
    zscores = [indicators_dict[ind] for ind in relevant_indicators]
    
    # 複数指標が「同じ方向」に動いているか
    direction_consistency = np.mean([np.sign(z) for z in zscores])
    
    # 指標の「変動幅」
    average_zscore = np.mean(np.abs(zscores))
    
    # 総合スコア
    background_strength = abs(direction_consistency) * average_zscore
    
    return {
        'topic': topic,
        'background_strength': background_strength,
        'direction_consistency': direction_consistency,
        'individual_zscores': dict(zip(relevant_indicators, zscores))
    }
```

**出力例**:

```
【社会的背景強度スコア】

エネルギー・環境:
  background_strength: 2.34 ← 強い背景
  direction_consistency: 0.95 ← 複数指標が同じ方向
  individual_zscores:
    - power_stress_index: +2.1 （通常値の2.1σ上昇）
    - electricity_price: +1.8
    - renewable_energy_ratio: -0.9

  → 解釈：電力逼迫と電気代上昇が同時発生
          社会的に「エネルギー問題」が顕在化していた
          → 有権者の関心が高まったはず
          → この課題は「構造的な民意」の可能性が高い

労働・雇用:
  background_strength: 0.85 ← 中程度の背景
  direction_consistency: 0.33 ← 指標が混在（悪い方向と良い方向）
  individual_zscores:
    - unemployment_rate: +0.6
    - job_opening_ratio: -0.4
    - wage_growth: +0.3

  → 解釈：失業率は高めだが、求人倍率は低くない
          指標が矛盾している
          → 単純な「雇用危機」ではない
          → この課題は「構造性が弱い」可能性

憲法改正:
  background_strength: 0.12 ← 背景が弱い
  direction_consistency: -0.15 ← 指標が矛盾
  individual_zscores:
    - world_opinion_on_amendment: -0.3
    - political_debate_intensity: +0.8

  → 解釈：社会統計に「改正要求」が見当たらない
          政治的議論だけが活発
          → 「イデオロギック争点」の可能性が高い
          → 民意ではなく、政治的対立
```

## Phase 3b: 選挙結果との逆算分析（準因果推論）

**概念**: 「民意の課題」なら、その課題を強調した政党が、より多くの票を得ているはず。例えば、「労働・雇用」を多く言及した政党が、労働者の多い地域で支持を増やしたか確認する。

### ⚠️ 因果推論の限界と解釈

完全な因果推論は不可能（選挙結果には多数の要因が影響するため）だが、以下のレベルで民意を検証できる：

- **相関分析（レベル1）**: 「課題言及」と「得票率」の相関を見る
  - 相関がない → その課題は民意ではない（否定的証拠として機能）
  - 相関がある → その課題は民意と関連している可能性がある

- **重回帰分析（レベル2）**: 複数課題を同時に考慮
  - 「他の課題を統計的に制御した上で」課題言及と得票の関係を見る
  - より因果に近い推定が可能

- **選挙区別・地域別分析（レベル3）**: 最も強い準因果推論
  - 「労働者が多い地域」で「労働政策を強調した政党」が支持されたか
  - 政党の実質的な支持層と、言及課題の整合性を検証

### 分析方法

#### Step 1: 相関分析（基礎レベル）

各課題について、「課題言及率」と「政党の得票率」の関係を計算。

```python
import pandas as pd
from scipy.stats import pearsonr

# 入力データ：各政党について
parties_data = {
    '政党名': {
        'economic_mention': 0.32,      # 経済関連の言及率
        'labor_mention': 0.08,         # 労働関連の言及率
        'energy_mention': 0.12,        # エネルギー関連の言及率
        # ... 他の課題
        'vote_share': 0.35,            # その政党の得票率
        'seats': 316,                  # 獲得議席数
    }
}

# 各課題について、言及率と得票率の相関を計算
for topic in ['economy', 'labor', 'energy', ...]:
    mention_rates = [data[f'{topic}_mention'] for data in parties_data.values()]
    vote_shares = [data['vote_share'] for data in parties_data.values()]
    
    r, p_value = pearsonr(mention_rates, vote_shares)
    
    print(f"{topic}:")
    print(f"  相関係数: r = {r:.3f}")
    print(f"  p値: {p_value:.4f}")
    
    if p_value < 0.05 and r > 0.5:
        print(f"  → 統計的に有意な正の相関")
        print(f"  → この課題は民意と連動している")
    elif p_value < 0.05 and r < -0.5:
        print(f"  → 統計的に有意な負の相関")
        print(f"  → この課題は民意と反対方向に働いている")
    else:
        print(f"  → 相関がない（または弱い）")
        print(f"  → この課題は民意の主要因ではない")
```

**解釈基準**:

```
r > 0.7, p < 0.05:
  ✅ 強い正の相関 → 民意と連動の可能性が高い

0.5 < r < 0.7, p < 0.05:
  ⚠️ 中程度の正の相関 → 民意と関連している可能性

|r| < 0.5 または p > 0.05:
  ❌ 弱い相関または統計的に有意でない → 民意の主要因ではない

r < -0.5, p < 0.05:
  🔴 負の相関 → 課題強調は票を失わせている（虚像的争点）
```

#### Step 2: 重回帰分析（複数要因の統制）

複数の課題を同時に考慮し、「他の課題を制御した上で」各課題の得票への寄与度を計算。

```python
from sklearn.linear_model import LinearRegression
import numpy as np

# 説明変数：複数課題の言及率
X = np.array([
    [party_data['economic_mention'], party_data['labor_mention'], 
     party_data['energy_mention'], party_data['healthcare_mention']],
    # ... 政党数分
])

# 目的変数：得票率
y = np.array([party_data['vote_share'] for party_data in ...])

# 重回帰分析
model = LinearRegression()
model.fit(X, y)

# 各課題の「得票への寄与度」を計算
topics = ['経済', '労働', 'エネルギー', '医療']
coefficients = model.coef_

print("【得票率への寄与度：重回帰係数】")
for topic, coef in zip(topics, coefficients):
    print(f"{topic}: {coef:.4f}")

R2_score = model.score(X, y)
print(f"\nR²スコア（説明力）: {R2_score:.3f}")
print(f"→ 各課題の言及が、得票の{R2_score*100:.1f}%を説明している")
```

**解釈例**:

```
経済：0.850 → 強い正の寄与（経済を強調すると票が増える）
労働：0.043 → ほぼ無寄与（労働言及と得票に関係なし）
エネルギー：0.621 → 強い正の寄与（エネルギー強調は票につながる）
医療：0.285 → 中程度の正の寄与

R²スコア：0.876
→ 各課題の言及が、得票の87.6%を説明している

結論：
✅ 経済・エネルギー → 民意
❌ 労働 → 民意ではない（政党が言及しても票にならない）
```

## Phase 4: 最終民意スコア統合

### スコア計算方法

Phase 3a（社会的背景強度）と Phase 3b（民意連動性）の2つの次元を統合して、最終的な「民意スコア」を計算。

```python
def calculate_final_public_will_score(topic, background_strength, correlation_coef, p_value):
    """
    最終民意スコアを計算
    
    入力：
    - background_strength：社会的背景強度（0～3程度、高いほど良い）
    - correlation_coef：相関係数（-1～1）
    - p_value：相関の統計的有意性（0～1、小さいほど良い）
    
    出力：
    - final_score：0～1（1に近いほど民意）
    - confidence：信頼度（0～1、両指標が一致しているほど高い）
    """
    
    # Step 1: 背景強度を正規化（0～1）
    normalized_background = min(background_strength / 2.5, 1.0)
    
    # Step 2: 相関係数の有意性を反映
    # p値が0.05以下 = 有意 → スコア加算
    significance_weight = 1.0 if p_value < 0.05 else 0.3
    
    # 相関係数が負の場合は虚像的争点
    if correlation_coef < -0.3:
        return {
            'topic': topic,
            'final_score': 0.0,  # 虚像的争点は0
            'confidence': 1.0,
            'classification': '🔴虚像的争点'
        }
    
    # Step 3: 2つの次元を統合
    final_score = (normalized_background * 0.5 + 
                   max(correlation_coef, 0) * significance_weight * 0.5)
    
    # Step 4: 2つの次元が一致しているか（信頼度）
    background_direction = 'strong' if normalized_background > 0.5 else 'weak'
    correlation_direction = 'positive' if correlation_coef > 0.4 else 'weak'
    
    if background_direction == 'strong' and correlation_direction == 'positive':
        confidence = 0.95  # 両指標が一致 → 強い信頼
    elif background_direction == correlation_direction:
        confidence = 0.70
    else:
        confidence = 0.40  # 指標が矛盾
    
    # 分類
    if final_score > 0.7:
        classification = '✅強い民意'
    elif final_score > 0.5:
        classification = '⚠️中程度の民意'
    elif final_score > 0.2:
        classification = '❌弱い民意'
    else:
        classification = '❌民意ではない'
    
    return {
        'topic': topic,
        'final_score': final_score,
        'confidence': confidence,
        'classification': classification
    }
```

## 注釈と付記

### 削除した要素の補足

**なぜ「対応分析（イデオロギー軸の抽出）」を削除したか**:

当初の計画では、対応分析でイデオロギー軸を自動抽出し、それに基づいて「イデオロギック修辞」を除去する予定でした。しかし、以下の理由で削除されました：

1. **後続フェーズで使用されない**：  
   Phase 3a（社会背景）と Phase 3b（選挙結果）では、イデオロギー軸の出力を明示的に使用していない。

2. **より直接的な検証方法がある**：  
   外部データ（統計指標、選挙結果）との照合の方が、「民意か否か」を直接的に判定できる。

3. **データドリブンの原則に従う**：  
   外部データとの照合を通じて「必要な補正」を判定する方が、より客観的である。

### SSDSEデータセット への依存性

本分析の成否は、**Phase 3a で必要な統計指標がSSDSEに含まれているか**に大きく依存しています。
