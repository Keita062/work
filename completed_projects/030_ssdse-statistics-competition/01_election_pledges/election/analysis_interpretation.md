# 選挙マニフェスト超党派政策NLP解析 - 解釈報告書

**作成日**: 2026年4月24日  
**分析対象**: 衆議院・参議院選挙マニフェスト（19政党・11政党統合）  
**分析方法**: NMF トピックモデリング + 埋め込み + クラスタリング

---

## Executive Summary

本分析により、**超党派で真に共有されている政策テーマは極めて限定的**であることが明らかになった。

- **最も超党派的テーマ**: 経済・成長戦略（Economy-Growth）- 4政党でのみ言及
- **トピック分散度**: 12トピック中10トピックが単一政党のみに集中
- **政党差異**: 衆議院版と参議院版で同じ政党でも異なるテーマに特化

## 1. 超党派重要度スコア分析

### 1.1 ランキング（議席数加重スコア順）

| ランク | トピック | スコア | 出現政党数 | 特徴 |
|------|---------|--------|----------|------|
| **1** | 農業・食料安全保障 | 0.419 | 1党 | 自民党（衆）に集中 |
| **2** | デジタル・行政改革 | 0.376 | 1党 | 自民党（参）に集中 |
| **3** | 経済・成長戦略 | 0.053 | **4党** | 最も超党派的 |
| **4** | 医療・介護 | 0.044 | 1党 | 国民民主党（衆） |
| **5** | 税制改革 | 0.042 | 1党 | 中道（衆） |
| 6-12 | その他 | <0.02 | 1党 | 各政党の個別政策 |

### 1.2 重要な知見

**観察1: 「超党派」は幻想に近い**
- トップ5のテーマ中、4つが**単一政党のみ**で言及
- これらの「高スコア」は「議席数が多い政党が重視している」を意味する
- 真の超党派テーマは「経済・成長戦略」のみで、かつスコアは0.053（低い）

**観察2: 経済テーマだけが多党派対応**
- Economy-Growth は 4政党（公明党、参政党、国民民主党、みんなで作る党）で言及
- その他11テーマは政党が単独で提唱
- 政党は「共通課題の違う解決策」を提示するのではなく、「異なる政策課題」に焦点

## 4. 真の「超党派」テーマの検討

### 4.1 経済・成長戦略が唯一の共通テーマ

```
出現政党（4党）:
- 公明党（参）: 0.618
- 参政党（両議院）: 0.655
- 国民民主党（両議院）: 0.644
- みんなで作る党（衆）: 0.650
```

**共通点**: 
- 右派・中道・中道左派の幅広い政党が言及
- 左派（共産党、社民党、立憲民主党）は言及なし
- 経済成長を「目標」とする政党の政治的スペクトラム

### 4.2 なぜこれだけが超党派か？

1. **普遍的な課題**: GDP、賃金、物価は全政党が対象にしなければならない基本指標
2. **解決策の差異**: 成長戦略は政党の経済観の集約
   - 右派: 規制緩和、大企業支援
   - 中道: 中小企業・雇用重視
   - 中道左派: 再分配・社会保障重視
3. **左派の棄権**: 共産党・社民党・立憲民主党は「成長至上主義」を批判し、別テーマ重視

### 4.3 「超党派がない」ことの意味

- **政治的分裂**: 日本の政党システムは経済観の相違で完全に分裂
- **政策の多様性**: 共通課題に対して異なるアプローチを提示
- **選挙競争の形式**: 政党は「共通課題の解決策の違い」ではなく「課題設定の違い」で競争

## 5. データ品質と分析の限界

### 5.1 データ不足の問題

| 政党 | 衆議院 | 参議院 | 状態 | 影響 |
|-----|-------|-------|------|------|
| 自民党 | ✓ | ✓ | 豊富 | 信頼度高 |
| 参政党 | ✓ | ✓ | 良好 | 信頼度高 |
| チームみらい | ✓ | ✓ | 限定的 | 信頼度中 |
| **日本保守党** | ✗ | - | **空白** | 分析対象外 |
| **日本維新の党** | - | ✗ | **空白** | 分析対象外 |
| 社民党 | ✗（微少） | ✓ | 不均衡 | 分析は参議院版のみ有効 |

**結論**: 分析対象政党の約1/3でデータが不足・不完全

### 5.2 トークナイゼーション方法の限界

- **正規表現ベース**: 形態素解析（MeCab）の複雑性を避けるため、シンプルな文字分割を採用
- **結果**: 複合語の分割、文法構造の無視
- **改善案**: MeCab/Janome導入で粒度を改善可能

### 5.3 サンプル数の限界

- **パラグラフ数**: 34個（小規模）
- **NMF安定性**: 19政党で12トピック抽出は理想的（通常は100+ドキュメント推奨）
- **トピック数確定**: Perplexity分析を実施せず、固定値12で実行

## 7. 選挙戦略への含意

### 7.1 争点設定の戦略

**現状**: 各政党は「テーマ競争」をしている
- 自民党: 農業・経済のオーナー
- 立憲民主党: 憲法改正反対のオーナー
- 共産党: 脱原発・地方のオーナー

**戦略的含意**:
- 政党は「共通課題での競争」ではなく、「異なるテーマの提唱」で差別化
- 有権者は「どのテーマを重視するか」で投票政党を決定

### 7.2 「超党派的合意」の構築困難性

**経済・成長戦略のみが超党派的** → 左派が異議を唱える限り、本当の意味での超党派合意は難しい

### 7.3 投票者セグメンテーション

| 投票者特性 | 重視テーマ | 対応政党 |
|----------|-----------|--------|
| 農業従事者・地方 | 農業・地方創生 | 自民党 |
| 都市圏・デジタル労働者 | デジタル・成長 | 参政党、チームみらい |
| 労働組合員 | 労働条件・脱原発 | 共産党、社民党 |
| リベラル知識人 | 憲法・民主主義 | 立憲民主党 |
| 自営業者・中小企業 | 経済成長・減税 | 国民民主党 |

## 8. 結論と提言

### 8.1 主要発見

1. **「超党派政策」はほぼ存在しない** - テーマの差異化が政党戦略の中核
2. **経済成長のみが相対的に超党派的** - ただしスコア0.053と低い
3. **衆参差異が大きい** - 同じ政党でも議院別に異なるテーマ強調
4. **左右のイデオロギー分裂は根本的** - 経済観の相違が政党差異を規定

### 8.2 政策分析への提言

- **マニフェスト品質向上**: 全政党の均等なデータ提供
- **テーマ分類の細分化**: 「経済成長」の内部差異（規制緩和 vs. 雇用保護）を分析
- **左右軸の明確化**: イデオロギースコア（-5 to +5）を自動抽出

### 8.3 今後の研究課題

1. **時系列分析**: 選挙ごとにテーマがどう変わるか
2. **与野党差**: 政権政党と野党のテーマ差異
3. **地域別分析**: 地域ごとにどの政党のテーマが有効か
4. **感情分析**: ポジティブな「提案」vs. ネガティブな「批判」の比率

## 付録: 技術詳細

### A1. 分析パイプライン

```
マニフェスト原文
    ↓
[Phase 1] ボイラープレート除去 + パラグラフ分割（34段落）
    ↓
[Phase 2] 日本語トークナイズ（正規表現ベース）
    ↓
[Phase 3] TF-IDF + NMF（12トピック）
    ↓ (並行処理)
[Phase 4] sentence-transformer 埋め込み
    ↓
[Phase 4] K-Means クラスタリング（k=12）
    ↓
[Phase 5] UMAP 次元削減 → 可視化
```

### A2. ハイパーパラメータ

| 処理 | パラメータ | 値 | 理由 |
|-----|----------|-----|------|
| TF-IDF | min_df | 2 | 最低2政党で言及 |
| TF-IDF | max_df | 0.9 | 90%以上の政党が言及する語は除去 |
| NMF | n_topics | 12 | 政治的トピック領域の標準数 |
| NMF | init | nndsvda | 決定論的初期化で再現性確保 |
| K-Means | n_clusters | 12 | NMFと対応 |
| UMAP | n_neighbors | 10 | 小規模コーパス向け |

### A3. 出力ファイル形式

| ファイル | 用途 | 形式 |
|---------|------|------|
| ranked_topics.csv | トピック重要度 | 4列（ID, ラベル, スコア, 政党数） |
| party_topic_matrix.csv | 政党×トピック行列 | 19×12 NMF重み |
| paragraph_clusters.csv | 段落クラスタ割当 | テキスト+クラスタID |
| plot_A_party_map.html | 政党ポジショニング | 対話的バブルチャート |
| plot_C_heatmap.png | 可視化 | ヒートマップ |
