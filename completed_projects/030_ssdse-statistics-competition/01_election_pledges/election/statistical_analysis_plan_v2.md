## 第1部: 分析戦略と社会課題の視点

### 1.1 本分析の根本的な問題設定

**問題**: 既存分析（RQ-1〜RQ-4）の限界
- RQ-1の「民意重み付け」は大政党（自民党316議席）に支配される
- RQ-3の「時系列一貫性」は「繰り返し言及された=重要」という単純な仮定に基づく
- **政治的ノイズ**: 衆議院と参議院の制度的性質の違いが結果に混入している
  - 衆議院：全国一区で総合政策を訴求
  - 参議院：都道府県単位で地方的課題を強調
  - この制度差が「公約の言及頻度」に影響 → テキスト分析ノイズになる

### 1.2 社会課題を紐解く分析者の視点

**20年のベテラン分析者として気付くべき3つの構造的問題**:

1. **テキスト量 ≠ 政策優先度**
   - テキスト量が多い = 政党が力を入れているか？それとも「説明に時間がかかる複雑な課題」か？
   - 例）原発政策：反対派は「危険性の説明」で長文、賛成派は「経済効果」で短文
   - → テキスト長の「差分スコア」を導入

2. **言及頻度 ≠ 有権者の関心**
   - 政党は「政治的に有利な課題」を強調する（有権者の実際の困難とは異なる）
   - 例）COVID-19後のインフレは「経済成長」として語られているが、実は「生活費上昇」が民意
   - → 外部データ（世論調査、求人数の動向、社会統計）との統合分析が必須

3. **両院の公約の「乖離パターン」が有益**
   - 衆議院で強調されない課題が参議院で急に出現 = 地方課題が顕在化
   - 衆議院で「経済成長」と呼ばれるもの、参議院では「地域経済」と呼ばれるか確認
   - → 院別の「話題転換」を正式に検定

## 第2部: 政治ノイズ除去フレームワーク

### 2.1 Level-1: テキスト正規化と構造的ノイズの除去

#### 2.1.1 政治スローガンの除去

**やるべき処理:**
```
除去対象:
- 「〜の実現」「〜を推進」「強化する」などの虚像的キーワード（全政党共通）
- 「日本の未来」「国民のために」などの普遍的修辞
- 「困難だが必要」などの政治的ポジショニング用語

判定方法:
- 全政党のテキストに > 80% 出現するキーワード → 除去
- 特定の政党が「修辞的に多用」する表現 → 政党別に重み付け低下
```

**具体例:**
```
処理前: 「経済成長を推進し、困難な改革を実現する」
処理後: 「経済成長」（修辞除去）→ 「経済」への圧縮

効果: テキスト量の政党間バイアスが30〜50%削減される
```

#### 2.1.2 院別の「制度的言及パターン」の検出と補正

**統計的手法: 院別言及率の差分スコア**

```
差分スコア(課題 t) = 
  [ 参議院での言及率(t) - 衆議院での言及率(t) ] / 
  [ 衆議院での言及率(t) + 参議院での言及率(t) + ε ]
```

**解釈:**
- スコア > 0.3 = 参議院が特に強調（地方課題、長期課題）
- スコア < -0.3 = 衆議院が特に強調（全国的課題、短期的課題）
- |スコア| < 0.15 = 院別ノイズが小さい、本質的な民意を反映

**期待される発見:**
- 「農業・食糧安保」: スコア > 0.5 （参議院が特に強調）→ 地方の課題
- 「経済成長」: スコア < -0.4 （衆議院が特に強調）→ 政治的イデオロギー
- 「医療・介護」: |スコア| < 0.1 （両院で均等）→ 普遍的民意

### 2.2 Level-2: 「政治的优先度」と「民意」の乖離を定量化

#### 2.2.1 政治的優先度指標 (Political Salience Index, PSI)

**仮説**: 政党が「政治的に有利な課題」を多く掲げるのは、その課題が民意と一致しているからではなく、「政党のイデオロギー」が決めている。

**測定方法:**

```
PSI(政党 p, 課題 t) = 
  1 / [ 1 + exp(-5 × (言及率(p,t) - 政党平均言及率(p))) ]

ただし:
- 言及率(p,t) = 政党pが課題tに言及した割合
- 政党平均言及率(p) = 政党pの全課題の平均言及率
```

**具体例:**
```
自民党：
- 「経済成長」PSI = 0.92 （政党内で特に強調）
- 「社会保障」PSI = 0.35 （政党内で平均以下）

立憲民主党：
- 「経済成長」PSI = 0.48 （政党内で弱調）
- 「社会保障」PSI = 0.88 （政党内で特に強調）

→ 解釈: 「経済成長」の高い言及率は自民党のイデオロギー的優先であり、
  民意の直接的反映ではない可能性がある
```

#### 2.2.2 イデオロギー軸の抽出と制御

**統計手法: 対応分析 (Correspondence Analysis)**

```
入力:
- クロス集計表: 政党（行） × 課題（列） = 言及度数

出力:
- 第1軸：左右のイデオロギー軸
- 第2軸：中央 vs 周辺軸
- 各政党・課題のスコア

目的:
- 「経済成長」という課題が「右翼政党が強調」→ イデオロギーノイズ
- 「医療・介護」が「全政党で均等」→ ノイズが少ない民意
```

**R/Pythonコード例:**
```python
from scipy.stats import chi2_contingency
from sklearn.decomposition import FactorAnalysis

# contingency_table: 政党 × 課題の言及度数行列
chi2, p_val, dof, expected = chi2_contingency(contingency_table)

# イデオロギー軸を抽出
from prince import CA  # correspondence analysis library
ca = CA()
ca = ca.fit(contingency_table)
party_coords = ca.row_coordinates(contingency_table)  # 政党の座標
issue_coords = ca.column_coordinates(contingency_table)  # 課題の座標

# イデオロギー軸で「言及率を補正」
ideology_axis_1 = party_coords.iloc[:, 0]  # 左右軸
adjusted_emphasis = contingency_table / ideology_axis_1.values.reshape(-1, 1)
```

### 2.3 Level-3: 政治的イデオロギーを「制御」した分析

#### 2.3.1 残差分析 (Residual Analysis from Ideology)

**理論背景:**
```
観測された言及率 = (イデオロギー的に期待される言及率) + (民意による剰余変動)

剰余変動 = 観測値 - 期待値
→ この剰余変動が「純粋な民意」の指標となる
```

**計算方法:**

```
step 1: イデオロギー効果のベースラインを推定
  - 政党の左右スコア（対応分析の第1軸）と言及率の関係を回帰分析
  - 期待言及率 = β₀ + β₁ × イデオロギー_スコア

step 2: 観測値との乖離を計算
  residual(t) = 観測言及率(t) - 期待言及率(t)

step 3: 残差の平均値 > 0 の課題が「超党派的民意」
  → イデオロギーの予測値以上に、全政党が言及している = 民意が強い
```

**期待される発見:**

| 課題 | 観測値 | 期待値 | 残差 | 解釈 |
|------|--------|--------|------|------|
| 経済成長 | 0.45 | 0.42 | +0.03 | 弱いイデオロギー依存（民意あり） |
| エネルギー | 0.22 | 0.05 | +0.17 | **強い民意（イデオロギー超越）** |
| 憲法改正 | 0.15 | 0.18 | -0.03 | イデオロギー予測より弱い |

## 第3部: 民意の本質特定のための統計手法

### 3.1 多段階スクリーニング: 民意スコアの構築

#### 3.1.1 「政党横断的な同意度」の測定

**疑問**: 「複数政党が言及した = 民意」という仮定は本当か？

**より精密なスコア:**

```
民意スコア(課題 t) = 

  [ Π(p=1 to N) min(言及率(p,t), 閾値) ] × 
  [ 1 - イデオロギー依存度(t) ] × 
  [ 政党カバレッジ正規化(t) ]

各項の意味:
1. Π項: 最低限の政党すべてが言及している度合い
2. イデオロギー依存度: 「イデオロギーで説明される程度」の逆数
3. カバレッジ: 議席数で重み付けした政党カバレッジ
```

**計算例:**

```python
def民意スコア(課題, 政党言及率辞書, イデオロギー依存度, 議席シェア):
    # 1. 各政党の言及率の「最小値」（全党が賛成している程度）
    min_emphasis = min(政党言及率辞書.values())
    
    # 2. イデオロギー依存度を0-1に正規化（高いほど民意が弱い）
    ideology_penalty = イデオロギー依存度
    
    # 3. 議席数で重み付けされた平均（大政党が言及していないと民意が弱い）
    weighted_emphasis = sum(
        言及率 * 議席シェア 
        for 言及率, 議席シェア in zip(政党言及率辞書.values(), 議席シェア)
    )
    
    # 統合スコア
    score = min_emphasis * (1 - ideology_penalty) * weighted_emphasis
    return score
```

#### 3.1.2 「言及パターンの一貫性」による検証

**仮説**: 「民意の課題」は、複数政党で「似た文脈」で言及されているはず

**統計的検証:**

```
手法: Word2Vecの意味空間上での「政党別の言及文脈の類似度」

step 1: 各課題について「課題の周辺300語」をコンテキストとして抽出
  （例）「エネルギー」という単語の周辺の単語リスト

step 2: 政党別に「エネルギーの意味ベクトル」を学習
  - 自民党でのエネルギー・ベクトル
  - 立憲民主党でのエネルギー・ベクトル
  - ...など

step 3: 政党間の意味ベクトルの「コサイン類似度」を計算
  cos_similarity = 自民党ベクトル · 立憲民主党ベクトル / (||自民党|| ||立憲民主||)

step 4: 高い類似度（> 0.7）= 政党横断的な「民意としての合意」
       低い類似度（< 0.4）= イデオロギー的に対立する課題
```

**期待される結果:**

| 課題 | 政党間類似度 | 解釈 |
|------|------------|------|
| エネルギー | 0.72 | 「再生可能か原発か」は異なるが、目標（エネルギー安保）は共通 → **民意** |
| 経済成長 | 0.45 | 「規制緩和か福祉充実か」で全く異なる定義 → **イデオロギー対立** |
| 医療・介護 | 0.81 | 「財源方法」は異なるが「充実すべき」は共通 → **民意** |

### 3.2 外部検証: 世論調査データとの統合分析

#### 3.2.1 因果推論フレームワーク: Propensity Score Matching

**問題**: 「公約データ」だけでは「有権者が実際に何を求めているか」は判らない

**解決策**: 世論調査データ（例：NHK世論調査、朝日世論調査）との照合

```
目的: 「公約で強調された課題」と「世論調査での関心度」に乖離がないか確認

手法: Propensity Score Matching (PSM)

step 1: 政党の「言及率」を説明変数として、世論調査での「その課題への関心度」を予測
  
  world_attention(課題) = β₀ + β₁×言及率(課題) + β₂×イデオロギー依存度(課題) + ε

step 2: 「言及率が高いが世論が低い課題」を特定
  → これは「政党が政治的に有利な課題を強調しているが、民意ではない」の証拠

step 3: 「言及率が低いが世論が高い課題」を特定
  → これは「民意があるのに政党が軽視している課題」= 隠された民意

例:
- 「経済成長」: 公約で高×世論で高 → 純粋な民意
- 「憲法改正」: 公約で中×世論で低 → 政党の政治的関心
- 「給与・労働条件」: 公約で低×世論で高 → **隠された民意！**
```

#### 3.2.2 数値例による計算

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 入力データ
公約言及率 = np.array([0.45, 0.22, 0.08, 0.12, ...])  # 各課題の公約言及率
世論関心度 = np.array([0.68, 0.74, 0.15, 0.22, ...])  # NHK世論調査での関心度
イデオロギー依存 = np.array([0.32, 0.15, 0.78, 0.55, ...])  # 各課題のイデオロギー依存度

# 回帰分析: 公約から世論を予測
X = np.column_stack([公約言及率, イデオロギー依存])
model = LinearRegression()
model.fit(X, 世論関心度)
予測世論 = model.predict(X)

# 乖離を計算
乖離 = 世論関心度 - 予測世論

# 乖離が大きい課題を特定
高乖離_インデックス = np.where(np.abs(乖離) > 0.15)[0]
for idx in 高乖離_インデックス:
    print(f"課題{idx}: 公約{公約言及率[idx]:.2f}→世論{世論関心度[idx]:.2f} (乖離: {乖離[idx]:.2f})")
```

### 3.3 時間軸分析: 「課題の出現パターン」を検証

#### 3.3.1 時系列の「言及率の安定性」の検定

**疑問**: RQ-3の「時系列一貫性」は単なる「繰り返し言及」だが、それは民意か？

**より精密な検定:**

```
Granger因果性検定 (Granger Causality Test)

帰無仮説:
  「衆議院での言及率」が「参議院での言及率」の直後の値を予測しない
  
→ 帰無仮説が棄却される課題 = 「政治的な継続性」（民意ではなく政治的決定）
→ 帰無仮説が採択される課題 = 「独立した民意」（異なる時点で同じく言及される）

実装:
from statsmodels.tsa.stattools import grangercausalitytests

衆議院時系列 = [2024Q4, 2025Q1, 2025Q2, ...]のエネルギー言及率
参議院時系列 = [2025Q3, 2025Q4, 2026Q1, ...]のエネルギー言及率

結果 = grangercausalitytests(参議院時系列, 衆議院時系列, maxlag=2)
# p値 < 0.05なら「衆議院での言及が参議院に影響」= 政治的継続性
# p値 > 0.05なら「独立した言及」= 民意
```

#### 3.3.2 「課題の急出現」と「急消失」の検出

**社会課題を紐解く視点**: ある課題が「突然言及され始める」のはなぜか？

```
手法: 変点検出 (Change Point Detection)

step 1: 各課題について、月別の言及率の時系列を作成

step 2: PELT (Pruned Exact Linear Time) アルゴリズムで変点を検出
  → 言及率が「急に上昇」「急に下降」した時点を特定

step 3: その時点での「社会的イベント」と照合
  例）
  - 2024年8月: 「エネルギー」言及率が0.12→0.28に急上昇
    → この時点で「電力逼迫警報」があったか確認
    → 「政治的対応」ではなく「社会的背景」があるか検証
    → 社会的背景がある = より真の民意に近い

実装:
from ruptures import Pelt

課題の時系列 = [0.10, 0.11, 0.12, 0.28, 0.35, 0.32, ...]  # 月別言及率
検出器 = Pelt(model="l2", min_size=3).fit(課題の時系列)
変点 = 検出器.predict()
```

## 第4部: 最終的な「民意スコア」の統合計算

### 4.1 複合民意スコア (Composite Public Will Index, CPWI)

**これまでの手法を統合した最終指標:**

```
CPWI(課題t) = 
  w₁ × normalize(民意スコア) +
  w₂ × normalize(1 - イデオロギー依存度) +
  w₃ × normalize(政党間意味類似度) +
  w₄ × normalize(世論との乖離補正) +
  w₅ × normalize(社会的背景スコア)

重み設定:
- w₁ = 0.25: 基本の民意スコア
- w₂ = 0.20: イデオロギー超越性
- w₃ = 0.20: 政党横断的合意
- w₄ = 0.20: 世論調査との整合性
- w₅ = 0.15: 社会的背景（外部イベント）
```

### 4.2 ロバスト性検定

```
検定方法:
1. ブートストラップ法 (Bootstrap Resampling)
   - 政党サンプルを100回復元抽出
   - 毎回のCPWI計算で「スコアの分布」を確認
   - 95%信頼区間が狭い課題 = ロバストな結果

2. 感度分析 (Sensitivity Analysis)
   - 重み(w₁...w₅)を±10%変動させる
   - CPWI順位の変動を確認
   - 順位変動が小さい課題 = 重みの仮定に依存しない結果

3. k値の感度分析
   - NMFのトピック数を k=8, 10, 12, 15 で実行
   - トピック集約後のCPWI結果が一貫しているか確認
```
