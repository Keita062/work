# SSDSE

統計データ分析コンペティション（SSDSE）向けのリサーチ・分析を管理するフォルダです。

これまで分析テーマが複数回転換しており（選挙公約分析 → 産業別労働経済分析）、その都度過去の作業が迷子にならないよう、**テーマ単位のサブフォルダ**で管理しています。次にまた方針が変わってSSDSEに戻ってきた場合も、下記の一覧から状況を確認し、`03_...` のように新しいテーマフォルダを追加すれば作業を再開できます。

## フォルダ構成

### `common/`
テーマに依存しない共通リソース。
- `2025_toukei/` — 2025年実施会の過去問PDF（H1-H4, U1-U4: 基本問題／H5-01〜06, U5-01〜05: 応用問題）。データ分析スキルの習得やコンペ傾向の把握に使う。
- `2025年統計データ分析競技_完全ガイド.md` — コンペ自体の完全ガイド

### `01_election_pledges/`（状況: 一区切り・保留）
2025年衆議院・参議院選挙の各党公約テキストを分析し、「有権者が直面する社会課題の優先度」をSSDSE公的統計と突き合わせて特定しようとしたテーマ。
- 結論・詳細: [`01_election_pledges/README.md`](01_election_pledges/README.md)

### `02_industry_labor_economics/`（状況: 進行中）
産業別の賃金・勤続年数・超過労働時間・失業者数・倒産件数を用いて、失業者数を被説明変数とするOLS回帰分析を行っているテーマ。
- 方針・詳細: [`02_industry_labor_economics/README.md`](02_industry_labor_economics/README.md)

### `03_unemployment_lca_gis/`（状況: 要件定義ほぼ確定・実行プラン策定済み）
業種別の完全失業率を目的変数とし、業種の労働特性から潜在クラスモデリング（LCA、主手法）で要因パターンを抽出、都道府県別の産業構成比を介した地理レイヤー（曝露度算出・空間統計・マッピング）を統合するテーマ。SSDSEコンペのエントリー締切2026-08-07・論文締切2026-08-28午前を意識して進行中。
- 要件定義・詳細: [`03_unemployment_lca_gis/README.md`](03_unemployment_lca_gis/README.md)

## SSDSEに戻ってきたときの始め方

1. まず `common/2025_toukei` と完全ガイドで出題傾向を再確認する。
2. 既存テーマ（`01_...`, `02_...`）のREADMEを読み、続きから再開するか新テーマにするか判断する。
3. 新テーマを始める場合は `03_<テーマ名>/` を作り、`data/` `scripts/` `docs/` `results/` 等、既存テーマと同様の構成とREADMEを用意する。
