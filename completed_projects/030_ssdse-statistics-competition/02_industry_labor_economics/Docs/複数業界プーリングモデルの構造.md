# 複数業界プーリングモデルの詳細構造

## 📐 モデル式

```
失業者数 = β₀ + Σβᵢ × 労働統計ᵢ + Σγⱼ × 年度ダミーⱼ + Σδₖ × 業界ダミーₖ + ε
```

### 各成分の説明

| 項目 | 内容 | 個数 |
|------|------|------|
| **β₀** | 定数項 | 1 |
| **労働統計** | 勤続年数、超過労働時間、給与額（企業規模別） | 12 |
| **年度ダミー** | 2018, 2019, 2020, ..., 2025（2014年を基準） | 8 |
| **業界ダミー** | 全10業界のうち9個（サービス業他を基準） | 9 |
| **残差** | 説明されない部分 | - |

---

## 📊 データ構造：ビフォー・アフター

### ❌ 修正前（失敗したモデル）

```
サンプル数：9（年度のみ）

2014年  失業者数=37 ←→ 勤続年数=13.4年（9企業規模の平均）
2018年  失業者数=31 ←→ 勤続年数=13.8年
2019年  失業者数=35 ←→ 勤続年数=13.1年
...

問題：
・被説明変数が年度のみで決定される
・年度ダミー 8個 + 定数項 1個 = 説明変数 9個以上
・説明変数 > 残差自由度 → R²=1.0（過学習）
```

## 📈 推定結果の解釈

### モデル式の具体例

```
サービス業他、2014年の場合：
  失業者数 = 47.08 + Σ労働統計係数 × 値 + 0 + 0 + ε
           = 47.08 + (労働統計項目の効果) + ε
           ≈ 37人

不動産業、2018年の場合：
  失業者数 = 47.08 + Σ労働統計係数 × 値 + (-3.14) + (-38.69) + ε
           = 47.08 - 3.14 - 38.69 + (労働統計項目の効果) + ε
           ≈ 1人

情報通信業、2022年の場合：
  失業者数 = 47.08 + Σ労働統計係数 × 値 + (-3.74) + (-36.69) + ε
           = 47.08 - 3.74 - 36.69 + (労働統計項目の効果) + ε
           ≈ 4人
```

### 推定係数の解釈

#### 労働統計の係数（有意でない）
```
10人_勤続年数_年：β = -1.506  (p=0.484)
  ❌ 有意でない
  解釈：企業規模別の勤続年数変化が、失業者数に直接的な影響なし
  
10人_超過実労働時間数_時間：β = 0.387  (p=0.516)
  ❌ 有意でない
  解釈：超過労働時間の増減が、失業者数の変化を説明しない

所定内給与額_千円：β = -0.043～0.020  (p > 0.5)
  ❌ 有意でない
  解釈：給与変化の失業への直接的効果は検出不可
```

**理由：** 業界効果と年度効果が支配的で、労働統計の変動は相対的に小さい

#### 年度ダミーの係数（一部有意）
```
year_2018：β = -3.14  ** p=0.020
  ✅ 有意（p<0.05）
  解釈：2014年比で、2018年は失業者数が平均3.14人減少

year_2019：β = -3.12  ** p=0.022
  ✅ 有意（p<0.05）
  解釈：2014年比で、2019年は失業者数が平均3.12人減少

year_2022：β = -3.74  ** p=0.029
  ✅ 有意（p<0.05）
  解釈：2014年比で、2022年は失業者数が平均3.74人減少

year_2020：β = 0.88   (p=0.621)
  ❌ 有意でない（パンデミック年も有意な上昇なし）

year_2021：β = -0.85  (p=0.615)
  ❌ 有意でない
```

#### 業界ダミーの係数（全て有意***）
```
industry_産業合計：β = 48.04  *** p<0.001
  ✅ 非常に有意
  解釈：全業界集計の失業者数は、サービス業他比で約48人多い

industry_農・林・漁・鉱業：β = -41.74  *** p<0.001
  ✅ 非常に有意
  解釈：農林漁業の失業者数は、サービス業他比で約41.74人少ない

industry_情報通信業：β = -36.69  *** p<0.001
industry_不動産業：β = -38.69  *** p<0.001
industry_金融・保険業：β = -35.65  *** p<0.001
  ✅ いずれも非常に有意（p<0.001）
  解釈：これらの業界は失業者数が大きく少ない
```

## 🎯 モデルから何がわかるのか？

### 1. **業界の特性が支配的**
- 失業者数の最大差異は業界によって生じている
- サービス業他が相対的に失業者が多い業界
- 情報通信業、金融・保険業は失業者が少ない

### 2. **時系列トレンド**
- 2018, 2019, 2022年に失業が減少
- パンデミック（2020年）の有意な影響は検出されず
- 全体的には安定した失業パターン

### 3. **労働統計の限定的な役割**
- 勤続年数、超過労働時間、給与額は
  **業界効果と年度効果を制御した後**
- 失業者数を説明する有意な力がない
- 業界内での労働条件の違いが失業に反映されない

### 4. **モデルの予測精度**
- R² = 0.992（99.2%のばらつきを説明）
- しかし、ほぼ業界ダミーによる説明
- 労働統計の追加的価値は限定的

## ⚠️ モデルの限界と注意点

### 1. **多重共線性**
```
条件数 = 3.66e+04（非常に大きい）
→ 説明変数間に相関がある
→ 個別係数の精度が低い可能性
```

### 2. **業界効果の過度な説明力**
```
モデルのR²の大部分は業界ダミーで説明されている
→ 労働統計の効果が隠れている可能性
→ より詳細なモデル化が必要かもしれない
```

### 3. **残差の分布**
```
Jarque-Bera検定：p < 0.001
→ 残差が正規分布していない
→ Kurtosis = 9.037（厚い尾を持つ分布）
→ 外れ値の存在を示唆
```

### 4. **因果関係の欠如**
```
このモデルは相関関係（association）を示すが
原因と結果の関係（causality）を証明するものではない
例）超過労働が少ない → 失業が多い
    vs
    失業が多い → 超過労働が少ない
どちらの因果性は？
```
