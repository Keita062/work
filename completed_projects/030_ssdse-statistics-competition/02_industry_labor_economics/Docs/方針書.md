# 失業者数を被説明変数とするOLS回帰分析の方針書

## 1. 分析の基本方針

### 被説明変数（アウトカム）
- **失業者数**（男女計）
  - サービス業他の失業者数を時系列で観察する
  - 対象産業：**サービス業他のみ**
  - 理由：全産業の中で最大規模の失業者数を有し、十分な変動幅があり、経済トレンド（特にCOVID-19等のマクロショック）を最も反映する信頼性が高い

### 推定手法
- **OLS（普通最小二乗法）**
  - 線形回帰モデルを用いた最小二乗推定
  - 各説明変数が失業者数に与える影響を定量的に把握

---

## 2. データの準備とフィルタリング

### データソース
- **失業者データ**: 失業者 - シート1_共通年_統一.csv
- **労働特性データ**: 勤続年数・超過実労働時間数・所定内給与額_時系列_共通年_統一.csv

### フィルタリング手順

#### 産業の絞り込み
- 対象産業：**サービス業他のみ**を抽出

#### 区分（分類）による統一化
労働特性データに含まれる「区　分」列には、統計局の分類基準が記載されています。「男女計」と「学歴計」の両方を含む区分を選択することで、全体統計データを取得します。

**注記**: 統計局がデータ形式を変更したため、年度によって異なる区分値が使用されています：
- **2014年、2018-2019年**: 「     男\n学　　計　　計」形式
- **2020-2024年**: 「男\n学教育計」形式  
- **2025年**: 「　　　男\n学　　計　　計」形式

これら複数の区分値を統合して、全期間（2014年、2018-2025年）のデータを統一します。

---

## 3. 説明変数の構成

失業者数に影響を与える可能性がある労働市場の特性について、2つのアプローチを採用します。

### 説明変数の候補
以下の変数をベースとして用いる：

1. **勤続年数**（事業者人数ごと）
   - 10人未満
   - 10～99人
   - 100～999人
   - 1,000人以上

2. **超過実労働時間数**（事業者人数ごと）
   - 10人未満
   - 10～99人
   - 100～999人
   - 1,000人以上

3. **所定内給与額**（事業者人数ごと）
   - 10人未満
   - 10～99人
   - 100～999人
   - 1,000人以上

4. **年度ダミー変数**
   - 2014年、2018年、2019年、2020年、2021年、2022年、2023年、2024年、2025年
   - （利用可能な年度のみ。2015年、2016年、2017年のデータはなし）
   - 時系列の固定効果を捉える

**変数の意味**：
- **勤続年数**: 雇用の安定性を示す。勤続年数が長い産業は失業が少ないと予想
- **超過実労働時間数**: 労働需要の強さを示す。超過労働が多い場合は失業が少ないと予想
- **所定内給与額**: 労働生産性や産業競争力を示す。給与が高い産業は構造的失業が少ないと予想
- **年度ダミー変数**: マクロ経済的なショック（景気変動、パンデミックなど）の時系列効果を制御

---

## 4. 推定方法の詳細

### 方針1：単純な説明変数の直接投入

#### モデル式
```
失業者数_t = β₀ + Σβᵢ × 説明変数ᵢ_t + εₜ
```

#### 説明変数の構成
以下の説明変数を直接投入：

**勤続年数（4種類）**
- X₁: 10人未満企業の勤続年数
- X₂: 10～99人企業の勤続年数
- X₃: 100～999人企業の勤続年数
- X₄: 1,000人以上企業の勤続年数

**超過実労働時間数（4種類）**
- X₅: 10人未満企業の超過実労働時間数
- X₆: 10～99人企業の超過実労働時間数
- X₇: 100～999人企業の超過実労働時間数
- X₈: 1,000人以上企業の超過実労働時間数

**所定内給与額（4種類）**
- X₉: 10人未満企業の所定内給与額
- X₁₀: 10～99人企業の所定内給与額
- X₁₁: 100～999人企業の所定内給与額
- X₁₂: 1,000人以上企業の所定内給与額

**年度ダミー変数（9種類）**
- D₁: 2014年ダミー
- D₂: 2018年ダミー
- D₃: 2019年ダミー
- D₄: 2020年ダミー
- D₅: 2021年ダミー
- D₆: 2022年ダミー
- D₇: 2023年ダミー
- D₈: 2024年ダミー
- D₉: 2025年ダミー

#### 推定結果の解釈
- 各説明変数の係数の有意性を検定
- 失業者数に対する影響度を定量評価
- 多重共線性の確認
- 年度ダミーの係数から、時系列的なマクロ経済ショック（景気変動、パンデミック等）の影響を定量化

---

### 方針2：主成分分析（PCA）を用いた説明変数の圧縮

#### モデル式
```
失業者数_t = β₀ + Σβⱼ × PC_j + εₜ
```

#### 手順

**Step 1: データの標準化**
- 以下の合計21個の説明変数を標準化（平均0、標準偏差1）：
  - 勤続年数：4個
  - 超過実労働時間数：4個
  - 所定内給与額：4個
  - 年度ダミー：9個（2014, 2018, 2019, 2020, 2021, 2022, 2023, 2024, 2025年）

**Step 2: 主成分分析の実施**
- 相関行列に基づいて固有値分解を実施
- 主成分を抽出し、累積寄与率を確認

**Step 3: 説明変数の構成**
- **全ての主成分**を説明変数として投入
  - PC₁（第1主成分）
  - PC₂（第2主成分）
  - PC₃（第3主成分）
  - ⋮
  - PCₘ（第m主成分）
  
※ここで、年度ダミー変数も主成分分析の入力に含まれるため、時系列効果が主成分に組み込まれる

#### PCA使用の利点
1. **多重共線性の除去**: 主成分は互いに直交しており、多重共線性が存在しない（年度ダミー間の相関も吸収）
2. **解釈可能性**: 各主成分が労働市場のどの側面を捉えているかを分析可能
3. **モデルの安定性**: OLSの推定安定性が向上
4. **次元削減**: 24個の変数から更に少ない次元の主成分に圧縮し、過学習を防止

#### 推定結果の解釈
- 各主成分の係数の有意性と符号を検定
- 元の説明変数への変換によって、最終的な影響を復元
- 方針1との結果比較による頑頑性の確認

## 5. 推定結果の比較と検証

### 両方針の比較観点

| 項目 | 方針1（直接投入） | 方針2（PCA） |
|------|-----------------|----------|
| **説明変数数** | 21個（勤続年数4 + 超過労働4 + 給与4 + 年度ダミー9） | m個の主成分 |
| **解釈性** | 各変数の直接的な効果が明確 | 合成指標としての効果が明確 |
| **多重共線性** | 注意が必要（年度ダミー間の相関） | なし |
| **自由度** | 24個の係数を推定 | m個の主成分係数を推定 |
| **モデル選択** | AIC/BIC等で判定 | 累積寄与率で判定 |

### 検証項目
- **決定係数（R²）**: モデルの適合度評価
- **調整済み決定係数（Adjusted R²）**: 自由度を考慮した適合度
- **各係数のt検定**: 個別変数の有意性確認
- **F検定**: モデル全体の有意性確認
- **残差分析**: 正規性、等分散性、自己相関の確認

## 6. 期待される結果と解釈

### 方針1（直接投入）での予想

**正の係数（失業を増加させる）**
- 勤続年数が短い → 雇用が不安定 → 失業増加
- 超過労働時間が少ない → 労働需要不足 → 失業増加
- 所定内給与が低い → 産業競争力低下 → 失業増加

**負の係数（失業を減少させる）**
- 勤続年数が長い → 雇用安定 → 失業減少
- 超過労働時間が多い → 労働需要高 → 失業減少
- 所定内給与が高い → 産業競争力高 → 失業減少

### 方針2（PCA）での予想

- **PC₁**: 労働環境全体の質を示す合成指標
  - 勤続年数、給与、労働時間が同方向に変動
  - 失業との負の相関が想定される

- **PC₂以降**: 労働市場の特定側面を捉える指標
  - 企業規模別の差異や業界固有の特性を反映
