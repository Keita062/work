# データスケール問題の図式説明

## 🔴 現在の問題の本質

### 1️⃣ データソースのスケールが異なっている

```
【失業者データ（被説明変数）】
全国レベル・業界全体の単一値
┌─────────────────────────┐
│ 2014年：失業者数 = 37人  │  ← 1つの値のみ
│ 2018年：失業者数 = 31人  │
│ 2019年：失業者数 = 35人  │
│ 2020年：失業者数 = 42人  │
└─────────────────────────┘

【労働統計データ（説明変数）】
企業規模別の複数値
┌────────────────────────────────────┐
│ 2014年：                            │
│  ├─ 10人未満：勤続年数13.4年,...    │
│  ├─ 10～99人：勤続年数13.7年,...   │
│  ├─ 100～999人：勤続年数13.3年,... │
│  ├─ 1,000人以上：勤続年数14.2年,..│
│  └─ 他の変数（超過労働時間等）...  │
└────────────────────────────────────┘
```

---

### 2️⃣ マージ後：不自然なデータ構造

```
【マージ前】
失業者データ（9行 × 1年度）
  2014年 → 失業者数 = 37

労働統計（9行 × 9企業規模・複数項目）
  2014年 → 異なる値の9サンプル

【マージ後】
┌────────┬────────────┬─────────────────┐
│ 年度   │ 失業者数   │ 説明変数        │
├────────┼────────────┼─────────────────┤
│ 2014   │ 37.0  ◄─── │ 13.4, 7, 428..  │
│ 2014   │ 37.0  ◄─── │ 8.3, 7, 343..   │
│ 2014   │ 37.0  ◄─── │ 13.7, 14, 404.. │
│ 2014   │ 37.0  ◄─── │ 10.2, 10, 290.. │
│ 2014   │ 37.0  ◄─── │ 9.5, 15, 272..  │
│ ...    │ ...   ◄─── │ ...             │
│ 2018   │ 31.0  ◄─── │ 13.4, 6, 434..  │
│ 2018   │ 31.0  ◄─── │ 9.1, 7, 340..   │
│ ...    │ ...   ◄─── │ ...             │
└────────┴────────────┴─────────────────┘

⚠️ 問題：同じ年度では被説明変数が完全に一定！
```

---

### 3️⃣ 回帰分析の結果

```
【説明変数12個のみで推定】
労働統計だけで失業者数を説明
R² = 0.266（26.6%）
❌ 説明変数は失業者数の変動をほとんど説明できない

【説明変数12個 + 年度ダミー8個で推定】
労働統計 + 「2014, 2018, 2019, 2020, 2021, 2022, 2023, 2024」
R² = 1.000（100%）
✅ しかし...これは当然の結果！

       なぜなら：
       ┌─────────────────────────────────┐
       │ 失業者数 = 年度のみで決定される   │
       │           (変動がすべて年度)    │
       │                                 │
       │ 年度ダミー 9個で年度を完全に    │
       │ 識別できるため R² = 1.0         │
       └─────────────────────────────────┘
```

---

## 🟡 なぜこんなことが起きた？

```
【データの階層が異なる】

失業者データ：
  年度 → 失業者数（単一値）
  
       2014  →  37人 ┐
       2018  →  31人 │ 全国レベル・業界全体
       2019  →  35人 │ 1つの値のみ
       2020  →  42人 ┘

労働統計：
  年度 → 企業規模（複数分類） → 複数の値
  
       2014 ─┬─ 10人未満 → 13.4年, 7時間, 428千円
            ├─ 10～99人 → 13.7年, 14時間, 404千円
            ├─ 100～999人 → 13.3年, 14時間, 424千円
            └─ 1,000人以上 → 14.2年, 11時間, 322千円

❌ スケールが違うデータをマージした
   = 同じ被説明変数が9回重複
   = 年度のみで説明可能に
```

---

## 🟢 解決策

### 方法1：失業率を使う
```
変更前：失業者数 = 37人（絶対値、年度で決定）
変更後：失業率 = 失業者数 ÷ 労働力人口
        ↓
        企業規模別に変動する可能性がある
        ↓
        説明変数と本来の関係を分析可能
```

### 方法2：企業規模別に分解
```
変更前：
  全業界失業者数 = 37人 ← マージできない
  
変更後：
  10人未満企業の失業者数 = ?
  10～99人企業の失業者数 = ?
  100～999人企業の失業者数 = ?
  1,000人以上企業の失業者数 = ?
  
  ↓ マージ ↓
  
  企業規模別失業者数 ←→ 企業規模別労働統計
  （同じレベルのデータ）
```

### 方法3：前年度比や変化率を使う
```
失業者数（レベル）：年度で完全決定
    ↓
失業者数の変化率：企業規模別労働変化の影響を反映？
    ↓
説明変数の変化率と組み合わせる
```

## 📊 データ構造の比較

### ❌ 現在（うまくいかない）
```
全国失業者数（1値）  ←→  企業規模別労働統計（9値）
      └─ 1:9 でマージ
      └ 結果：年度のみで説明可能
```

### ✅ 理想形（解決後）
```
企業規模別失業者数（9値）  ←→  企業規模別労働統計（9値）
         └─ 1:1 対応
         └ 結果：有意な関係を検出可能
```

## 📌 まとめ

| 項目 | 現状 | 問題 |
|------|------|------|
| **被説明変数** | 全国・業界全体の単一値 | 年度でのみ変動 |
| **説明変数** | 企業規模別の複数値 | 同一年度内で変動 |
| **マージ構造** | 1:9の不等データ | 年度ダミーで完全説明 |
| **R²** | 1.000 | 経済学的意味がない |
| **結論** | データレベルの不一致 | **修正が必須** |
